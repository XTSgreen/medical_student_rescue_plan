# 人工智能的数学基础

<span class="chapter-tag">第三模块</span>

本模块面向想进入机器学习 / 深度学习方向的同学，系统讲解 AI 所需的三大数理基础：**线性代数**、**概率与统计**、**最优化**。每个核心概念均配有公式推导、几何直觉、Python 代码示例，部分章节包含基于 Three.js 的 3D 交互演示。

## 学习建议

<div class="admonition key-idea">
<p class="title">三重视角</p>
<p>线性代数强调"代数—几何—工程"三重视角；概率统计强调"频率派—贝叶斯派"两种思维；最优化强调"几何直观—算法实现"双向理解。贯穿三者的主线是：把抽象数学翻译成可运行的代码。</p>
</div>

### 推荐学习顺序

1. **线性代数 1.1 - 1.8** —— 完整学完，配合 3D 交互演示建立直觉
2. **概率与统计 2.1 - 2.4** —— 理解随机性与不确定性
3. **最优化 3.1 - 3.4** —— 掌握神经网络训练背后的数学原理

完成本模块后，你将具备阅读主流机器学习 / 深度学习教材（如《动手学深度学习》《Pattern Recognition and Machine Learning》）所需的全部数理基础。
