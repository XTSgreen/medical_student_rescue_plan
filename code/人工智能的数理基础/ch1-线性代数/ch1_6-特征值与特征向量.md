# 1.6 特征值与特征向量

<span class="chapter-tag">第一章 · 线性代数</span>

> 本章节正在建设中，将在 1.1 验收通过后批量铺开。

## 预计内容

- 特征值与特征向量的定义 $A\mathbf{v} = \lambda \mathbf{v}$
- 几何意义：变换中"方向不变"的特殊向量
- 特征方程与特征多项式
- 对角化 $A = P D P^{-1}$
- 对称矩阵的正交对角化
- 谱定理
- 工程应用：主成分分析（PCA）、PageRank、振动模态分析
