# 1.1 向量与基本运算

<span class="chapter-tag">第一章 · 线性代数</span>

线性代数的全部大厦，建立在一个最朴素的对象之上——**向量**。本节将围绕向量的几何本质、代数运算、度量方式、乘法规则与组合方式五个层面，循序渐进地建立起代数—几何—工程的三层意义。理解向量不只是记住它的定义与公式，更重要的是能在三种视角之间自由切换：**解方程时用代数视角，理解变换时用几何视角，处理数据时用工程视角**。

## 1.1.1 向量的几何本质与坐标表达

### 标量与向量的数学定义对比

在进入向量之前，先回顾一个更基础的对象——**标量**（Scalar）。标量是一个只用一个数就能完全描述的量，例如温度 $36.5$℃、血压 $120$ mmHg、基因表达量 $5.2$。标量只关心"多少"，不关心"朝哪个方向"。在数学上，标量就是实数 $\R$ 中的元素，它的全部信息浓缩在一个数值里。

**向量**（Vector）则不同，它同时携带"多少"和"哪个方向"两重信息。一个三维力 $\mathbf{F} = (3, 0, 4)$ 牛顿，不仅告诉我们力的大小是 $5$ 牛顿，还告诉我们力的方向是沿 $x$ 轴正向 $3$ 个单位、沿 $z$ 轴正向 $4$ 个单位。当你在临床上推平车时，光知道"用力 $50$ 牛顿"是没用的——你必须知道这个力是朝病房门口推还是朝墙推。这正是向量相对于标量的本质扩展：**在量值之外引入了方向**。

从数学形式上看，标量是 $\R$ 中的元素，$n$ 维向量是 $\R^n$ 中的元素。当 $n=1$ 时，向量退化为标量，因此标量可以视为向量的特殊情形。这种"特殊包含于一般"的思维方式在数学中极为常见——一维是高维的退化，实数是复数的退化，标量是向量的退化。

### 向量的几何具象化：有向线段

把向量放在坐标系中，最直观的几何形象是**一根带方向的线段**，称为**有向线段**。它有两个关键属性：**模长**（线段的长度，表示向量的大小）与**方向**（箭头指向，表示向量的朝向）。在二维平面中，向量 $\mathbf{v} = (3, 4)$ 就是从原点 $(0, 0)$ 出发指向点 $(3, 4)$ 的一根箭头；其模长由勾股定理给出 $\|\mathbf{v}\| = \sqrt{3^2 + 4^2} = 5$，方向则是从原点看向 $(3, 4)$ 的视线方向。

需要特别强调的是，**向量的几何本质是"方向 + 模长"，与起点无关**。把同一根箭头平移到平面任何位置，它仍然代表同一个向量。这一点初学者常常忽略，但它却是后续理解"自由向量"与"线性变换"的关键。在工程实践中，无论把图像特征向量存在内存的哪个位置，它所表示的"特征方向"是不变的。

### 向量的代数具象化：有序数对

几何形象直观但不便于计算，因此需要把向量翻译成代数语言。一个 $n$ 维向量是 $n$ 个有序实数的组合，称为**有序数对**（在二维情形）或**有序数组**（在高维情形）。这 $n$ 个数称为向量的**分量**（component）。

向量有两种书写形式：**列向量**与**行向量**。列向量把分量竖向排列：

$$
\mathbf{v} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix} \in \R^n
$$

行向量把分量横向排列：$\mathbf{v} = [v_1, v_2, \ldots, v_n]$。在大多数线性代数教材与机器学习论文中，**默认使用列向量**，因为它与矩阵右乘的记法一致：$\mathbf{A}\mathbf{v}$ 表示矩阵 $\mathbf{A}$ 作用于列向量 $\mathbf{v}$。行向量通常视为列向量的转置，记作 $\mathbf{v}^T$。本教程在不特别说明时，一律采用列向量。

<div class="admonition note">
<p class="title">书写规范提示</p>
<p>在数学推导中，向量通常用粗体小写字母 $\mathbf{v}$ 或带箭头的 $\vec{v}$ 表示；标量用普通斜体 $v$ 表示。在工程代码中（如 NumPy），向量就是一维数组，没有粗细之分。看到 $\mathbf{v}$ 时脑海中应浮现一根箭头，看到 $v$ 时应浮现一个数。</p>
</div>

### 零向量与负向量

**零向量**（Zero Vector）是所有分量都为 $0$ 的向量，记作 $\mathbf{0}$。在二维中 $\mathbf{0} = (0, 0)$，在三维中 $\mathbf{0} = (0, 0, 0)$。几何上，零向量是从原点指向自身的一根"长度为零的箭头"——它没有方向，或者说方向是任意的。零向量在向量运算中扮演的角色类似于实数 $0$ 在算术中的角色：它是加法的单位元，$\mathbf{v} + \mathbf{0} = \mathbf{v}$ 对任何向量 $\mathbf{v}$ 都成立。

**负向量**（Negative Vector）是与原向量大小相等、方向相反的向量。若 $\mathbf{v} = (3, 4)$，则 $-\mathbf{v} = (-3, -4)$。几何上，负向量就是把原箭头绕起点旋转 $180°$ 得到的新箭头。负向量的引入使得向量减法可以统一为加法：$\mathbf{u} - \mathbf{v} = \mathbf{u} + (-\mathbf{v})$。这一点在后续理解线性方程组求解时极为重要。

### 单位向量与归一化

**单位向量**（Unit Vector）是模长为 $1$ 的向量。单位向量的意义在于：它**只携带方向信息**，把"大小"这一维度剥离出去。在许多工程场景中（如余弦相似度计算、神经网络权重初始化），我们只关心方向而不关心大小，此时就需要把向量转化为单位向量，这个过程称为**标准化**或**归一化**（Normalization）。

给定非零向量 $\mathbf{v}$，其归一化公式为：

$$
\hat{\mathbf{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|}
$$

其中 $\|\mathbf{v}\|$ 是向量的模长。归一化的几何意义是把箭头"压缩"或"拉伸"到长度为 $1$，但保持方向不变。归一化后的向量 $\hat{\mathbf{v}}$ 读作 "v hat"，它的所有分量都除以了同一个标量 $\|\mathbf{v}\|$，因此分量间的比例关系保持不变，方向自然不变。

```python
import numpy as np

# 一个非零向量
v = np.array([3.0, 4.0])

# 模长（L2 范数）
norm_v = np.linalg.norm(v)
print(f"|v| = {norm_v}")  # 输出 5.0

# 归一化得到单位向量
v_hat = v / norm_v
print(f"v̂ = {v_hat}")              # 输出 [0.6 0.8]
print(f"|v̂| = {np.linalg.norm(v_hat)}")  # 输出 1.0
```

### 标准正交基：i, j, k

在三维空间中，有三个特殊的单位向量构成了整个空间的"骨架"，它们是 $\mathbf{i}, \mathbf{j}, \mathbf{k}$：

$$
\mathbf{i} = (1, 0, 0), \quad \mathbf{j} = (0, 1, 0), \quad \mathbf{k} = (0, 0, 1)
$$

这三个向量分别指向 $x$ 轴、$y$ 轴、$z$ 轴的正方向，长度均为 $1$，且两两互相垂直。它们构成了三维空间的**标准正交基**（Standard Orthonormal Basis）。所谓"正交"就是互相垂直，"标准"就是长度为 $1$。

任何一个三维向量 $\mathbf{v} = (v_1, v_2, v_3)$ 都可以分解为这三个基向量的线性组合：

$$
\mathbf{v} = v_1 \mathbf{i} + v_2 \mathbf{j} + v_3 \mathbf{k}
$$

这就是为什么向量的坐标 $(v_1, v_2, v_3)$ 同时具有"沿三个坐标轴的投影长度"这层几何含义。理解标准正交基是后续学习"基变换"和"特征分解"的起点——任何一个基向量组只要满足"两两正交且模长为 $1$"，都可以充当坐标系。

### 自由向量与固定向量的区别

至此需要澄清一个常被忽略的概念区分：**自由向量**（Free Vector）与**固定向量**（Bound Vector / Position Vector）。

**自由向量**只关心"方向 + 模长"，与起点无关。把它平移到空间任何位置，仍然代表同一个向量。本教程中讨论的向量运算（加法、数乘、点积、叉积）默认都是对自由向量进行的。在数学推导中，把向量平移到同一起点是为了便于几何作图，但向量本身是"自由"的。

**固定向量**则与起点绑定，常用于描述物理中的位置或位移。例如，质点的位置向量 $\mathbf{r}$ 通常以坐标原点为起点；力的作用效果不仅取决于力的大小和方向，还取决于作用点（即起点）。

<div class="admonition tip">
<p class="title">为什么这个区分重要</p>
<p>在物理学中，把力当作固定向量处理才能正确计算力矩；在数学中，把向量当作自由向量才能定义"两个向量相等"——只要方向相同、模长相等就视为相等，不必关心起点。本教程后续讨论的线性代数概念（如线性组合、张成、线性无关）都建立在自由向量的前提下。</p>
</div>

### 向量坐标与空间点的坐标映射

向量与空间点之间存在一一对应关系：向量 $\mathbf{v} = (v_1, v_2, v_3)$ 对应空间中的点 $P(v_1, v_2, v_3)$。这种对应关系通过"从原点出发的固定向量"建立：点 $P$ 的坐标就是从原点 $O$ 指向 $P$ 的向量 $\overrightarrow{OP}$ 的分量。

这种映射使得"点"与"向量"在很多时候可以互换使用，但要理解它们的语义差异：**点描述位置，向量描述方向与位移**。说"点 $A$ 在 $(1, 2, 3)$"是描述位置；说"向量 $\mathbf{v} = (1, 2, 3)$"是描述一个方向。从点 $A$ 到点 $B$ 的位移向量是 $\overrightarrow{AB} = B - A$，这是"两点决定一个向量"的核心公式，也是后续理解减法几何意义的基础。

## 1.1.2 向量的代数运算与几何可视化

向量之所以能成为线性代数的主角，是因为它定义了一组结构良好的运算。本节核心的两个运算是**加法**与**数乘**，它们共同构成了"线性结构"的全部内容。后续将要学习的线性变换、线性空间、线性组合等概念，其"线性"二字本质上都源自这两条运算规则。

### 加法：分量法则与几何实现

两个 $n$ 维向量 $\mathbf{u} = (u_1, u_2, \ldots, u_n)$ 与 $\mathbf{v} = (v_1, v_2, \ldots, v_n)$ 的加法，按**分量法则**逐项相加：

$$
\mathbf{u} + \mathbf{v} = \begin{bmatrix} u_1 + v_1 \\ u_2 + v_2 \\ \vdots \\ u_n + v_n \end{bmatrix}
$$

代数上极其简单，但几何含义却有两种等价的实现方式，掌握它们对后续理解矩阵乘法至关重要。

**三角形法则**（首尾相连）：把向量 $\mathbf{v}$ 平移，使其起点落在 $\mathbf{u}$ 的终点上，则从 $\mathbf{u}$ 的起点指向 $\mathbf{v}$ 的终点的箭头就是 $\mathbf{u} + \mathbf{v}$。这种"接龙式"的加法在物理中极为常见——多次位移的合成、多个力的依次作用，都遵循三角形法则。当你从家走到医院（向量 $\mathbf{u}$），再从医院走到病房（向量 $\mathbf{v}$），总位移就是 $\mathbf{u} + \mathbf{v}$，与"先回家再绕路到病房"无关。

**平行四边形法则**（同起点）：把 $\mathbf{u}$ 与 $\mathbf{v}$ 平移到同一起点，以它们为邻边作平行四边形，则从公共起点出发的对角线就是 $\mathbf{u} + \mathbf{v}$。这是物理学中"力的合成"的标准画法——两个共点力合成为一个等效力的几何表示。

```python
import numpy as np

u = np.array([2.0, 1.0])
v = np.array([1.0, 2.0])

# 三角形法则 / 平行四边形法则的代数实现都是分量相加
w = u + v
print(f"u + v = {w}")  # 输出 [3. 3.]
```

### 加法运算律的可视化验证

向量加法满足两条关键运算律，它们看起来"显然成立"，但理解其几何含义能为后续学习抽象代数打下基础。

**交换律**：$\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$。几何上，平行四边形的两条邻边无论哪条是 $\mathbf{u}$ 哪条是 $\mathbf{v}$，对角线都是同一条——因为平行四边形的对边平行且相等。这意味着"先走 $\mathbf{u}$ 再走 $\mathbf{v}$"和"先走 $\mathbf{v}$ 再走 $\mathbf{u}$"到达同一个终点。

**结合律**：$(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$。几何上，三个向量首尾相接形成一条折线，无论先合并哪两段，最终从起点指向终点的箭头都是同一个。这条性质使得"多个位移求和"无需关心计算顺序，是后续定义向量级数、矩阵幂级数的基础。

### 减法：同起点连终点

向量减法 $\mathbf{u} - \mathbf{v}$ 的代数定义是分量相减：

$$
\mathbf{u} - \mathbf{v} = \begin{bmatrix} u_1 - v_1 \\ u_2 - v_2 \\ \vdots \\ u_n - v_n \end{bmatrix}
$$

几何上有一个非常实用的口诀：**同起点，连终点，指向被减向量**。把 $\mathbf{u}$ 与 $\mathbf{v}$ 平移到同一起点，从 $\mathbf{v}$ 的终点指向 $\mathbf{u}$ 的终点的箭头就是 $\mathbf{u} - \mathbf{v}$。这条口诀在解析几何中频繁使用——求两点间距离、求方向向量、计算相对位移，本质上都是向量减法。

减法也可以转化为加法：$\mathbf{u} - \mathbf{v} = \mathbf{u} + (-\mathbf{v})$。把 $-\mathbf{v}$ 视为与 $\mathbf{v}$ 反向的向量，然后套用三角形法则即可。这种"转化思维"在数学中极为重要——遇到陌生运算时，先尝试把它转化为已知运算，是解决新问题的通用策略。

### 数乘：分量伸缩法则

向量 $\mathbf{v}$ 与标量 $k$ 的数乘（Scalar Multiplication）定义为：

$$
k \mathbf{v} = \begin{bmatrix} k v_1 \\ k v_2 \\ \vdots \\ k v_n \end{bmatrix}
$$

每个分量都乘以 $k$。几何上，数乘是对向量的"伸缩变换"，根据 $k$ 的取值有三种情形：

- **$|k| > 1$**：向量被**拉伸**，方向不变（若 $k > 0$）或反向（若 $k < 0$）。例如 $2\mathbf{v}$ 是 $\mathbf{v}$ 长度变为 $2$ 倍。
- **$0 < |k| < 1$**：向量被**压缩**，方向同样取决于 $k$ 的符号。例如 $0.5\mathbf{v}$ 是 $\mathbf{v}$ 长度变为 $1/2$。
- **$k < 0$**：向量被**反向**，再按 $|k|$ 伸缩。例如 $-\mathbf{v}$ 是反向不伸缩，$-2\mathbf{v}$ 是反向并拉伸 $2$ 倍。
- **$k = 0$**：得到零向量 $\mathbf{0}$，无论原向量方向如何。

数乘满足几条重要的运算律：$k(\mathbf{u} + \mathbf{v}) = k\mathbf{u} + k\mathbf{v}$（对向量加法的分配律）、$(k + l)\mathbf{v} = k\mathbf{v} + l\mathbf{v}$（对标量加法的分配律）、$k(l\mathbf{v}) = (kl)\mathbf{v}$（结合律）。其中对向量加法的分配律几何意义最为丰富——"先把向量相加再伸缩"与"先分别伸缩再相加"结果相同，这是后续理解线性变换的几何基础。

```python
import numpy as np

v = np.array([1.0, 2.0, 2.0])

# 数乘的各种情形
print(f"2v  = {2 * v}")    # 拉伸 2 倍
print(f"0.5v = {0.5 * v}") # 压缩到 1/2
print(f"-v   = {-v}")      # 反向
print(f"-2v  = {-2 * v}")  # 反向并拉伸
print(f"0v   = {0 * v}")   # 零向量
```

## 1.1.3 向量的度量与空间距离

向量有了，下一步就是"测量"它。本节将定义几种核心的度量：模长、距离、夹角，它们是后续学习范数、距离度量学习、向量相似度的基础。

### 模长：勾股定理的高维推广

向量 $\mathbf{v} = (v_1, v_2, \ldots, v_n)$ 的**模长**（也叫 $\ell_2$ 范数或欧几里得范数）定义为：

$$
\|\mathbf{v}\|_2 = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2} = \sqrt{\sum_{i=1}^{n} v_i^2}
$$

这是勾股定理在 $n$ 维空间的自然延拓。在二维情形中，$\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2}$ 就是从原点到点 $(v_1, v_2)$ 的直线距离；在三维情形中，$\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2 + v_3^2}$ 是空间中一根箭头的长度。模长是向量最重要的"大小"度量，几乎所有后续的归一化、相似度计算、距离比较都建立在它之上。

### L1 范数：曼哈顿距离

除了 $\ell_2$ 范数，还有一种常用度量是 $\ell_1$ 范数（也叫曼哈顿距离或出租车距离）：

$$
\|\mathbf{v}\|_1 = |v_1| + |v_2| + \cdots + |v_n|
$$

它的几何含义是"沿坐标轴走的总路程"。在曼哈顿这样的方格街道上，从一点到另一点的最短路径不是直线距离（$\ell_2$），而是沿街道走的距离（$\ell_1$）。在机器学习中，$\ell_1$ 范数因能产生稀疏解而被广泛用于 Lasso 回归与特征选择——它能自动把不重要的特征系数压到 $0$，从而实现"自动特征筛选"。

### 空间两点间的距离公式

给定点 $A$ 与点 $B$，它们之间的欧几里得距离是"差向量的模长"：

$$
d(A, B) = \|\overrightarrow{AB}\| = \|\mathbf{B} - \mathbf{A}\|_2 = \sqrt{\sum_{i=1}^{n} (B_i - A_i)^2}
$$

这个公式把"两点距离"与"向量模长"统一在一起。理解这一点的关键是：$\mathbf{B} - \mathbf{A}$ 就是从 $A$ 指向 $B$ 的位移向量，它的长度自然就是 $A$ 与 $B$ 之间的距离。在 k-means 聚类、k-近邻算法、推荐系统中，距离公式的选择直接决定算法的行为——选择 $\ell_2$ 范数关注整体偏移，选择 $\ell_1$ 范数关注逐维差异。

### 向量夹角的定义域

两个非零向量 $\mathbf{u}$ 与 $\mathbf{v}$ 之间的夹角 $\theta$ 定义在区间 $[0, \pi]$ 上。为什么是闭区间？因为 $0$ 表示两向量同向（指向同一方向），$\pi$ 表示反向（指向相反方向），所有中间值都对应一个唯一的方向关系。夹角不能超过 $\pi$，因为超过 $\pi$ 的角可以等价表示为 $2\pi - \theta$，方向关系已经反向。

夹角的余弦值 $\cos\theta$ 在 $[-1, 1]$ 之间取值，这个性质将在下一节的点积中扮演核心角色——它直接把"夹角"翻译成了"代数运算"。

### 方向余弦

向量与坐标轴正方向之间的夹角的余弦值，称为**方向余弦**（Direction Cosines）。对于向量 $\mathbf{v} = (v_1, v_2, v_3)$，设它与 $x, y, z$ 轴的夹角分别为 $\alpha, \beta, \gamma$，则：

$$
\cos\alpha = \frac{v_1}{\|\mathbf{v}\|}, \quad \cos\beta = \frac{v_2}{\|\mathbf{v}\|}, \quad \cos\gamma = \frac{v_3}{\|\mathbf{v}\|}
$$

也就是说，方向余弦就是归一化后向量的各个分量。三个方向余弦满足恒等式 $\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$。方向余弦在物理（描述力的方向）、计算机图形学（描述相机朝向）、医学影像（描述切片法向量）中都有广泛应用。

```python
import numpy as np

v = np.array([3.0, 4.0, 12.0])
norm_v = np.linalg.norm(v)  # 13.0

# 方向余弦
cos_alpha, cos_beta, cos_gamma = v / norm_v
print(f"cos α = {cos_alpha:.4f}")  # 0.2308
print(f"cos β  = {cos_beta:.4f}")  # 0.3077
print(f"cos γ = {cos_gamma:.4f}")  # 0.9231

# 验证恒等式
print(f"平方和 = {cos_alpha**2 + cos_beta**2 + cos_gamma**2:.4f}")  # 1.0000
```

## 1.1.4 向量间的乘法：本节的重中之重

本节的核心，也是整个线性代数中最容易被"会用不会懂"的部分。两种向量乘法——**点积**与**叉积**——分别从"方向相似度"和"垂直方向生成"两个角度刻画了向量之间的关系。理解它们的几何本质，比记住公式重要一百倍。

### 点积：代数定义与几何定义

**点积**（Dot Product），又称**内积**（Inner Product）或**数量积**（Scalar Product），是两个向量之间最基础的一种乘法。它的代数定义是"对应分量乘积之和"：

$$
\mathbf{u} \cdot \mathbf{v} = u_1 v_1 + u_2 v_2 + \cdots + u_n v_n = \sum_{i=1}^{n} u_i v_i
$$

注意点积的结果是一个**标量**（一个数），而不是向量。这是"数量积"名称的由来。

点积的**几何定义**则更具洞察力：

$$
\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\| \|\mathbf{v}\| \cos\theta
$$

其中 $\theta$ 是两向量的夹角。这个公式把"长度"和"角度"两个几何量压缩成一个数，是线性代数中最优雅的公式之一。它告诉我们：**点积同时编码了长度信息和方向信息**——只看一个点积值，你就能反推两向量的夹角。

代数定义与几何定义的等价性是线性代数的一个基本定理，它的证明依赖于余弦定理，这里不再展开。重要的是要建立"代数—几何"双向直觉：看到 $\mathbf{u} \cdot \mathbf{v}$ 就同时想到"分量乘积之和"和"长度乘夹角余弦"。

### 投影：点积的几何本质

点积最深刻的几何意义是**投影**。给定两个向量 $\mathbf{a}$ 与 $\mathbf{b}$，把 $\mathbf{a}$ 沿 $\mathbf{b}$ 的方向"压扁"下来，得到 $\mathbf{a}$ 在 $\mathbf{b}$ 上的投影。

**标量投影**（也叫投影长度）的公式是：

$$
\text{comp}_{\mathbf{b}} \mathbf{a} = \|\mathbf{a}\| \cos\theta = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{b}\|}
$$

它表示 $\mathbf{a}$ 在 $\mathbf{b}$ 方向上的"有效长度"。当 $\theta$ 为锐角时投影为正，钝角时为负，垂直时为零。

**向量投影**（Projection Vector）则把标量投影转化为一个向量——方向沿 $\mathbf{b}$，长度为标量投影：

$$
\text{proj}_{\mathbf{b}} \mathbf{a} = \frac{\mathbf{a} \cdot \mathbf{b}}{\mathbf{b} \cdot \mathbf{b}} \mathbf{b} = \left( \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{b}\|^2} \right) \mathbf{b}
$$

推导过程非常自然：先求出标量投影 $\mathbf{a} \cdot \mathbf{b} / \|\mathbf{b}\|$，再乘以 $\mathbf{b}$ 方向的单位向量 $\mathbf{b} / \|\mathbf{b}\|$，合并分母即得上式。投影是后续理解"最小二乘法"、"傅里叶级数"、"主成分分析"的几何基础——它们本质上都是"把向量投影到某个子空间"。

### 点积的运算律

点积满足三条重要的运算律，理解它们的几何含义比记住公式更重要。

**交换律**：$\mathbf{u} \cdot \mathbf{v} = \mathbf{v} \cdot \mathbf{u}$。几何上，$\mathbf{u}$ 在 $\mathbf{v}$ 上的投影长度乘以 $\|\mathbf{v}\|$，与 $\mathbf{v}$ 在 $\mathbf{u}$ 上的投影长度乘以 $\|\mathbf{u}\|$，结果是同一个数——因为两者都等于 $\|\mathbf{u}\|\|\mathbf{v}\|\cos\theta$。

**分配律**：$\mathbf{u} \cdot (\mathbf{v} + \mathbf{w}) = \mathbf{u} \cdot \mathbf{v} + \mathbf{u} \cdot \mathbf{w}$。几何上，"和向量在 $\mathbf{u}$ 上的投影"等于"两个向量分别在 $\mathbf{u}$ 上投影之和"。这是投影线性性的体现，也是后续定义线性变换的关键。

**数乘结合律**：$(k\mathbf{u}) \cdot \mathbf{v} = k(\mathbf{u} \cdot \mathbf{v})$。几何上，把 $\mathbf{u}$ 拉伸 $k$ 倍，其投影长度也变为 $k$ 倍，因此点积变为 $k$ 倍。

### 柯西-施瓦茨不等式

点积几何定义的一个直接推论是**柯西-施瓦茨不等式**（Cauchy-Schwarz Inequality）：

$$
|\mathbf{u} \cdot \mathbf{v}| \leq \|\mathbf{u}\| \|\mathbf{v}\|
$$

这个不等式看似抽象，但其几何解释极为直观：因为 $|\cos\theta| \leq 1$，所以 $|\mathbf{u} \cdot \mathbf{v}| = \|\mathbf{u}\|\|\mathbf{v}\||\cos\theta|$ 一定不超过 $\|\mathbf{u}\|\|\mathbf{v}\|$。等号成立的条件是 $|\cos\theta| = 1$，即两向量共线（同向或反向）。

柯西-施瓦茨不等式是数学中最重要的不等式之一，它在泛函分析、概率论、量子力学中都有深远影响。在机器学习中，它是证明余弦相似度取值范围 $[-1, 1]$ 的理论基础，也是 SVM 推导中的关键工具。

### 利用点积判定正交

点积最重要的应用之一是判定**正交**（垂直）关系。由几何定义 $\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|\|\mathbf{v}\|\cos\theta$ 可知：

- 若 $\mathbf{u} \cdot \mathbf{v} = 0$ 且 $\mathbf{u}, \mathbf{v}$ 均非零，则 $\cos\theta = 0$，即 $\theta = \pi/2$，两向量**正交**。
- 若 $\mathbf{u} \cdot \mathbf{v} > 0$，则 $\theta$ 为锐角，两向量"方向相近"。
- 若 $\mathbf{u} \cdot \mathbf{v} < 0$，则 $\theta$ 为钝角，两向量"方向相反"。
- 若 $\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|\|\mathbf{v}\|$，则 $\theta = 0$，两向量同向。

**"点积为零即正交"**这条性质是整个线性代数中最高频使用的结论之一。它把"几何垂直"翻译成了"代数零"，使得"判定垂直"变成了一次简单的乘加运算。后续学习正交矩阵、Gram-Schmidt 正交化、QR 分解时，这条性质都会反复出现。

### 叉积：二阶与三阶

**叉积**（Cross Product），又称**向量积**（Vector Product），是仅在三维（及二维退化情形）中定义的运算。与点积不同，叉积的结果是一个**向量**，而非标量。

**二维叉积**（也叫二维外积）的结果是标量。对于 $\mathbf{u} = (u_1, u_2)$ 与 $\mathbf{v} = (v_1, v_2)$：

$$
\mathbf{u} \times \mathbf{v} = u_1 v_2 - u_2 v_1
$$

它的几何意义是两向量张成的平行四边形的**有向面积**——正负号表示 $\mathbf{v}$ 在 $\mathbf{u}$ 的左侧还是右侧。

**三维叉积**的结果是向量。对于 $\mathbf{u} = (u_1, u_2, u_3)$ 与 $\mathbf{v} = (v_1, v_2, v_3)$，利用行列式记法：

$$
\mathbf{u} \times \mathbf{v} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ u_1 & u_2 & u_3 \\ v_1 & v_2 & v_3 \end{vmatrix} = (u_2 v_3 - u_3 v_2)\mathbf{i} - (u_1 v_3 - u_3 v_1)\mathbf{j} + (u_1 v_2 - u_2 v_1)\mathbf{k}
$$

这个行列式记法只是助记工具——第一行是基向量，第二行是 $\mathbf{u}$ 的分量，第三行是 $\mathbf{v}$ 的分量，按第一行展开就得到上述公式。

### 叉积的几何意义：法向量与面积

叉积最重要的几何性质有两条：

**第一，方向**：$\mathbf{u} \times \mathbf{v}$ 垂直于 $\mathbf{u}$ 与 $\mathbf{v}$ 所张成的平面。具体指向哪个方向由**右手定则**（Right-hand Rule）决定——右手四指从 $\mathbf{u}$ 转向 $\mathbf{v}$（转角小于 $180°$），大拇指所指方向就是 $\mathbf{u} \times \mathbf{v}$ 的方向。这条性质使得叉积成为"由两个向量生成垂直向量"的标准工具，在物理（力矩、电磁力）、计算机图形学（法向量计算）中至关重要。

**第二，模长**：$\|\mathbf{u} \times \mathbf{v}\| = \|\mathbf{u}\|\|\mathbf{v}\|\sin\theta$，恰好等于两向量张成的平行四边形的面积。这一性质把"面积计算"转化为"叉积求模"，是解析几何中的常用技巧。如果两向量共线（$\theta = 0$ 或 $\pi$），则 $\sin\theta = 0$，叉积为零向量——这是判定三维向量共线的充要条件。

### 叉积的运算律

叉积的运算律与点积有重要区别，需要特别注意。

**反交换律**（Anticommutativity）：$\mathbf{u} \times \mathbf{v} = -(\mathbf{v} \times \mathbf{u})$。注意这里的负号！交换叉积顺序会改变结果方向。几何上，从 $\mathbf{u}$ 转向 $\mathbf{v}$ 与从 $\mathbf{v}$ 转向 $\mathbf{u}$ 是反方向旋转，因此右手定则给出的大拇指方向相反。这与点积的交换律形成鲜明对比——点积交换无影响，叉积交换要加负号。

**分配律**：$\mathbf{u} \times (\mathbf{v} + \mathbf{w}) = \mathbf{u} \times \mathbf{v} + \mathbf{u} \times \mathbf{w}$。这条性质使得叉积对加法可分配，是后续理解叉积矩阵、李代数等高级概念的基础。

**不满足结合律**：$\mathbf{u} \times (\mathbf{v} \times \mathbf{w}) \neq (\mathbf{u} \times \mathbf{v}) \times \mathbf{w}$。这是叉积与"普通乘法"最大的差异，使用时务必注意括号位置。

```python
import numpy as np

u = np.array([1.0, 0.0, 0.0])  # x 方向单位向量
v = np.array([0.0, 1.0, 0.0])  # y 方向单位向量

# 叉积：x × y = z
cross = np.cross(u, v)
print(f"u × v = {cross}")  # 输出 [0. 0. 1.]，即 z 方向

# 反交换律验证
print(f"v × u = {np.cross(v, u)}")  # 输出 [0. 0. -1.]

# 模长 = 平行四边形面积
area = np.linalg.norm(cross)
print(f"面积 = {area}")  # 输出 1.0
```

### 混合积：平行六面体的有向体积

把点积与叉积结合，就得到**混合积**（Scalar Triple Product）：

$$
[\mathbf{u}, \mathbf{v}, \mathbf{w}] = \mathbf{u} \cdot (\mathbf{v} \times \mathbf{w})
$$

混合积的几何意义极为优雅——它等于三个向量张成的**平行六面体的有向体积**。叉积 $\mathbf{v} \times \mathbf{w}$ 给出底面的法向量（其模长是底面积），再与 $\mathbf{u}$ 点积就得到 $\mathbf{u}$ 在法向量方向上的投影长度，乘积即为"底面积 × 高"。

混合积为零，当且仅当三个向量共面（它们张成的平行六面体"压扁"成平面，体积为零）。这是判定三向量共面的标准方法，也是后续理解行列式几何意义（"行列式即体积"）的入门。

## 1.1.5 向量的组合与空间的初步构建

本节是从"单向量"向"向量空间"过渡的桥梁。前面讨论的都是单个向量或两个向量之间的关系，从这里开始，我们要把视角提升到"一组向量如何构成空间"。这种视角的转换，是从"算术"进入"代数"的关键一步。

### 线性组合

给定一组向量 $\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_k$ 和一组标量 $c_1, c_2, \ldots, c_k$，表达式

$$
c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \cdots + c_k \mathbf{v}_k
$$

称为这些向量的**线性组合**（Linear Combination）。线性组合是线性代数最基础的结构——它把"加法"和"数乘"两种运算结合起来，构造出无穷多个新向量。

线性组合在工程中无处不在。在机器学习中，神经网络的一层就是输入特征的线性组合加上偏置；在信号处理中，傅里叶级数把任意信号表示为正弦波的线性组合；在统计学中，主成分分析把高维数据表示为若干主成分的线性组合。理解线性组合，就理解了线性代数的"加法—数乘"二件套如何在工程中发挥作用。

### 张成：从向量到空间

把一个向量组的**所有可能的线性组合**构成的集合，称为这个向量组的**张成空间**（Span），记作 $\text{span}(\mathbf{v}_1, \ldots, \mathbf{v}_k)$。

**单个非零向量**的张成是一条过原点的直线。因为 $c\mathbf{v}$（$c \in \R$）取遍所有实数时，箭头终点在过原点沿 $\mathbf{v}$ 方向的直线上移动。无论 $c$ 是正、负还是零，终点都落在这条直线上。

**两个不共线向量**的张成是一个过原点的平面。因为 $c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2$ 取遍所有 $(c_1, c_2)$ 时，箭头终点扫过整个由 $\mathbf{v}_1, \mathbf{v}_2$ 决定的平面。如果两向量共线，则张成退化为一根直线——这是后续"线性相关"的雏形。

**三个不共面向量**的张成是整个三维空间。因为三个独立方向足以"够到"空间中任何一点。如果三个向量共面，则张成退化为一张平面——它们提供不了第三个独立方向。

<div class="admonition key-idea">
<p class="title">张成的直觉</p>
<p>张成回答了一个核心问题："用这些向量能走到哪些地方？" 在二维平面中，单个向量只能让你在一条直线上移动；两个不共线向量能让你走到平面任何一点。向量组提供的"独立方向数"决定了张成空间的维度——这正是后续"秩"概念的几何原型。</p>
</div>

### 线性相关与线性无关

一个向量组如果存在一组**不全为零**的标量 $c_1, c_2, \ldots, c_k$，使得

$$
c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \cdots + c_k \mathbf{v}_k = \mathbf{0}
$$

则称这组向量**线性相关**（Linearly Dependent）。否则称为**线性无关**（Linearly Independent）。

线性相关的几何直觉是：**至少有一个向量可以表示为其他向量的线性组合**——它在某种意义上是"多余的"，去掉它不会减少张成空间。线性无关则意味着每个向量都提供了独立的"方向贡献"，缺一不可。

- **两个向量共线**（一个能表示为另一个的数倍）→ 线性相关
- **三个向量共面**（一个能表示为另两个的线性组合）→ 线性相关
- **向量组线性无关** → 每个向量都"指出一个新的方向"

### 共线定理与共面定理

**共线定理**：两个向量 $\mathbf{u}, \mathbf{v}$ 共线（同向或反向），当且仅当存在实数 $k$ 使得 $\mathbf{u} = k\mathbf{v}$。这是"两向量线性相关"的最简形式。判定方法：叉积为零（三维情形）或对应分量比例相等（任意维情形）。

**共面向量定理**：三个向量 $\mathbf{u}, \mathbf{v}, \mathbf{w}$ 共面，当且仅当其中一个能表示为另两个的线性组合。判定方法：混合积为零（三维情形），即 $\mathbf{u} \cdot (\mathbf{v} \times \mathbf{w}) = 0$。

这两条定理在解析几何中频繁使用——判断空间中三点是否共线、四点是否共面、直线与平面是否平行，本质上都是共线/共面判定。它们也是后续学习"线性方程组解的结构"和"矩阵的秩"的几何入口。

```python
import numpy as np

# 共线判定
u = np.array([1.0, 2.0, 3.0])
v = np.array([2.0, 4.0, 6.0])  # u 的 2 倍，共线
print(f"u × v = {np.cross(u, v)}")  # 输出 [0. 0. 0.]，共线判定通过

# 共面判定
a = np.array([1.0, 0.0, 0.0])
b = np.array([0.0, 1.0, 0.0])
c = np.array([1.0, 1.0, 0.0])  # a + b，与 a, b 共面
mixed = np.dot(a, np.cross(b, c))
print(f"混合积 = {mixed}")  # 输出 0.0，共面判定通过

# 线性无关判定（通过矩阵秩）
import numpy.linalg as la
M = np.column_stack([a, b, np.array([0.0, 0.0, 1.0])])
rank = la.matrix_rank(M)
print(f"秩 = {rank}")  # 输出 3，三个向量线性无关
```
