# 1.7 奇异值分解（SVD）

<span class="chapter-tag">第一章 · 线性代数</span>

> 本章节正在建设中，将在 1.1 验收通过后批量铺开。

## 预计内容

- SVD 的定义 $A = U \Sigma V^\top$
- 几何解释：任意线性变换 = 旋转 → 缩放 → 旋转
- SVD 与特征分解的关系
- 截断 SVD 与低秩近似
- 工程应用：图像压缩、推荐系统、潜在语义分析（LSA）
