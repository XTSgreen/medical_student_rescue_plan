# 深度学习

本模块是《从问题到模型：深度学习经典论文精讲》视频系列的配套教程。每一集对应一章，围绕该集所依据的原始论文展开：先说明论文面对的问题，再给出其中的定义、推导与结论，最后用可运行的代码核验每一个数值环节。

教程与视频共用同一组数据、同一套符号和同一批计算结果，读者可以逐项对照。

## 第二季与第三季

第二季从分类走向定位、分割、视觉 token、语言模型、规模律、自监督、多模态与指令对齐，共 8 集。第三季从生成模型走向强化学习与具身智能，共 8 集。两季的章目在对应视频进入制作阶段后补齐。

## 体例

每一章按同一套结构组织。

1. 导言给出该集面对的具体问题，并说明它与前一章的联系。
2. 正文以定义、命题与证明的方式展开，术语第一次出现时给出可操作的解释。
3. 代码验证给出可以独立运行的脚本，输出与视频使用的计算结果逐项一致。
4. 练习题与参考答案用于检查对定义和推导的掌握。
5. 常见错误列出初学者在该主题上最容易出现的误解。

各章只使用该集视频已经出现的数学工具。尚未引入的概念以链接形式指向数学模块的对应章节。
