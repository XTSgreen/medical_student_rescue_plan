# 命令行任务管理器（Task Manager）

这是一个贯穿整个 Python 核心语法教程的渐进式项目：**命令行任务管理器（Task Manager）**。随着每章知识点的学习，这个项目会逐步从最简单的"Hello World"演变为一个支持增删改查、文件持久化、模块化结构的完整程序。

项目演进路线：

- 第1章（开发环境）：搭建环境，写出第一个 Python 脚本
- 第2章（语法与数据类型）：用变量和字符串存储单条任务信息
- 第3章（控制结构）：实现菜单交互、条件判断、循环操作
- 第4章（组合数据类型）：用列表存储多条任务，用字典存储任务详情
- 第5章（函数与模块化）：将代码拆分为函数和模块
- 第6章（文件与异常处理）：将任务保存到文件，处理各种异常

每个阶段的完整代码放在对应的 stage 文件中。
