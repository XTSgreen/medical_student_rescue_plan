# 4.8 组合数据类型的构造与类型转换


构造组合数据类型有多种途径，包括字面量、构造器以及类型之间的转换。掌握这些构造方式和转换规则，能让代码在不同场景下选择最合适的写法。本节将系统介绍列表、元组、字典、集合的构造方法，以及类型之间转换的常见模式与注意事项，帮助你写出更简洁、更高效的代码。

## 4.8.1 使用字面量直接构造

最直接的构造方式是使用**字面量**。列表用方括号 `[]`，元组用圆括号 `()`，字典用花括号 `{key: value}`，集合用花括号 `{elem1, elem2}`。字面量写法直观，适合元素已知且数量不多的场景。

```python
# 列表字面量
fruits = ["apple", "banana", "cherry"]

# 元组字面量
point = (3, 4)

# 字典字面量
prices = {"apple": 5, "banana": 3}

# 集合字面量
tags = {"vip", "new", "active"}

print(type(fruits), type(point), type(prices), type(tags))
# <class 'list'> <class 'tuple'> <class 'dict'> <class 'set'>
```

需要注意两点。其一，空花括号 `{}` 是空字典而非空集合，创建空集合必须用 `set()`。其二，单元素元组必须加逗号 `(1,)`，否则 `(1)` 只是被括号包裹的整数 1。字面量适合初始化静态数据，元素动态生成时应改用构造器。

## 4.8.2 使用类型构造器

每种内置类型都有对应的**构造器**，无参数调用时返回空容器。`list()` 返回空列表，`tuple()` 返回空元组，`dict()` 返回空字典，`set()` 返回空集合，`frozenset()` 返回空的冻结集合。

```python
empty_list = list()
empty_tuple = tuple()
empty_dict = dict()
empty_set = set()
empty_frozenset = frozenset()

print(empty_list, empty_tuple, empty_dict, empty_set, empty_frozenset)
# [] () {} set() frozenset()
```

构造器更重要的用途是接受可迭代对象进行转换，下一节起会逐一介绍。在需要先创建空容器再逐步填充的场景下，构造器比字面量更明确地表达了创建空容器的意图。

## 4.8.3 从字符串构造列表

字符串是可迭代对象，每个元素是一个字符。用 `list()` 转换字符串时，会得到一个字符列表。

```python
chars = list("abc")
print(chars)  # ['a', 'b', 'c']

words = list("hello")
print(words)  # ['h', 'e', 'l', 'l', 'o']
```

如果希望按单词而非字符切分，应先调用字符串的 `split()` 方法，再转换。例如 `list("a b c".split())` 得到 `['a', 'b', 'c']`。直接 `list("a b c")` 会得到 `['a', ' ', 'b', ' ', 'c']`，包含空格字符。区分这两种写法在处理文本数据时很重要。

## 4.8.4 从列表构造元组

`tuple()` 接受可迭代对象，返回包含所有元素的元组。从列表构造元组是常见的**冻结**操作，把可变数据转为不可变形式。

```python
lst = [1, 2, 3]
t = tuple(lst)
print(t)  # (1, 2, 3)
print(type(t))  # <class 'tuple'>

# 从字符串构造元组同理
t2 = tuple("ab")
print(t2)  # ('a', 'b')
```

元组创建后不能修改，适合作为字典键、集合元素或函数返回多个值。把列表转元组常用于需要不可变性的场景，比如把配置数据固化下来防止误改。

## 4.8.5 从键值对序列构造字典

`dict()` 接受一个**键值对序列**，每个元素是包含两个元素的序列（如元组、列表），第一个元素作为键，第二个作为值。

```python
pairs = [(1, "a"), (2, "b"), (3, "c")]
d = dict(pairs)
print(d)  # {1: 'a', 2: 'b', 3: 'c'}

# 也可以用列表的列表
d2 = dict([["x", 10], ["y", 20]])
print(d2)  # {'x': 10, 'y': 20}
```

这种构造方式在处理成对数据时非常方便，比如从数据库查询结果的两列构造映射表。如果序列中有重复键，后出现的会覆盖先出现的，与字面量中重复键的规则一致。

## 4.8.6 从关键字参数构造字典

`dict()` 还接受**关键字参数**，每个关键字成为字典的键，对应的值成为字典的值。这种写法适合键是合法标识符（如字符串且符合命名规则）的场景。

```python
d = dict(a=1, b=2, c=3)
print(d)  # {'a': 1, 'b': 2, 'c': 3}
```

关键字参数的键自动作为字符串，不需要加引号。但这也限制了键必须是合法的 Python 标识符，不能含空格、特殊字符或以数字开头。`dict(1="a")` 会报语法错误，这种情况下应改用键值对序列或字面量。两种构造方式可以混用，`dict([("x", 1)], y=2)` 得到 `{'x': 1, 'y': 2}`。

## 4.8.7 从两个列表组合构造字典

实际开发中常有两个平行列表，一个存键、一个存值，需要合并成字典。这时配合 `zip()` 函数和 `dict()` 构造器可以一行完成。

```python
keys = ["name", "age", "city"]
values = ["Alice", 30, "Beijing"]

d = dict(zip(keys, values))
print(d)  # {'name': 'Alice', 'age': 30, 'city': 'Beijing'}
```

`zip(keys, values)` 把两个列表按位置配对，生成 `("name", "Alice")`、`("age", 30)` 等元组的迭代器，再交给 `dict()` 即可。两个列表长度不一致时，`zip()` 会在较短的一方结束时停止，多余的元素被忽略。如果想用默认值填充缺失项，可以用 `itertools.zip_longest()`。

## 4.8.8 从可迭代对象构造集合

`set()` 接受任意可迭代对象，自动去除重复元素，得到唯一元素的集合。

```python
lst = [1, 2, 2, 3, 3, 3, 4]
s = set(lst)
print(s)  # {1, 2, 3, 4}

# 从字符串构造集合，得到唯一字符
chars = set("hello")
print(chars)  # {'h', 'e', 'l', 'o'}，顺序不定
```

去重是集合最常见的用途。从列表去重时要注意结果顺序不定，如果需要保留原始顺序，应配合 `dict.fromkeys()` 使用。集合本身无序，不能保证构造后元素的遍历顺序与输入一致。

## 4.8.9 类型转换时的可哈希检查

转换成字典的键或集合的元素时，元素必须**可哈希**。可哈希意味着对象在其生命周期内哈希值不变，即不可变类型。数字、字符串、元组可哈希，列表、字典、集合不可哈希。

```python
# 合法：元组作为字典键
d = {(1, 2): "point", (3, 4): "point2"}
print(d[(1, 2)])  # point

# 合法：元组作为集合元素
s = {(1, 2), (3, 4)}
print(s)  # {(1, 2), (3, 4)}
```

```python
# 非法：列表作为字典键
d = {[1, 2]: "value"}  # TypeError: unhashable type: 'list'

# 非法：列表作为集合元素
s = {[1, 2]}  # TypeError: unhashable type: 'list'
```

如果数据本身是可变结构但需要作为键或集合元素，可以先转成不可变形式。例如把嵌套列表 `[[1, 2], [3, 4]]` 转成元组的元组 `((1, 2), (3, 4))` 就能作为集合元素。这一限制背后的原理是哈希表结构，可变对象的哈希值会随内容变化而失效，无法稳定查找。

## 4.8.10 zip 函数在组合构造中的使用

`zip()` 是组合构造的核心工具之一，它把多个可迭代对象按位置打包成元组序列。在字典构造（见 4.8.7）、并行遍历、矩阵转置等场景中大量使用。`zip()` 返回的是迭代器，一次性消费，需要重复使用时应先转成列表。`zip(*matrix)` 还能实现矩阵转置，是函数式编程中的经典写法。

## 4.8.11 解包运算符 * 在列表和元组构造中的作用

**星号解包运算符** `*` 可以把可迭代对象展开，嵌入到列表或元组字面量中。这在组合多个可迭代对象时非常方便，比 `+` 拼接更灵活。

```python
a = [1, 2]
b = [3, 4]

# 用 * 展开并组合
combined = [0, *a, *b, 5]
print(combined)  # [0, 1, 2, 3, 4, 5]

# 元组中同样适用
t = (*a, *b)
print(t)  # (1, 2, 3, 4)

# 展开字符串
chars = [*"ab", *"cd"]
print(chars)  # ['a', 'b', 'c', 'd']
```

`*a` 会把 `a` 中的每个元素依次取出，嵌入到新列表的对应位置。这种写法可以混合多个不同类型的可迭代对象，比 `a + b` 更通用，因为 `+` 要求两边类型一致。`*` 还能用在函数调用时解包参数，例如 `func(*args)`。

## 4.8.12 解包运算符 ** 在字典构造中的作用

**双星号解包运算符** `**` 用于展开字典的键值对，嵌入到新字典中。这是合并字典的简洁写法，尤其在 Python 3.5 之后广泛使用。

```python
base = {"a": 1, "b": 2}
extra = {"c": 3, "d": 4}

merged = {**base, **extra}
print(merged)  # {'a': 1, 'b': 2, 'c': 3, 'd': 4}

# 也可以混入字面量键值对
mixed = {**base, "x": 0}
print(mixed)  # {'a': 1, 'b': 2, 'x': 0}
```

当多个字典有相同键时，后展开的会覆盖先展开的。`{**base, **extra}` 中 `extra` 的同名键会覆盖 `base`。Python 3.9+ 还引入了 `|` 运算符合并字典，`base | extra` 效果类似，但 `**` 写法在更早版本就能用，且更灵活，能混入任意键值对。

## 4.8.13 列表与元组之间的转换效率差异

列表与元组之间的转换会创建新对象，复制所有元素。从列表转元组（`tuple(lst)`）开销与列表长度成正比，因为要遍历列表并构造新元组。反向转换（`list(tup)`）同理。由于元组不可变，CPython 会对元组做某些优化，比如缓存空元组和单元素元组，但通用转换仍需线性时间。在性能敏感的循环中反复转换同一数据是不良实践，应在循环外一次性确定数据结构。日常使用中这种转换开销通常可以忽略，但在大规模数据处理时需要留意。

::: note 构造方式的选择
元素已知且数量少时用字面量最直观，元素来自其他可迭代对象时用构造器更合适，需要合并多个来源时优先考虑解包运算符 `*` 和 `**`。类型转换前要确认元素满足目标类型的要求，比如转字典键或集合元素时必须可哈希。
:::

## 练习题

### 第 1 题：写出下列类型构造与转换的输出结果

阅读下面这段代码，在不运行的情况下写出它的输出。

```python
print(list("abc"))
print(tuple([1, 2, 3]))
print(set([1, 2, 2, 3]))
print(dict([("x", 1), ("y", 2)]))
print(type({}))
print(type(set()))
```

::: details 参考答案
输出如下：

```
['a', 'b', 'c']
(1, 2, 3)
{1, 2, 3}
{'x': 1, 'y': 2}
<class 'dict'>
<class 'set'>
```

`list("abc")` 把字符串按字符拆成列表，`tuple([1, 2, 3])` 把列表转成元组，`set([1, 2, 2, 3])` 去重得到集合，`dict([...])` 从键值对序列构造字典。空花括号 `{}` 是空字典而非空集合，空集合必须用 `set()` 创建，这是构造时最容易混淆的一点。
:::

### 第 2 题：用 zip 和 dict 从两个列表构造字典

给定两个列表 `keys = ["name", "age", "city"]` 和 `values = ["Alice", 30, "Beijing"]`，请用 `zip()` 和 `dict()` 一行构造字典，并打印结果。再思考：如果两个列表长度不一致会发生什么？

::: details 参考答案
```python
keys = ["name", "age", "city"]
values = ["Alice", 30, "Beijing"]

d = dict(zip(keys, values))
print(d)
```

输出 `{'name': 'Alice', 'age': 30, 'city': 'Beijing'}`。

`zip(keys, values)` 把两个列表按位置配对成元组迭代器，`dict()` 把这些元组转成键值对。两个列表长度不一致时，`zip()` 会在较短的一方结束时停止，多余元素被忽略。比如 `zip(["a", "b"], [1, 2, 3])` 只产出 `("a", 1)` 和 `("b", 2)`，3 被丢弃。需要保留所有元素时可以用 `itertools.zip_longest` 配合默认值填充。
:::

### 第 3 题：用解包运算符合并列表和字典

给定两个列表 `a = [1, 2]`、`b = [3, 4]` 和两个字典 `base = {"x": 1, "y": 2}`、`extra = {"y": 3, "z": 4}`，请用 `*` 运算符把两个列表合并成一个新列表 `[0, 1, 2, 3, 4, 5]`，用 `**` 运算符把两个字典合并成一个新字典，并解释相同键的处理方式。

::: details 参考答案
```python
a = [1, 2]
b = [3, 4]

combined_list = [0, *a, *b, 5]
print(combined_list)

base = {"x": 1, "y": 2}
extra = {"y": 3, "z": 4}

merged_dict = {**base, **extra}
print(merged_dict)
```

输出：

```
[0, 1, 2, 3, 4, 5]
{'x': 1, 'y': 3, 'z': 4}
```

`*a` 和 `*b` 把列表元素展开嵌入新列表，可以混入任意字面量元素，比 `+` 拼接更灵活。`**base` 和 `**extra` 把字典的键值对展开嵌入新字典，遇到相同键时后展开的覆盖先展开的，所以 `extra` 的 `y: 3` 覆盖了 `base` 的 `y: 2`。这种写法在合并配置、覆盖默认值时非常常用。
:::

### 第 4 题：项目练习题（命令行任务管理器）

命令行任务管理器需要从两个平行列表构造任务字典：`names = ["写文档", "测试", "部署"]` 是任务名，`priorities = ["high", "medium", "low"]` 是对应优先级。请用 `zip()` 和 `dict()` 构造任务名到优先级的映射，并用 `**` 解包把默认配置 `{"status": "todo"}` 合并进每个任务的完整配置中，最终打印每个任务的完整信息。

::: details 参考答案
```python
names = ["写文档", "测试", "部署"]
priorities = ["high", "medium", "low"]

priority_map = dict(zip(names, priorities))

default = {"status": "todo"}

tasks = []
for name, priority in priority_map.items():
    task = {**default, "name": name, "priority": priority}
    tasks.append(task)

for task in tasks:
    print(task)
```

输出：

```
{'status': 'todo', 'name': '写文档', 'priority': 'high'}
{'status': 'todo', 'name': '测试', 'priority': 'medium'}
{'status': 'todo', 'name': '部署', 'priority': 'low'}
```

`dict(zip(names, priorities))` 把两个平行列表合成任务名到优先级的映射。`{**default, "name": name, "priority": priority}` 用 `**` 展开默认配置，再混入任务名和优先级，构造出完整的任务字典。这种写法让默认值与动态值组合非常直观，任务管理器初始化任务、合并用户输入与默认配置时都会用到。
:::

## 常见错误

**错误 1 · `type({})` 返回 `<class 'dict'>`，空花括号不是空集合**

原因:空花括号 `{}` 在 Python 中被解释为空字典，字面量层面没有空集合的写法。误用 `{}` 创建空集合会导致后续集合操作抛出 `AttributeError`。

解决:创建空集合必须用 `set()`。非空集合可用花括号字面量 `{1, 2, 3}`。

**错误 2 · `list("a b c")` 得到 `['a', ' ', 'b', ' ', 'c']` 而非单词列表**

原因:`list()` 把字符串按字符拆分，空格也是字符，会被当作元素保留。期望按单词切分时直接用 `list()` 会得到含空格的字符列表。

解决:按单词切分先调用 `split()`：`list("a b c".split())` 得到 `['a', 'b', 'c']`。按字符切分用 `list(s)`。

**错误 3 · `zip()` 长度不一致时静默丢弃较长列表的多余元素**

原因:`zip()` 在较短的可迭代对象结束时停止，较长一方的剩余元素被忽略，不报错也不提示。数据长度不一致时会导致配对结果少于预期。

解决:确认两侧长度一致再调用 `zip()`，或用 `itertools.zip_longest(iter1, iter2, fillvalue=...)` 用默认值填充缺失项。

**错误 4 · `dict(1="a")` 抛出 `SyntaxError`**

原因:`dict()` 的关键字参数形式要求键是合法的 Python 标识符，不能以数字开头、含空格或特殊字符。数字开头的键无法作为关键字参数传入。

解决:键不符合标识符规则时改用键值对序列构造：`dict([("1", "a")])` 或字面量 `{"1": "a"}`。键是合法标识符时才用关键字参数形式 `dict(a=1)`。
