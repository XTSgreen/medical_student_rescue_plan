# 2.1 变量、常量与赋值机制

变量是 Python 管理数据的最基本单位。本节将从变量的定义、命名、赋值机制一直讲到对象引用模型，这些内容是理解后续所有语法的基础。理解了变量与对象的关系，你才能解释为什么修改一个列表会意外影响另一个列表，为什么有些函数调用会改变传入的参数而有些不会。

## 2.1.1 变量定义（变量名 = 值）

Python 中定义变量的写法极其简洁，直接使用 `变量名 = 值` 的形式即可。等号左侧是变量名，右侧是要存储的值，解释器执行这一行时会在内存中创建对应的数据对象，然后把变量名关联到这个对象上。这种写法不需要提前声明变量类型，也不需要指定变量的存储空间，解释器会根据右侧值的类型自动处理。

```python
# 定义几个变量
user_name = "张三"
age = 45
price = 120.5
is_active = True

print(user_name)      # 张三
print(age)            # 45
print(price)          # 120.5
print(is_active)      # True
```

上述代码中，`user_name` 关联到一个字符串对象，`age` 关联到一个整数对象，`price` 关联到一个浮点数对象，`is_active` 关联到一个布尔对象。每个变量名都像一张贴在箱子上的标签，标签本身不是箱子里的物品，只是标记物品所在的位置。这种**标签贴对象**的模型在后面讲对象引用时会详细展开。

## 2.1.2 变量命名规则（字母、数字、下划线，首字符不能为数字）

变量命名有几条硬性规则，违反这些规则会直接导致语法错误，代码根本无法运行。这些规则是 Python 解释器强制检查的，属于语法层面的约束。

变量名只能由字母、数字和下划线组成，不能包含空格、连字符、特殊符号（如 `@`、`$`、`%`）。首字符必须是字母或下划线，不能是数字。变量名区分大小写，`age`、`Age`、`AGE` 是三个完全不同的变量。变量名不能与 Python 的保留字冲突，保留字列表稍后会给出。

```python
# 合法的变量名
user_id = "U001"
score = 75
_status = "active"
BUF2 = 1024

# 非法的变量名（取消注释会导致 SyntaxError）
# 2user = "张三"        # 首字符是数字
# blood-pressure = 120  # 包含连字符
# heart rate = 75       # 包含空格
# @name = "李四"        # 包含特殊符号
```

下划线开头的变量名有特殊含义。单下划线开头（如 `_data`）表示内部使用的变量，按约定不应该在外部访问；双下划线开头且结尾（如 `__init__`）是 Python 的魔术方法或属性，不要自己发明这类名字。初学阶段避开这些特殊命名方式即可。

## 2.1.3 变量命名规范（PEP 8：小写字母，单词间用下划线分隔）

命名规则是语法层面的强制要求，命名规范则是社区约定，违反规范不会报错，但会让代码难以阅读和维护。Python 官方的 PEP 8 风格指南对变量命名给出了明确建议：变量名使用小写字母，单词之间用下划线分隔，这种风格称为 snake_case（蛇形命名）。

```python
# 符合 PEP 8 规范的命名
user_name = "张三"
score = 75
buffer_size = 120
is_valid = True

# 不推荐的命名（虽然合法，但不符合规范）
UserName = "张三"           # PascalCase，用于类名
userName = "张三"           # camelCase，Java 风格
p = "张三"                  # 过于简短，无法看出含义
x1 = 75                     # 含义不明
```

命名应做到见名知意。`score` 一眼能看出是分数，`s` 也可以但需要上下文，`x` 或 `a` 这种名字只在临时变量或循环计数中可以接受。实际开发中常见的变量名往往包含多个单词，如 `max_retry_count`（最大重试次数）、`default_page_size`（默认每页条数），用下划线分隔能让名字清晰可读。

::: note 规则与规范的区别
规则是解释器强制的，违反会报错；规范是社区约定的，违反不报错但影响协作。养成遵守 PEP 8 的习惯，能让你的代码在团队中更易被接受，也方便他人接手维护。
:::

## 2.1.4 保留字（关键字）列表

Python 有一组保留字（也称关键字），这些词被语言本身占用，具有特殊语法含义，不能用作变量名、函数名或其他标识符。如果在代码中把保留字当变量名使用，解释器会抛出 `SyntaxError`。Python 3.10 及以上版本共有 35 个保留字，完整列表如下：

```python
# 查看 Python 的全部保留字
import keyword
print(keyword.kwlist)
print(len(keyword.kwlist))  # 35
```

下面按功能分类列出全部 35 个保留字，方便你理解它们的用途。

布尔与空值相关的有三个：`True`、`False`、`None`。逻辑运算相关的有三个：`and`、`or`、`not`。条件判断相关的有四个：`if`、`elif`、`else`、`assert`。循环相关的有四个：`for`、`while`、`break`、`continue`。函数定义相关的有四个：`def`、`return`、`lambda`、`yield`。异常处理相关的有五个：`try`、`except`、`finally`、`raise`、`with`（`with` 也用于上下文管理）。导入相关的有两个：`import`、`from`。类与对象相关的有四个：`class`、`self`（实际不是关键字，但约定使用）、`pass`、`del`。作用域相关的有两个：`global`、`nonlocal`。命名空间相关的有一个：`as`。成员判断相关的有一个：`in`（也用于循环）。身份判断相关的有一个：`is`。异步编程相关的有两个：`async`、`await`。

```python
# 精确的 35 个保留字清单
keywords = [
    "False", "None", "True", "and", "as", "assert", "async", "await",
    "break", "class", "continue", "def", "del", "elif", "else", "except",
    "finally", "for", "from", "global", "if", "import", "in", "is",
    "lambda", "nonlocal", "not", "or", "pass", "raise", "return", "try",
    "while", "with", "yield"
]
print(len(keywords))  # 35
```

::: note 关于 self
`self` 并不是 Python 的保留字，它只是社区约定在类的方法中用于指代实例自身的参数名。理论上你可以用 `this`、`me` 等任何名字代替 `self`，但强烈建议遵循约定使用 `self`，否则其他 Python 开发者会觉得你的代码很奇怪。
:::

## 2.1.5 内置函数名不可用作变量名

除了 35 个保留字，Python 还有一批内置函数和类型，它们虽然不是保留字，语法上允许被重新赋值，但一旦重新赋值就会覆盖原有功能，导致后续代码无法使用该函数。这是初学者最容易踩的坑之一。常见的内置函数名包括 `print`、`input`、`len`、`type`、`int`、`float`、`str`、`bool`、`list`、`tuple`、`dict`、`set` 等。

```python
# 错误示范：把 list 当作变量名
list = [1, 2, 3]       # 此时 list 不再是内置类型
# list("hello")        # 这一行会报错，list 已被覆盖成列表对象
```

上述代码执行后，`list` 这个名字指向了一个列表对象 `[1, 2, 3]`，原本的内置类型 `list` 被遮蔽（shadowing）。此后如果调用 `list("hello")` 想把字符串转成列表，解释器会报错，因为 `list` 已经不是可以调用的类型了。

::: warning 遮蔽内置名的危害
覆盖内置函数名不会立即报错，往往在后续代码调用该函数时才暴露问题，排查难度较大。建议用 `user_list`、`record_list` 这样带业务含义的名字，既符合规范又避免冲突。如果你不小心覆盖了内置名，可以通过 `del 变量名` 删除自定义变量，恢复对内置名的访问，或者直接重启解释器。
:::

## 2.1.6 常量概念（Python无语法级常量，全大写命名约定）

许多编程语言（如 C、Java）提供语法级的常量定义，一旦定义就不能修改。Python 没有这种语法机制，所有变量在技术上都是可修改的。Python 社区通过命名约定来表示常量：用全大写字母加下划线的方式命名，提示阅读者这个值在程序运行期间不应该被改变。

```python
# 用全大写命名表示常量
MAX_CONNECTIONS = 10
BUFFER_SIZE = 1024
DEFAULT_TIMEOUT = 30
PI = 3.141592653589793

# 计算当前连接数是否在允许范围
current_connections = 7
is_ok = current_connections <= MAX_CONNECTIONS
print(is_ok)  # True
```

实际开发中常见的常量场景有最大连接数、缓冲区大小、超时时间等。这些值在程序中固定不变，用全大写命名既醒目又便于统一管理。把所有常量集中在文件开头或单独的配置模块中，修改时只需改一处，避免在代码各处散落魔法数字。

::: note 常量只是约定
Python 不会阻止你修改全大写命名的变量，技术上你完全可以写 `MAX_CONNECTIONS = 20`，只是这违背了命名约定，会被视为不良实践。团队协作中，看到全大写变量名就应该意识到它是常量，不要在代码中修改它的值。
:::

## 2.1.7 赋值运算符 =

赋值运算符 `=` 是 Python 中最基础的运算符，作用是把右侧的值赋给左侧的变量。需要严格区分赋值运算符 `=` 和比较运算符 `==`，前者是赋值操作，后者是判断两个值是否相等。这是初学者最容易混淆的地方，尤其在 `if` 语句中写 `if x = 5:` 会导致语法错误，正确写法是 `if x == 5:`。

```python
# 赋值运算符
item_count = 50        # 把 50 赋给 item_count
item_count = 60        # 重新赋值，旧值 50 被覆盖

# 比较运算符（注意区分）
print(item_count == 60)  # True，比较是否相等
print(item_count = 60)   # SyntaxError，赋值不能用在表达式里
```

赋值运算符的计算顺序是从右到左。先计算右侧表达式的值，再把结果赋给左侧变量。这意味着你可以把一个复杂表达式的结果直接赋值给变量，也可以把一个变量的值赋给另一个变量。

```python
# 从右到左计算
total = 100 + 200          # 先算 100 + 200 = 300，再赋给 total
discounted = total * 0.8   # 先算 total * 0.8 = 240.0，再赋给 discounted
copy_count = total         # 把 total 的值赋给 copy_count
```

## 2.1.8 链式赋值（a = b = 10）

链式赋值允许把同一个值一次性赋给多个变量，写法是 `a = b = 10`。这种写法的执行过程是先在内存中创建对象 `10`，然后把 `a` 和 `b` 都关联到这同一个对象上。对于不可变对象（如整数、字符串）这种共享通常不会带来问题，因为不可变对象一旦创建就不能被修改。

```python
# 链式赋值
a = b = c = 0

print(a, b, c)  # 0 0 0

# 链式赋值给多个变量赋初始值
width = height = 0
width = 120
print(width, height)  # 120 0，height 不受影响
```

链式赋值常用于给多个计数器或状态变量赋相同的初始值。需要注意的是，链式赋值让多个变量指向同一个对象，对于可变对象（如列表）要特别小心，修改其中一个变量会影响所有指向同一对象的变量，这一点在后面讲可变对象时还会详细说明。

## 2.1.9 平行赋值（a, b = 1, 2）

平行赋值（也称元组解包赋值）允许在一行内同时给多个变量赋不同的值，写法是 `a, b = 1, 2`。等号右侧的值按位置依次赋给左侧的变量，数量必须一致，否则会报错。这种写法在交换两个变量的值时特别优雅，无需借助临时变量。

```python
# 平行赋值
width, height = 120, 80
print(width, height)  # 120 80

# 交换两个变量的值（无需临时变量）
a, b = 1, 2
a, b = b, a
print(a, b)  # 2 1
```

平行赋值在处理函数返回多个值的场景中也很常用。比如一个函数同时返回宽度和高度，调用时可以用平行赋值直接接收：

```python
def get_dimensions():
    return 120, 80

# 平行赋值接收多个返回值
width, height = get_dimensions()
print(width, height)  # 120 80
```

如果右侧值的数量与左侧变量数量不一致，可以使用星号 `*` 收集多余的值到一个列表中，这种用法在后面讲函数参数时会再次出现：

```python
# 星号收集多余的值
first, *rest = [1, 2, 3, 4, 5]
print(first)  # 1
print(rest)   # [2, 3, 4, 5]
```

## 2.1.10 增量赋值运算符（+=, -=, *=, /=, //=, %=, **=）

增量赋值运算符是赋值运算符与算术运算符的组合简写，形式为 `x op= y`，等价于 `x = x op y`。比如 `x += 1` 等价于 `x = x + 1`。这种写法让累加、累减等操作更简洁，也减少了变量名重复书写带来的笔误风险。Python 支持的增量赋值运算符包括 `+=`、`-=`、`*=`、`/=`、`//=`、`%=`、`**=`，分别对应加、减、乘、除、整除、取余、幂运算。

```python
# 增量赋值示例
total_items = 100
total_items += 5    # 等价于 total_items = total_items + 5
print(total_items)  # 105

total_items -= 10   # 等价于 total_items = total_items - 10
print(total_items)  # 95

amount = 500
amount *= 2         # 等价于 amount = amount * 2
print(amount)       # 1000

amount /= 4         # 等价于 amount = amount / 4
print(amount)       # 250.0，注意除法结果是浮点数

n = 17
n //= 5             # 等价于 n = n // 5
print(n)            # 3

n %= 2              # 等价于 n = n % 2
print(n)            # 1

base = 2
base **= 10         # 等价于 base = base ** 10
print(base)         # 1024
```

对于可变对象（如列表），`+=` 的行为与 `x = x + y` 略有差异，`+=` 会就地修改原对象，而 `x + y` 会创建新对象。这个差异在初学阶段可以暂时忽略，等到学习列表的深浅拷贝时再深入理解。

## 2.1.11 动态类型特性（变量类型可随时改变）

Python 是动态类型语言，变量的类型由它当前关联的对象决定，无需在定义时声明类型。同一个变量可以先存整数，再存字符串，再存列表，解释器不会报错。这种特性让 Python 写起来非常灵活，少了很多样板代码。

```python
# 动态类型：同一个变量可以改变类型
data = 42
print(type(data))   # <class 'int'>

data = "用户姓名"
print(type(data))   # <class 'str'>

data = [120, 80, 75]
print(type(data))   # <class 'list'>

data = True
print(type(data))   # <class 'bool'>
```

动态类型的灵活性也有代价。类型错误往往要等到运行时才暴露，IDE 的静态检查也难以做到严格。在大型项目中，可以用 `typing` 模块加类型注解来缓解这一问题，但注解本身只是提示，不会强制执行。实际开发中，如果一段代码期望接收数值型的分数却收到了字符串，动态类型不会提前警告，要到运算时才报错。因此写代码时要注意变量类型的连贯性，避免随意切换类型。

::: note 类型注解简介
Python 3.5 引入类型注解语法，可以在函数定义和变量定义时标注预期类型，例如 `age: int = 45`。类型注解不影响运行，但能被 mypy 等工具检查，提前发现类型不匹配的问题。本教程后续章节会专门讲解类型注解的用法。
:::

## 2.1.12 对象引用机制（变量存储的是对象的引用，不是值本身）

理解 Python 的变量机制，需要先区分两个概念：变量和对象。对象是内存中实际存在的数据实体，有自己的类型和值；变量是一个名字，它指向某个对象，但变量本身不存储值。这种模型类似于文件名与文件的关系：文件名（变量名）指向某个文件（对象），文件名本身不是文件，只是标识。

```python
# 变量是对象的引用
a = [1, 2, 3]
b = a           # b 和 a 指向同一个列表对象
b.append(4)
print(a)        # [1, 2, 3, 4]，a 也变了
print(b)        # [1, 2, 3, 4]
```

上述代码中，`b = a` 并没有创建新的列表，只是让 `b` 也指向 `a` 所指向的同一个列表对象。对 `b` 的修改就是对那个共享列表的修改，`a` 自然也看得到变化。这与许多其他语言（如 C 的值传递）行为不同，是 Python 最容易让初学者困惑的地方。

把变量想象成贴在箱子上的标签，更准确地说，是贴在同一个箱子上的多张标签。一个对象可以有多个变量名指向它，就像一个箱子上可以贴多张标签。修改可变对象时，所有指向它的变量都会看到变化，因为它们看的是同一个箱子。

## 2.1.13 不可变对象与可变对象的赋值差异（仅概念区分）

Python 的对象分为两类：不可变对象和可变对象。不可变对象一旦创建，它的值就不能被修改，常见的不可变类型包括整数、浮点数、字符串、元组、布尔值。可变对象创建后可以修改其内容，常见的可变类型包括列表、字典、集合。这种区分对赋值和函数参数传递有重要影响。

```python
# 不可变对象：修改看似发生了，实际是创建了新对象
x = 10
y = x         # y 指向 10
x = x + 1     # x 指向新对象 11，y 仍指向 10
print(x, y)   # 11 10

# 可变对象：修改的是同一个对象
list_a = [1, 2, 3]
list_b = list_a       # list_b 和 list_a 指向同一个列表
list_a.append(4)      # 就地修改这个列表
print(list_a)         # [1, 2, 3, 4]
print(list_b)         # [1, 2, 3, 4]，list_b 也变了
```

对于不可变对象，任何**修改**操作实际上是创建了一个新对象，原对象保持不变。整数 `x = x + 1` 执行时，解释器计算 `10 + 1` 得到新对象 `11`，然后把 `x` 重新关联到 `11`，原来的 `10` 仍然在内存中，`y` 还指向它。对于可变对象，`list_a.append(4)` 是就地修改那个列表对象，没有创建新对象，所以 `list_b` 也看到了变化。

::: note 为什么区分可变与不可变
这种区分在函数传参时尤为关键。如果函数接收一个列表并在内部修改它，调用方的原列表也会被改变，这种副作用经常引发难以排查的 bug。实际开发中，如果一段代码负责往操作日志列表追加记录，而这份列表被多处共享，意外的修改可能导致日志出错。后续章节会讲解如何用拷贝避免这类问题。
:::

## 2.1.14 id() 函数查看对象内存地址

`id()` 是 Python 的内置函数，返回一个对象在内存中的唯一标识，这个标识通常就是对象在内存中的地址（在 CPython 实现中）。两个对象如果 `id` 相同，它们就是同一个对象；如果 `id` 不同，即使值相同也是两个独立的对象。`id()` 函数是理解对象引用机制的重要工具。

```python
# 用 id() 查看对象身份
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(id(a))  # 某个内存地址，例如 140234567890240
print(id(b))  # 与 a 相同
print(id(c))  # 与 a 不同，虽然是值相同的另一个列表

print(a is b)  # True，同一对象
print(a is c)  # False，不同对象
print(a == c)  # True，值相等
```

`id()` 返回的具体数字在不同运行中、不同机器上都不一样，不必关心这个数字本身的大小，只需关心几个变量对应的 `id` 是否相同。在调试引用相关的问题时，打印 `id()` 能帮你快速判断两个变量是否指向同一个对象。

```python
# 整数的小整数缓存现象
x = 100
y = 100
print(id(x) == id(y))  # True，CPython 缓存了小整数

x = 1000000
y = 1000000
print(id(x) == id(y))  # 可能 True 也可能 False，大整数不保证缓存
```

::: note 小整数缓存
CPython 解释器为了优化性能，会缓存常用的小整数（通常是 -5 到 256）和短字符串。这些对象在解释器启动时就创建好，所有用到这些值的变量都指向同一个缓存对象。这就是为什么 `a = 100; b = 100` 时 `a is b` 为 True。但这是实现细节，不应依赖它判断值是否相等，判断值相等始终用 `==`。
:::

## 2.1.15 is 运算符比较两个变量是否引用同一对象

`is` 运算符用于判断两个变量是否引用同一个对象，也就是它们的 `id` 是否相同。这与 `==` 运算符有本质区别：`==` 比较的是两个对象的值是否相等，`is` 比较的是两个对象是否就是同一个。可以用文件名类比：`is` 判断两个文件名是否指向同一个文件，`==` 判断两个文件的内容是否相同。

```python
# is 与 == 的区别
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True，值相等
print(a is b)  # False，不是同一个对象

c = a
print(a is c)  # True，c 和 a 是同一个对象
```

`is` 运算符最常见的实际用途是判断一个变量是否为 `None`。`None` 是 Python 中表示"空"的特殊单例对象，整个程序中只有一个 `None`，因此判断 `None` 应该用 `is` 而非 `==`：

```python
# 判断 None 的正确方式
result = None

if result is None:
    print("结果为空")

if result is not None:
    print("结果不为空")
```

::: warning 何时用 is，何时用 ==
判断 `None`、`True`、`False` 这类单例对象用 `is`，判断数值、字符串、列表等普通对象的值是否相等用 `==`。判断两个列表是否值相等用 `==`，判断两个变量是否指向同一个列表用 `is`。初学者常犯的错误是用 `is` 比较数值，由于小整数缓存的存在，`a = 100; b = 100; a is b` 可能返回 True，但换一个大数字就返回 False，这种不一致的行为容易引入隐蔽的 bug。
:::

## 2.1.16 is not 运算符

`is not` 是 `is` 的否定形式，判断两个变量是否引用不同的对象。语法上 `a is not b` 等价于 `not (a is b)`，但 `is not` 的可读性更好，推荐使用 `is not` 而非 `not ... is ...` 的写法。

```python
# is not 运算符
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a is not b)  # True，a 和 b 是不同对象
print(a is not c)  # False，a 和 c 是同一对象

# 判断变量不为 None 的标准写法
data = [1, 2, 3]
if data is not None:
    print("data 已赋值")
```

`is not None` 是 Python 代码中极为常见的判断模式，用于在执行后续操作前确认变量已被正确赋值，避免对 `None` 调用方法导致 `AttributeError`。函数返回值可能为 `None` 的场景下，调用方都应该先用 `is not None` 检查再使用。

## 2.1.17 del 语句删除变量引用

`del` 语句用于删除变量与对象之间的引用关系，并非直接销毁对象本身。执行 `del x` 后，变量名 `x` 不再存在，再次访问会报 `NameError`。被删除的变量原来指向的对象是否会被销毁，取决于是否还有其他变量引用它。如果一个对象没有任何变量引用它，Python 的垃圾回收器会自动回收它的内存。

```python
# del 删除变量引用
item_count = 50
print(item_count)  # 50

del item_count
# print(item_count)  # NameError: name 'item_count' is not defined
```

`del` 也可以删除列表或字典中的元素，这时它删除的是容器内的某个成员，而非变量本身：

```python
# 删除列表元素
records = ["U001", "U002", "U003"]
del records[1]
print(records)  # ['U001', 'U003']

# 删除字典的键值对
info = {"name": "张三", "age": 45, "status": "active"}
del info["status"]
print(info)  # {'name': '张三', 'age': 45}
```

`del` 在实际开发中用得不多，主要用于显式释放不再需要的大对象，或者从容器中移除特定元素。大多数情况下，让变量自然离开作用域或重新赋值即可达到类似效果。理解 `del` 删除的是引用而非对象本身，能帮你正确理解 Python 的内存管理机制。

::: note 垃圾回收机制简介
Python 使用引用计数为主、分代回收为辅的垃圾回收机制。每个对象维护一个引用计数，记录有多少变量指向它。引用计数降为 0 时，对象立即被回收。循环引用（两个对象互相引用）无法靠引用计数解决，由分代回收器定期扫描处理。日常编程无需关心这些细节，但理解引用计数能解释为什么 `del` 后对象不一定立即消失。
:::

学完本节，你应该理解了变量在 Python 中是对象的引用而非值的容器，这种模型决定了赋值、传参、修改等操作的行为。下一节将进入运算符与表达式的学习，看看这些数据如何参与计算和判断。

## 练习题

### 第1题 概念理解

阅读下面这段代码，写出它的输出结果，并解释为什么修改 `b` 之后 `a` 也发生了变化。

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
print(b)
```

::: details 参考答案
```python
print(a)  # [1, 2, 3, 4]
print(b)  # [1, 2, 3, 4]
```

`b = a` 并没有创建新的列表，而是让 `b` 也指向 `a` 所指向的同一个列表对象。`b.append(4)` 就地修改了这个共享的列表对象，由于 `a` 和 `b` 指向同一个对象，`a` 也看到了变化。Python 中变量是对象的引用，赋值操作传递的是引用而非值的拷贝。如果要让 `b` 独立于 `a`，应该用 `b = a.copy()` 或 `b = list(a)` 创建副本。
:::

### 第2题 代码编写

使用平行赋值交换两个变量的值，不借助临时变量。然后定义三个变量 `x`、`y`、`z` 分别为 1、2、3，用一行代码把它们重新赋值为 `z`、`x`、`y` 的值，打印交换后的结果。

::: details 参考答案
```python
# 交换两个变量
a, b = 10, 20
a, b = b, a
print(a, b)  # 20 10

# 交换三个变量
x, y, z = 1, 2, 3
x, y, z = z, x, y
print(x, y, z)  # 3 1 2
```

平行赋值（元组解包）允许在一行内同时给多个变量赋值。等号右侧的值先组成一个元组，再按位置依次赋给左侧的变量。交换变量时，右侧的 `b, a` 先组成元组 `(20, 10)`，再分别赋给 `a` 和 `b`，整个过程无需临时变量。这种写法比用临时变量的传统方式更简洁，也是 Python 的惯用写法。
:::

### 第3题 进阶练习

下面这段代码展示了不可变对象与可变对象在赋值时的差异。写出输出结果，并用对象引用机制解释为什么 `x` 和 `y` 的行为与 `list_a` 和 `list_b` 不同。

```python
x = 10
y = x
x = x + 1
print(x, y)

list_a = [1, 2, 3]
list_b = list_a
list_a.append(4)
print(list_a, list_b)
```

::: details 参考答案
```python
print(x, y)              # 11 10
print(list_a, list_b)    # [1, 2, 3, 4] [1, 2, 3, 4]
```

整数是不可变对象。`y = x` 让 `y` 指向 `10`，执行 `x = x + 1` 时，`10 + 1` 产生新对象 `11`，`x` 被重新关联到 `11`，原来的 `10` 仍然存在，`y` 还指向它，所以 `y` 不受影响。

列表是可变对象。`list_b = list_a` 让两个变量指向同一个列表，`list_a.append(4)` 就地修改这个列表对象，没有创建新对象，所以 `list_b` 也看到了变化。核心区别在于：对不可变对象的修改实际上是创建新对象并重新绑定变量，对可变对象的修改是直接改变原对象的内容。
:::

### 第4题 项目实践

命令行任务管理器中，任务的状态有几种固定取值（如待办、进行中、已完成）。请用常量的方式定义这些状态值，并说明为什么用全大写命名。再思考如果把这些状态存进列表传递给函数，会不会出现意外的修改问题。

::: details 参考答案
```python
# 状态常量，用全大写字母命名
STATUS_TODO = "todo"
STATUS_DOING = "doing"
STATUS_DONE = "done"

# 任务列表
tasks = [STATUS_TODO, STATUS_DOING, STATUS_TODO, STATUS_DONE]

def show_tasks(task_list):
    # 如果在这里修改 task_list，会影响原始的 tasks
    for task in task_list:
        print(task)

show_tasks(tasks)
```

全大写命名是 PEP 8 对常量的约定，提醒阅读者这些值在程序运行期间不应被修改。状态值用字符串常量表示，比直接写魔法字符串更易维护，修改时只需改一处。

把列表传递给函数时，函数内部得到的是同一个列表对象的引用。如果函数内部对 `task_list` 做 `append` 或 `remove` 操作，会影响到调用方的原始 `tasks` 列表。如果不想让函数修改原列表，应该在函数内部用 `task_list.copy()` 创建副本再操作，或者用 `tuple()` 转成不可变的元组传入。
:::

## 常见错误

**错误 1 · `SyntaxError: invalid syntax`**

原因:变量名违反命名规则。常见情况包括首字符为数字（如 `2user`）、包含连字符或空格（如 `blood-pressure`、`heart rate`）、使用保留字（如 `class = "用户"`）。`=` 用在条件表达式里也会触发，例如 `if x = 5:`。

解决:变量名只能由字母、数字、下划线组成且首字符不能为数字，使用 `snake_case` 风格。条件判断用 `==` 而非 `=`。遇到保留字冲突时改名，例如 `class_name`、`type_str`。

**错误 2 · `NameError: name 'item_count' is not defined`**

原因:访问了未定义的变量。常见于三种情况:变量在 `del` 之后被访问、拼写错误的变量名、变量在作用域外被引用。例如执行 `del item_count` 后再 `print(item_count)` 就会报错。

解决:检查变量名拼写，确认变量已在当前位置之前赋值。`del` 之后不要再访问该名字。函数内部修改全局变量时需要用 `global` 声明，否则视为局部变量。

**错误 3 · 遮蔽内置名后调用失败**

```python
list = [1, 2, 3]
# 后续代码
list("hello")  # TypeError: 'list' object is not callable
```

原因:把内置函数名或类型名（`list`、`str`、`int`、`print` 等）当作变量名赋值，原有功能被覆盖。这种错误不会立即报错，往往在后续调用该函数时才暴露，排查难度大。

解决:变量名加业务含义，用 `user_list`、`record_str`、`age_int` 代替 `list`、`str`、`int`。若已遮蔽，用 `del 变量名` 删除自定义绑定恢复内置名，或重启解释器。

**错误 4 · 用 `is` 比较数值得到不一致结果**

```python
a = 100
b = 100
print(a is b)  # True

a = 1000000
b = 1000000
print(a is b)  # 可能 False
```

原因:`is` 比较的是对象身份而非值是否相等。CPython 缓存了 -5 到 256 的小整数，这个范围内的 `is` 比较碰巧返回 `True`，超出范围就可能返回 `False`，行为不一致。

解决:比较值是否相等始终用 `==`。`is` 仅用于判断 `None`、`True`、`False` 等单例对象，例如 `if result is None:`。
