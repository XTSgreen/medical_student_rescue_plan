# 2.2 运算符与表达式

运算符是连接数据的桥梁，表达式是运算符与操作数组合而成的可计算片段。如果说变量是存放数据的箱子，运算符就是对这些箱子里的数据进行的各类操作：有的做加法、有的做比较、有的做逻辑判断。掌握运算符的种类、行为和优先级，才能写出正确且可读的计算逻辑。本节将系统讲解 Python 的算术、比较、逻辑、位、成员、身份六类运算符，以及表达式的概念和优先级规则。实际开发中的数值计算、条件判断、数据筛选，都建立在这些基础运算之上。

## 2.2.1 算术运算符

Python 提供七种算术运算符，覆盖日常数值计算的全部需求。这些运算符分别是 `+`（加）、`-`（减）、`*`（乘）、`/`（真除法）、`//`（整除）、`%`（取模）、`**`（幂运算）。每种运算符的行为需要逐一理解，尤其是除法相关的三种运算符，它们之间的差异容易让初学者混淆。

`+`、`-`、`*` 三种运算符的行为与数学常识一致。`/` 是真除法，无论操作数是整数还是浮点数，结果总是浮点数。`//` 是整除（也称地板除），返回商的整数部分，向下取整。`%` 是取模，返回除法的余数。`**` 是幂运算，计算乘方。

```python
# 基本算术运算
a = 10
b = 3

print(a + b)    # 13，加法
print(a - b)    # 7，减法
print(a * b)    # 30，乘法
print(a / b)    # 3.3333333333333335，真除法，结果是浮点数
print(a // b)   # 3，整除，向下取整
print(a % b)    # 1，取模，10 除以 3 余 1
print(a ** b)   # 1000，幂运算，10 的 3 次方
```

三种除法相关运算符的差异需要重点理解。`/` 总是返回浮点数，哪怕两个整数能整除：`6 / 2` 结果是 `3.0` 而非 `3`。`//` 返回商的整数部分，对正数来说是截断小数，对负数是向下取整：`-7 // 2` 结果是 `-4` 而非 `-3`，因为 `-3.5` 向下取整是 `-4`。`%` 的结果与 `//` 配合使用满足公式 `a = (a // b) * b + (a % b)`。

```python
# 三种除法的差异
print(6 / 2)     # 3.0，真除法返回浮点数
print(6 // 2)    # 3，整除返回整数
print(7 / 2)     # 3.5
print(7 // 2)    # 3，向下取整
print(-7 / 2)    # -3.5
print(-7 // 2)   # -4，向下取整（不是 -3）
print(-7 % 2)    # 1，与 // 配合：(-4)*2 + 1 = -7
```

::: note 实际开发中的取模运算
取模运算在周期性计算中很有用。比如计算某个任务距离上次执行过了几天，或者把小时数转换为班次编号。`hour % 8` 能告诉你当前小时在 8 小时班次中的位置。整除运算常用于把秒数转换为分钟数或小时数，比如 `total_seconds // 60` 得到分钟数。
:::

`+` 和 `*` 还可以用于字符串和列表等序列类型，行为是拼接和重复：

```python
# 字符串和列表的运算
prefix = "用户"
full_name = prefix + "张三"     # 字符串拼接
print(full_name)                # 用户张三

separator = "-" * 20            # 字符串重复
print(separator)                # --------------------

list_a = [1, 2] + [3, 4]        # 列表拼接
print(list_a)                   # [1, 2, 3, 4]

zeros = [0] * 5                 # 列表重复
print(zeros)                    # [0, 0, 0, 0, 0]
```

## 2.2.2 算术运算符的优先级

当多个算术运算符出现在同一个表达式中时，Python 按照固定的优先级顺序决定计算顺序。算术运算符的优先级从高到低依次是：`**`（幂运算）最高，其次是一元正负号 `+x`、`-x`，然后是 `*`、`/`、`//`、`%`（乘除类），最后是 `+`、`-`（加减类）。同级运算符从左到右计算，唯一例外是 `**`，它是从右到左结合的。

```python
# 算术运算符优先级
print(2 + 3 * 4)        # 14，先算 3*4=12，再算 2+12
print((2 + 3) * 4)      # 20，括号改变优先级
print(2 ** 3 ** 2)      # 512，从右到左：3**2=9，2**9=512
print(-2 ** 2)          # -4，** 优先于一元负号：-(2**2)
print(10 - 2 - 3)       # 5，从左到右：(10-2)-3
print(10 / 2 / 5)       # 1.0，从左到右：(10/2)/5
```

`-2 ** 2` 的结果是 `-4` 而非 `4`，这一点容易让人困惑。原因是 `**` 的优先级高于一元负号，所以先计算 `2 ** 2` 得到 `4`，再取负得到 `-4`。如果你想要的是 `(-2) ** 2`，必须显式加括号。这种细节在数值计算等场景中可能影响结果，写代码时遇到负数与幂运算混合的情况要特别留意。

::: warning 优先级记不住怎么办
不必死记所有优先级，遇到不确定的情况就加括号。括号能让计算顺序明确，也能提升代码可读性，让阅读者无需回忆优先级规则就能理解意图。`2 + (3 * 4)` 虽然比 `2 + 3 * 4` 多几个字符，但意图更清晰。在关键计算场景，加括号是良好的工程习惯。
:::

## 2.2.3 比较运算符

比较运算符用于比较两个值的大小或是否相等，返回布尔值 `True` 或 `False`。Python 提供六种比较运算符：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）。比较运算符是条件判断和循环控制的基础，几乎每段逻辑代码都会用到。

```python
# 比较运算符
score = 75

print(score == 75)   # True，等于
print(score != 80)   # True，不等于
print(score > 100)   # False，大于
print(score < 60)    # False，小于
print(score >= 75)   # True，大于等于
print(score <= 75)   # True，小于等于
```

`==` 和 `!=` 比较的是值的相等性，而非对象的身份。对于基本类型（整数、浮点数、字符串），`==` 直接比较值是否相等。对于列表、字典等容器类型，`==` 会递归比较每个元素是否相等。这一点在上一节讲 `is` 与 `==` 的区别时已经提到过。

```python
# 容器的值比较
list_a = [1, 2, 3]
list_b = [1, 2, 3]
print(list_a == list_b)   # True，值相等
print(list_a is list_b)   # False，不是同一个对象
```

比较运算符也适用于字符串，按字典序比较。字符串比较基于 Unicode 码点逐字符进行，这意味着大写字母小于小写字母（因为大写字母的码点更小），中文比较基于 Unicode 码点，不一定符合拼音或笔画顺序。

```python
# 字符串比较
print("abc" < "abd")     # True，前两个字符相同，c < d
print("abc" < "abcd")    # True，前缀相同时短的更小
print("ABC" < "abc")     # True，大写字母码点小于小写
print("张三" < "李四")    # True，按 Unicode 码点比较
```

## 2.2.4 比较运算符的链式使用

Python 支持比较运算符的链式写法，可以连续使用多个比较运算符表达区间判断。比如 `a < b <= c` 等价于 `a < b and b <= c`，但 `b` 只会被求值一次。这种写法在表达数值范围时特别自然，比拆分成两个比较更简洁可读。

```python
# 链式比较
score = 75

# 判断分数是否在及格范围 60-100
is_normal = 60 <= score <= 100
print(is_normal)   # True

# 等价写法
is_normal = 60 <= score and score <= 100
print(is_normal)   # True

# 链式比较的多种形式
age = 45
print(18 <= age < 60)    # True，成年且未到老年
print(0 < age < 150)     # True，合理的年龄范围
```

链式比较的求值规则是短路求值，与 `and` 一致。`60 <= score <= 100` 先判断 `60 <= score`，如果为 `False`，整个表达式就是 `False`，不会继续判断 `score <= 100`。这种短路行为在边界判断中避免了多余计算。

```python
# 链式比较的短路特性
# 不会对 score 求值两次
score = 50
print(60 <= score <= 100)   # False，60 <= 50 为 False，直接返回
```

## 2.2.5 逻辑运算符

逻辑运算符用于组合多个布尔表达式，Python 提供三个逻辑运算符：`and`（与）、`or`（或）、`not`（非）。`and` 要求两边都为 `True` 结果才为 `True`；`or` 只要有一边为 `True` 结果就是 `True`；`not` 对布尔值取反。逻辑运算符是构建复杂条件判断的核心工具。

```python
# 逻辑运算符
age = 45
score = 75
is_valid = False

# and：所有条件都满足
is_healthy = (age < 60) and (60 <= score <= 100) and (not is_valid)
print(is_healthy)   # True

# or：任一条件满足
is_high_risk = (age >= 60) or (score > 100) or is_valid
print(is_high_risk) # False
```

`not` 运算符用于取反，优先级高于 `and` 和 `or`。`not True` 是 `False`，`not False` 是 `True`。`not` 常与 `in`、`is` 等运算符组合使用，写成 `x not in y`、`x is not None` 的形式，这种组合形式比 `not (x in y)` 更自然。

```python
# not 运算符
is_active = True
print(not is_active)   # False

# 组合形式
records = ["U001", "U002"]
print("U003" not in records)   # True
```

逻辑运算符的一个独特之处是它返回的不一定是布尔值。`and` 和 `or` 返回的是决定结果的那个操作数，而非布尔值。具体规则是：`a and b` 如果 `a` 为真返回 `b`，否则返回 `a`；`a or b` 如果 `a` 为真返回 `a`，否则返回 `b`。这种特性称为短路求值返回，在后续章节会详细说明。

## 2.2.6 逻辑运算符的短路求值规则

短路求值是逻辑运算符的重要特性，指的是 `and` 和 `or` 在能确定结果时就停止求值，不再计算右侧表达式。`and` 的左侧为 `False` 时，整个表达式必定为 `False`，右侧不再求值；`or` 的左侧为 `True` 时，整个表达式必定为 `True`，右侧不再求值。

```python
# and 的短路：左侧为 False 时不评估右侧
def check_something():
    print("check_something 被调用了")
    return True

False and check_something()   # 不会打印，因为 and 左侧为 False
True and check_something()    # 会打印，因为 and 左侧为 True 需要看右侧

# or 的短路：左侧为 True 时不评估右侧
True or check_something()     # 不会打印
False or check_something()    # 会打印
```

短路求值在实际编程中非常有用。它可以避免对可能出错的表达式求值，比如先检查变量是否存在再访问其属性，先检查索引是否合法再访问列表元素。这种**安全检查在前**的模式是 Python 代码的常见写法。

```python
# 利用短路求值避免错误
user = None
name = "未知"

# 如果 user 为 None，不会访问 user.name，避免 AttributeError
display_name = user and user.name or name
print(display_name)   # 未知

# 更清晰的等价写法用条件表达式
display_name = user.name if user else name
```

::: note 短路求值的返回值
`a and b` 返回的是决定结果的操作数本身，而非布尔值。`a` 为假时返回 `a`（假值），`a` 为真时返回 `b`。`a or b` 返回的是第一个真值，如果都为假返回最后一个假值。这种特性常用于设置默认值：`value = config or default`，当 `config` 为空时使用 `default`。
:::

## 2.2.7 逻辑运算符的优先级

三个逻辑运算符的优先级从高到低依次是 `not`、`and`、`or`。这意味着在没有括号的情况下，`not` 先计算，然后是 `and`，最后是 `or`。理解这个优先级顺序对于正确书写复杂条件判断是必要的，否则可能出现逻辑错误。

```python
# 逻辑运算符优先级：not > and > or
a = True
b = False
c = True

# 等价于 (not b) and (a or c)
print(not b and a or c)   # 先 not b = True，再 True and True = True，最后 True or True = True

# 用括号明确意图
print((not b) and (a or c))   # True

# 另一个例子
x = False
y = True
z = False
# 等价于 (not x) and (y or z)
print(not x and y or z)   # True
```

当条件判断涉及多个 `and` 和 `or` 组合时，优先级规则容易让人混淆。为了避免歧义和错误，建议用括号显式标明逻辑分组，即使不加括号也能得到正确结果。括号让代码意图清晰，也方便后续修改逻辑时不容易出错。

```python
# 复杂条件判断：建议加括号
age = 65
is_vip = True
has_coupon = False

# 不加括号，依赖优先级，可读性差
high_risk = age >= 60 or is_vip and has_coupon
# 实际计算：age >= 60 or (is_vip and has_coupon)

# 加括号，意图清晰
high_risk = (age >= 60) or (is_vip and has_coupon)
print(high_risk)   # True，因为 age >= 60
```

## 2.2.8 位运算符

位运算符直接操作整数的二进制位，Python 提供六种位运算符：`&`（按位与）、`|`（按位或）、`^`（按位异或）、`~`（按位取反）、`<<`（左移）、`>>`（右移）。这些运算符在底层编程、权限控制、图像处理等场景中会用到，日常数据分析中用得较少，但理解其原理有助于读懂相关代码。

```python
# 位运算符示例
a = 12   # 二进制：00001100
b = 10   # 二进制：00001010

print(a & b)    # 8，按位与：00001000
print(a | b)    # 14，按位或：00001110
print(a ^ b)    # 6，按位异或：00000110
print(~a)       # -13，按位取反：补码表示
print(a << 2)   # 48，左移 2 位：00110000，相当于乘以 4
print(a >> 2)   # 3，右移 2 位：00000011，相当于除以 4
```

按位与 `&` 对每一位执行与运算，两位都为 1 结果才为 1。按位或 `|` 对每一位执行或运算，任一位为 1 结果就是 1。按位异或 `^` 对每一位执行异或运算，两位不同结果为 1，相同为 0。按位取反 `~` 对每一位取反，由于 Python 整数用补码表示，`~x` 等于 `-x - 1`。

左移 `<<` 把二进制位向左移动指定位数，右边补 0，相当于乘以 2 的 n 次方。右移 `>>` 把二进制位向右移动指定位数，左边补符号位，相当于除以 2 的 n 次方取整。

::: note 位运算的实际应用
图像处理中，图像的像素值有时用位平面存储，位运算可以提取特定位平面。权限控制中，常用位运算组合多个标志位，比如用每一位表示一种权限，按位或组合权限，按位与检查权限。这些场景在底层编程中会经常遇到。
:::

```python
# 用位运算做标志位管理
# 假设用 4 位表示操作权限
READ = 1      # 0001，读权限
WRITE = 2     # 0010，写权限
DELETE = 4    # 0100，删除权限
ADMIN = 8     # 1000，管理员权限

# 组合权限
user_perm = READ | WRITE          # 0011，普通用户有读写权限
admin_perm = READ | WRITE | DELETE | ADMIN  # 1111

# 检查权限
print(user_perm & WRITE)    # 2，非零表示有写权限
print(user_perm & DELETE)   # 0，零表示无删除权限
print(bool(user_perm & DELETE))  # False
```

## 2.2.9 位运算符的优先级

位运算符的优先级顺序从高到低依次是：`~`（按位取反）最高，然后是 `<<`、`>>`（移位），接着是 `&`（按位与），再是 `^`（按位异或），最后是 `|`（按位或）。这个顺序需要记忆，因为位运算符的优先级与算术运算符和比较运算符交织在一起，容易混淆。

```python
# 位运算符优先级
a = 12
b = 10
c = 6

# ~ 最高，然后 << >>，然后 &，然后 ^，最后 |
print(a & b | c)      # 14，先 a&b=8，再 8|c=14
print(a | b & c)      # 14，先 b&c=2，再 a|2=14
print(a ^ b & c)      # 10，先 b&c=2，再 a^2=10
print(~a & b)         # 2，先 ~a=-13，再 -13 & 10 = 2
```

位运算符的优先级高于比较运算符，但低于算术运算符。这意味着 `a + b & c` 会先算 `a + b`，再算 `& c`。为了避免混淆，涉及位运算的复杂表达式都应该加括号明确计算顺序。

```python
# 位运算与算术运算的优先级
a = 12
b = 10
c = 3

print(a + b & c)      # 先算 a+b=22，再 22 & 3 = 2
print((a + b) & c)    # 2，与上一行等价
print(a + (b & c))    # 14，先算 b&c=2，再 a+2=14
```

## 2.2.10 成员运算符

成员运算符用于判断一个值是否存在于某个容器中，Python 提供两个成员运算符：`in`（在...中）和 `not in`（不在...中）。成员运算符适用于字符串、列表、元组、集合、字典等容器类型，返回布尔值。

```python
# 成员运算符用于列表
tags = ["urgent", "vip", "error"]
print("vip" in tags)      # True
print("warn" not in tags) # True

# 用于字符串：判断子串
note = "用户提交了订单请求"
print("订单" in note)    # True
print("退款" in note)    # False

# 用于集合：判断成员
valid_scores = {60, 70, 80, 90, 100}
print(75 in valid_scores)   # False

# 用于字典：判断键（不是值）
user = {"name": "张三", "age": 45}
print("name" in user)    # True，判断键
print("张三" in user)    # False，值不在判断范围
print("张三" in user.values())  # True，显式判断值
```

成员运算符在不同容器上的性能差异很大。列表和字符串的成员判断是线性扫描，时间复杂度为 O(n)，元素越多越慢。集合和字典的键判断基于哈希表，时间复杂度为 O(1)，无论元素多少都很快。当需要频繁判断成员关系时，把列表转为集合能显著提升性能。

```python
# 性能对比：列表 vs 集合
import time

# 模拟大量数据
big_list = list(range(1000000))
big_set = set(big_list)

# 列表判断：线性扫描，较慢
start = time.time()
print(999999 in big_list)
print("列表判断耗时：", time.time() - start)

# 集合判断：哈希查找，极快
start = time.time()
print(999999 in big_set)
print("集合判断耗时：", time.time() - start)
```

::: note 实际开发中的成员判断
判断某个标签是否在标签列表、某个用户是否在白名单、某个键是否在配置集合中，都是典型的成员判断场景。当名单较大且需要频繁查询时，优先用集合存储数据，能大幅提升查询速度。
:::

## 2.2.11 身份运算符

身份运算符用于判断两个变量是否引用同一个对象，Python 提供两个身份运算符：`is`（是同一对象）和 `is not`（不是同一对象）。身份运算符比较的是对象的内存身份（`id`），与比较运算符 `==` 比较值有本质区别。上一节已经详细讲过 `is` 与 `==` 的差异，这里从运算符分类角度再做归纳。

```python
# 身份运算符
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a is c)       # True，a 和 c 是同一对象
print(a is not b)   # True，a 和 b 是不同对象
print(a == b)       # True，值相等

# is 的典型用途：判断 None
result = None
if result is None:
    print("结果为空")
```

身份运算符常见的用途是判断变量是否为 `None`、`True`、`False` 这三个单例对象。由于这些对象在整个程序中唯一存在，用 `is` 判断比 `==` 更准确，也符合 PEP 8 的建议。对于普通对象的相等比较，应该用 `==` 而非 `is`。

```python
# 单例对象的判断
x = True
print(x is True)     # True
print(x is not False) # True

y = None
print(y is None)     # True
```

## 2.2.12 运算符优先级完整顺序

把前面讲过的所有运算符汇总，Python 运算符的优先级从高到低排列如下：`**`（幂运算）最高，然后是一元运算符 `+x`、`-x`、`~x`，接着是乘除类 `*`、`/`、`//`、`%`，再到加减类 `+`、`-`，然后是移位 `<<`、`>>`，接着是按位与 `&`，按位异或 `^`，按位或 `|`，再是比较运算符 `==`、`!=`、`>`、`<`、`>=`、`<=`、`is`、`is not`、`in`、`not in`，然后是逻辑非 `not`，逻辑与 `and`，最低是逻辑或 `or`。

```python
# 运算符优先级综合示例
a = 5
b = 3
c = 2

# 混合多种运算符
result = a + b * c ** 2 > 10 and not a is b
# 计算顺序：
# 1. c ** 2 = 4
# 2. b * 4 = 12
# 3. a + 12 = 17
# 4. 17 > 10 = True
# 5. a is b = False
# 6. not False = True
# 7. True and True = True
print(result)   # True
```

完整的优先级表虽然看起来复杂，但日常编程中真正需要记忆的不多。绝大多数代码用括号明确计算顺序，避免依赖优先级规则。下表按从高到低列出主要运算符的优先级，方便查阅。

```python
# 运算符优先级速查（从高到低）
# 1.  **              幂运算
# 2.  +x -x ~x       一元正负、按位取反
# 3.  * / // %       乘、除、整除、取模
# 4.  + -            加、减
# 5.  << >>          左移、右移
# 6.  &              按位与
# 7.  ^              按位异或
# 8.  |              按位或
# 9.  == != > < >= <= is is not in not in   比较与身份与成员
# 10. not            逻辑非
# 11. and            逻辑与
# 12. or             逻辑或（最低）
```

::: note 赋值运算符的优先级
赋值运算符 `=` 及其衍生形式（`+=`、`-=` 等）的优先级比所有上述运算符都低，且没有返回值（不能用在表达式中）。这意味着 `a = b + c` 会先计算 `b + c`，再把结果赋给 `a`。`a + b = c` 这样的写法是非法的，因为赋值左侧必须是变量名而非表达式。
:::

## 2.2.13 括号 () 改变优先级

括号 `()` 可以改变运算符的默认优先级，括号内的表达式优先计算。嵌套括号时，最内层的括号先计算。使用括号是控制计算顺序最直接、最清晰的方式，也是提升代码可读性的重要手段。

```python
# 括号改变优先级
print(2 + 3 * 4)        # 14，默认先乘后加
print((2 + 3) * 4)      # 20，括号让加法先算

# 嵌套括号
result = ((2 + 3) * 4 - 6) / 2
# 计算顺序：2+3=5，5*4=20，20-6=14，14/2=7.0
print(result)   # 7.0

# 括号用于逻辑表达式
age = 45
is_vip = True
has_coupon = False

# 不加括号，依赖优先级
risk1 = age >= 60 or is_vip and has_coupon
# 等价于：age >= 60 or (is_vip and has_coupon)

# 加括号改变逻辑
risk2 = (age >= 60 or is_vip) and has_coupon
# 先算括号内的 or，再与 has_coupon 做 and

print(risk1)   # False，age < 60 且 (True and False) = False
print(risk2)   # False，(False or True) = True，True and False = False
```

在实际开发中，括号的使用很重要。复杂的数值计算、多条件组合判断，都需要明确的计算顺序。养成**遇到复杂表达式就加括号**的习惯，能让代码更可靠、更易维护。

```python
# 实际计算中的括号使用
weight = 70   # 重量 kg
unit_price = 5   # 单价 元
times_per_day = 3   # 每日次数
days = 7   # 天数

# 总价计算
total_cost = (weight * unit_price) * (times_per_day * days)
print(total_cost)   # 7350 元

# 矩形对角线长度计算
width = 3   # 宽 m
height = 4   # 高 m
diagonal = (width ** 2 + height ** 2) ** 0.5
print(diagonal)   # 5.0
```

## 2.2.14 表达式的概念

表达式是由运算符和操作数组合而成的、有返回值的代码片段。操作数可以是变量、字面量、函数调用等，运算符可以是前面讲过的任意一种。最简单的表达式是一个单独的字面量或变量，比如 `42` 或 `x`。复杂表达式由多个简单表达式通过运算符组合而成，比如 `(a + b) * c > 10 and x in y`。

```python
# 各种表达式
42              # 字面量是表达式，返回 42
x = 10
x               # 变量是表达式，返回变量关联的值
x + 5           # 算术表达式，返回计算结果
x > 5           # 比较表达式，返回布尔值
x > 5 and x < 20   # 逻辑表达式，返回布尔值
[1, 2, 3]       # 列表字面量是表达式
len([1, 2, 3])  # 函数调用是表达式，返回函数返回值
```

表达式与语句的区别在于：表达式有返回值，语句没有。`x = 10` 是赋值语句，没有返回值；`x + 10` 是表达式，返回计算结果。Python 中很多语法结构既接受表达式也接受语句，但 `if`、`while` 的条件位置必须是表达式，因为需要一个值来做判断。

```python
# 表达式 vs 语句
# 表达式：有返回值
result = 2 + 3          # 2 + 3 是表达式，返回 5
is_valid = x > 0        # x > 0 是表达式，返回布尔值

# 语句：没有返回值
x = 10                  # 赋值语句
if x > 0:               # if 语句
    print("正数")
```

在交互式环境中，输入表达式会立即显示返回值，输入语句则不会（除非语句中调用了 `print`）。这种差异反映了表达式与语句的本质区别。理解这一点，有助于在编写函数返回值、条件判断、列表推导式等场景中正确使用表达式。

```python
# 表达式可以出现在值需要的位置
# 1. 函数参数
print(2 + 3)            # 表达式 2+3 作为参数

# 2. 列表元素
numbers = [1, 2 + 3, 4 * 5]   # 每个元素都可以是表达式
print(numbers)          # [1, 5, 20]

# 3. 条件判断
x = 10
if x * 2 > 15:          # 表达式 x*2 作为条件
    print("大于 15")

# 4. 字符串格式化
name = "张三"
age = 45
info = f"姓名：{name}，年龄：{age + 1}岁后"   # 表达式 age+1 嵌入字符串
print(info)             # 姓名：张三，年龄：46岁后
```

::: note 表达式与可读性
复杂的表达式虽然能在一行内完成计算，但可能降低可读性。当表达式嵌套层次过多时，考虑拆分成多个步骤，用中间变量保存中间结果。`bmi = weight / (height ** 2)` 比把整个公式塞进条件判断中更清晰，也方便调试时检查中间值。
:::

学完本节，你已经掌握了 Python 的全部基础运算符和表达式的概念。这些运算符是构建程序的原子，后续的控制结构、函数、数据处理都建立在运算符之上。下一节将进入控制结构的学习，看看如何用条件判断和循环让程序具备逻辑分支和重复执行的能力。

## 练习题

### 第1题 概念理解

写出下面三个表达式的结果，并解释 `**` 运算符的结合方向和优先级如何影响结果。

```python
print(2 ** 3 ** 2)
print(-2 ** 2)
print(7 // 2)
```

::: details 参考答案
```python
print(2 ** 3 ** 2)  # 512
print(-2 ** 2)      # -4
print(7 // 2)       # 3
```

`**` 是从右到左结合的，`2 ** 3 ** 2` 等价于 `2 ** (3 ** 2)`，即 `2 ** 9` 等于 `512`。`-2 ** 2` 的结果是 `-4` 而非 `4`，因为 `**` 的优先级高于一元负号，先计算 `2 ** 2` 得 `4`，再取负得 `-4`。如果想要 `(-2) ** 2` 的结果 `4`，必须显式加括号。`7 // 2` 是整除，向下取整得到 `3`。
:::

### 第2题 代码编写

用位运算符实现一个简单的权限管理系统。定义读、写、删除三种权限分别为 1、2、4（二进制的不同位），给一个用户组合读写权限，再检查该用户是否有写权限和删除权限。

::: details 参考答案
```python
# 权限定义，每位代表一种权限
READ = 1     # 0001
WRITE = 2    # 0010
DELETE = 4   # 0100

# 用户拥有读和写权限
user_perm = READ | WRITE  # 0011，即 3

# 检查权限
has_write = bool(user_perm & WRITE)    # True
has_delete = bool(user_perm & DELETE)  # False

print(f"用户权限值：{user_perm}")
print(f"有写权限：{has_write}")
print(f"有删除权限：{has_delete}")
```

按位或 `|` 用于组合权限，`READ | WRITE` 把两个权限位合并。按位与 `&` 用于检查权限，结果非零表示有该权限，为零表示无。这种位运算权限管理在操作系统、数据库权限设计中很常见，用一组二进制位紧凑地表示多种权限的组合。
:::

### 第3题 进阶练习

利用逻辑运算符的短路求值特性，写一个表达式安全地获取可能为 `None` 的用户的姓名。要求当用户对象为 `None` 时不访问其 `name` 属性，避免 `AttributeError`，而是返回字符串 `"未知"`。再说明短路求值在这里如何起作用。

::: details 参考答案
```python
user = None
display_name = user and user.name or "未知"
print(display_name)  # 未知

user = {"name": "张三"}  # 假设这是一个有 name 属性的对象
# 用更清晰的等价写法
class User:
    def __init__(self, name):
        self.name = name

user = User("张三")
display_name = user and user.name or "未知"
print(display_name)  # 张三
```

`and` 的短路特性是：左侧为假值时直接返回左侧，不再评估右侧。当 `user` 为 `None` 时，`user and user.name` 中 `user` 是假值，整个 `and` 表达式返回 `None`，`user.name` 不会被访问，避免了 `AttributeError`。接着 `None or "未知"` 中 `None` 是假值，`or` 返回右侧的 `"未知"`。

当 `user` 是有效对象时，`user and user.name` 返回 `user.name`（非空字符串为真值），`user.name or "未知"` 返回 `user.name`。更清晰的等价写法是用条件表达式 `user.name if user else "未知"`。
:::

### 第4题 项目实践

命令行任务管理器中，任务有优先级（1 到 5 的整数）。请用链式比较写一个表达式，判断某个任务的优先级是否在合理范围内（1 到 5），并用逻辑运算符结合完成状态，判断该任务是否属于高优先级（1 或 2）且未完成。

::: details 参考答案
```python
priority = 2
completed = False

# 判断优先级是否在合理范围
is_valid = 1 <= priority <= 5
print(f"优先级合法：{is_valid}")  # True

# 判断是否为高优先级且未完成
is_urgent = (priority in (1, 2)) and (not completed)
print(f"高优先级且未完成：{is_urgent}")  # True
```

链式比较 `1 <= priority <= 5` 比 `1 <= priority and priority <= 5` 更简洁，且 `priority` 只求值一次。`priority in (1, 2)` 用成员运算符判断优先级是否为 1 或 2，比 `priority == 1 or priority == 2` 更简洁。`and` 组合高优先级和未完成两个条件，`not completed` 对布尔值取反。后续学习控制流后，可以用这个表达式筛选需要优先处理的任务。
:::

## 常见错误

**错误 1 · `TypeError: unsupported operand type(s) for +: 'int' and 'str'`**

原因:用 `+` 拼接字符串和数字。例如 `"年龄: " + 45`，`+` 运算符要求两边类型一致，字符串与整数不能直接相加。列表拼接也要求两边都是列表，`[1, 2] + 3` 同样会报错。

解决:字符串拼接数字时先用 `str()` 转换，例如 `"年龄: " + str(45)`，或直接用 f-string `f"年龄: {45}"`。列表追加单元素用 `append()`，追加一批用 `extend()`。

**错误 2 · `-2 ** 2` 得到 `-4` 而非 `4`**

```python
print(-2 ** 2)   # -4，不是 4
print((-2) ** 2) # 4
```

原因:`**` 的优先级高于一元负号，`-2 ** 2` 等价于 `-(2 ** 2)` 即 `-4`。这与数学直觉不符，容易在数值计算中引入隐蔽错误。

解决:负数参与幂运算时显式加括号 `(-2) ** 2`。涉及复杂表达式一律用括号标明计算顺序，不依赖优先级记忆。

**错误 3 · `-7 // 2` 结果是 `-4`（期望 `-3`）**

```python
print(-7 // 2)   # -4
print(-7 % 2)    # 1
```

原因:`//` 是向下取整操作，朝负无穷方向取整。`-7 / 2 = -3.5`，向下取整得到 `-4`。`%` 的结果与 `//` 配合满足 `a = (a // b) * b + (a % b)`，所以 `-7 % 2` 是 `1` 而非 `-1`。

解决:需要对负数向零截断时用 `int(a / b)`，例如 `int(-7 / 2)` 得到 `-3`。涉及负数的整除和取模要特别留意方向，必要时用 `math.floor` 或 `math.trunc` 明确意图。

**错误 4 · `0.1 + 0.2 == 0.3` 返回 `False`**

```python
print(0.1 + 0.2 == 0.3)  # False
print(0.1 + 0.2)         # 0.30000000000000004
```

原因:浮点数采用 IEEE 754 双精度表示，`0.1` 和 `0.2` 在二进制中都是无限循环小数，存储时被截断，相加后得到略大于 `0.3` 的值。`==` 直接比较二进制位，发现不等就返回 `False`。

解决:比较浮点数用容差判断 `abs(a - b) < 1e-9`，或用 `math.isclose(a, b)`。涉及金额等精度敏感场景使用 `decimal.Decimal`。
