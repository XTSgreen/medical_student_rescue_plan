# 0.2 让向量自己变好

0.1 里的两个向量是随机生成的，配对相似度之所以高，只因为构造时给正样本加了噪声。真实的编码器一开始并不知道什么该和什么配对，它输出的向量是随机的，配对相似度不会高于无关配对。要让配对相似度升上去，必须调整编码器里的参数。

调整参数需要回答一个具体问题：把某个参数改动一点，损失会变化多少。这个量就是导数。

## 0.2.1 导数：敏感度

**导数**（derivative）回答的问题是：自变量改动一点，函数值跟着改变多少。若 $f$ 在 $x$ 处可导，

$$
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
$$

把极限理解成一个近似就够了：$f(x+h) \approx f(x) + f'(x)\,h$，当 $h$ 很小时误差可以忽略。导数的符号说明变化方向，绝对值说明变化的剧烈程度。

## 0.2.2 偏导与梯度

模型有成千上万个参数，每个参数都影响损失。固定其余参数，只对其中一个求导，得到**偏导数**（partial derivative）。把所有偏导数按参数顺序排成一个向量，得到**梯度**（gradient）：

$$
\nabla L(\boldsymbol{\theta}) = \left[\frac{\partial L}{\partial \theta_1}, \frac{\partial L}{\partial \theta_2}, \ldots, \frac{\partial L}{\partial \theta_n}\right]^\top
$$

梯度的几何含义是损失上升最快的方向。相应地，$-\nabla L(\boldsymbol{\theta})$ 是损失下降最快的方向。

## 0.2.3 梯度下降

既然负梯度指向损失下降的方向，就沿着它走一小步，再重新计算梯度：

$$
\boldsymbol{\theta}_{k+1} = \boldsymbol{\theta}_k - \eta \, \nabla L(\boldsymbol{\theta}_k)
$$

$\eta$ 称为**学习率**（learning rate），控制每步走多远。这就是**梯度下降**（gradient descent）的全部结构，后续的 Adam 一类优化器都是在它的基础上调整步长与方向。

## 0.2.4 链式法则与反向传播

ConVIRT 的编码器是复合函数：胸片先经过 $f_v$，再经过 $g_v$，然后进入相似度、softmax 与对数，最后得到损失。求损失对最底层参数的导数，需要**链式法则**（chain rule）：

$$
\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}y}{\mathrm{d}h} \cdot \frac{\mathrm{d}h}{\mathrm{d}x}
$$

含义是：如果 $x$ 的影响先经过 $h$ 再传到 $y$，那么 $x$ 对 $y$ 的总影响是沿这条链条上每一级的局部影响相乘的结果。

反向传播做的就是这件事的自动化：从损失出发，沿着计算图从后往前逐级应用链式法则，得到每个参数的梯度。PyTorch 的 `backward()` 里没有别的东西。

## 代码验证

先看梯度下降在一次一维优化上的行为：

```python
def L(theta):
    return (theta - 2.0) ** 2 + 1.0


def grad(theta):
    return 2.0 * (theta - 2.0)


theta, eta = -3.0, 0.2
print("eta =", eta)
for step in range(1, 8):
    g = grad(theta)
    print(f"step {step}: theta = {theta:7.4f}  L = {L(theta):7.4f}  grad = {g:7.4f}")
    theta -= eta * g
print("最终 theta =", round(theta, 6), " 最优点 = 2.0")
```

输出：

```
eta = 0.2
step 1: theta = -3.0000  L = 26.0000  grad = -10.0000
step 2: theta = -1.0000  L = 10.0000  grad = -6.0000
step 3: theta =  0.2000  L =  4.2400  grad = -3.6000
step 4: theta =  0.9200  L =  2.1664  grad = -2.1600
step 5: theta =  1.3520  L =  1.4199  grad = -1.2960
step 6: theta =  1.6112  L =  1.1512  grad = -0.7776
step 7: theta =  1.7667  L =  1.0544  grad = -0.4666
最终 theta = 1.860032  最优点 = 2.0
```

每一步都朝梯度的反方向移动，损失从 $26.0$ 降到 $1.05$，参数逼近最优点 $2.0$ 但不会一步到位。梯度在接近最优点时变小，步长也随之变小，这是梯度下降收敛的方式。

再验证导数确实等于敏感度，并检验链式法则：

```python
def numerical_grad(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)


for x in [-1.0, 0.5, 2.0, 3.5]:
    print(f"x = {x:5.1f}  解析梯度 = {grad(x):7.4f}  数值梯度 = {numerical_grad(L, x):7.4f}")

x0 = 1.5
h0 = 2 * x0 + 1
print(f"x = {x0}, h = 2x + 1 = {h0}, y = h^2 = {h0 ** 2}")
print(f"dy/dh = {2 * h0}, dh/dx = 2")
print(f"dy/dx 解析 = {2 * h0 * 2}, 数值 = {numerical_grad(lambda x: (2 * x + 1) ** 2, x0):.4f}")
```

输出：

```
x =  -1.0  解析梯度 = -6.0000  数值梯度 = -6.0000
x =   0.5  解析梯度 = -3.0000  数值梯度 = -3.0000
x =   2.0  解析梯度 =  0.0000  数值梯度 =  0.0000
x =   3.5  解析梯度 =  3.0000  数值梯度 =  3.0000
x = 1.5, h = 2x + 1 = 4.0, y = h^2 = 16.0
dy/dh = 8.0, dh/dx = 2
dy/dx 解析 = 16.0, 数值 = 16.0000
```

用 $(f(x+h)-f(x-h))/(2h)$ 近似导数，与解析式的差在小数点后四位以内。$x = 2$ 处梯度为 $0$，对应最优点。链式法则的结果 $8 \times 2 = 16$ 与数值结果一致。

最后比较不同学习率的效果：

```python
for eta in [0.1, 0.5, 0.9, 1.1]:
    th = -3.0
    for _ in range(5):
        th -= eta * grad(th)
    print(f"eta = {eta:4}  5 步后 theta = {th:10.4f}  L = {L(th):12.4f}")
```

输出：

```
eta =  0.1  5 步后 theta =     0.3616  L =       3.6844
eta =  0.5  5 步后 theta =     2.0000  L =       1.0000
eta =  0.9  5 步后 theta =     3.6384  L =       3.6844
eta =  1.1  5 步后 theta =    14.4416  L =     155.7934
```

$\eta = 0.1$ 五步只走到 $0.36$，收敛缓慢；$\eta = 0.5$ 五步后精确落在 $2.0$，对这个二次函数而言正好一步到位；$\eta = 0.9$ 越过最优点到 $3.64$，损失与 $\eta=0.1$ 相同；$\eta = 1.1$ 直接发散，损失涨到 $155.8$。

## 练习题

1. 对 $L(\theta) = (\theta - 5)^2$，梯度是什么？在 $\theta = 3$ 处，梯度下降会把这个参数往哪个方向推？
2. 学习率取得过大会发生什么？取 $0.1$、$0.5$、$0.9$、$1.1$ 分别跑五步，观察 $L(\theta) = (\theta-2)^2 + 1$ 从 $\theta = -3$ 出发的结果。
3. 若 $y = \sigma(Wh)$，其中 $\sigma$ 是 ReLU，且 $Wh = -2$，$\partial y / \partial h$ 是什么？

### 拷打 AI

1. 这个损失对哪个参数求导？梯度的形状和参数的形状一致吗？
   及格标准：梯度张量形状与参数张量相同，逐元素对应。若 AI 声称梯度是标量，追问维度。
2. 梯度为 $0$ 是否一定意味着找到了最小值？
   及格标准：不一定。梯度为 $0$ 只说明是驻点，可能是极大值或鞍点，在非凸问题上尤其如此。
3. 论文声称使用梯度下降，是否意味着一定收敛？还缺哪些条件？
   及格标准：缺少条件。收敛还需要光滑性、合适的学习率、以及问题本身的性质。仅凭使用梯度下降不能推出收敛。
4. 反向传播经过了哪些中间变量？
   及格标准：从损失开始，依次经过对数、softmax、余弦相似度、投影 $g$、编码器 $f$。

## 参考答案

1. $L'(\theta) = 2(\theta - 5)$，在 $\theta = 3$ 处为 $-4$。梯度为负，梯度下降沿 $-\nabla L$ 即正方向移动，参数朝增大的方向走，趋向 $5$。
2. 学习率过小则收敛缓慢；过大则可能越过最优点来回振荡，甚至发散。数据见本节代码验证中学习率一项。
3. ReLU 在 $Wh = -2$ 处导数为 $0$，因此 $\partial y / \partial h = \mathbf{0}$。这就是 ReLU 饱和导致梯度消失的具体形态。

## 常见错误

**错误 1 · NaN 或 inf 出现在损失里**

原因：学习率过大，参数更新一步跨过最优区，损失发散。
解决：把学习率调小一到两个数量级后重跑，观察损失是否单调下降。见下面的验算。

**错误 2 · 把梯度为 0 当成训练完成**

原因：在非凸问题上，梯度为 0 的位置可能是鞍点或局部极大值。
解决：结合损失值、二阶信息或多次随机初始化判断，不要只看梯度是否归零。

**错误 3 · 链式法则中漏乘其中一级**

原因：复合层数较多时容易漏掉某一层的局部导数。
解决：用数值梯度检验。对一维参数做 $(f(x+h)-f(x-h))/(2h)$ 的近似，与解析梯度对比，偏差超过 $10^{-4}$ 就说明推导有误。
