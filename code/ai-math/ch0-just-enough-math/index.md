# 够用数学

线性代数、概率论与统计推断、最优化、信息论、数学分析这五章组成一条完整路线，每一章都展开到足以支撑方法创新的深度。这条路线起点偏高：一个只想读懂应用论文、调用现成模型的读者，很可能在向量空间公理或极限的严格定义前停下。

主线论文是 ConVIRT（Zhang et al., MLHC 2022），一篇用胸片与影像报告做图文对比学习的预训练方法。它的好处是全部数学都落在同一组公式上：两个编码器把图与文变成向量，向量两两算余弦相似度，相似度经 softmax 与负对数得到损失，损失求梯度更新参数。最后一节的对照论文是 MedCLIP（Wang et al., EMNLP 2022）。

## 一条应当自己讲得出来的链

读完五节之后，下面这条链应当能够不加查阅地讲出来。它是本章的验收标准。

数据是一批胸片与对应的报告。两种模态各自经过编码器与投影变成向量，落进同一个 $d$ 维空间。把一批胸片的向量与一批报告的向量两两做余弦相似度，得到一个方阵 $S$。把 $S$ 按行做 softmax 再取负对数，得到 InfoNCE 损失。损失对参数的梯度说明每个参数该往哪个方向改，优化器按梯度更新参数。训练结束后，用验证集挑选检查点，最后在测试集上评估一次。

最后一步需要说清楚。验证集用于选择超参数与检查点，测试集只在最后评估一次，不能一边看测试集一边改模型。ConVIRT 的验证把预训练得到的表示迁移到 4 个分类任务和 2 个检索任务上，确认它确实可迁移。完整的证据链是：损失下降，验证指标变好，下游与测试指标仍然变好，才说明表示学到了有用的信息。
