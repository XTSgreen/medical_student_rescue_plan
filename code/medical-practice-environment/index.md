## 章节定位

本章节聚焦医疗执业环境的现实压力。医疗行为天然带有风险与不确定性，医护人员在诊疗工作中除了面对疾病本身，还要应对来自系统、法律、舆论等多重外部压力。这五篇综述分别从系统挑战、外部施压、心理干预、暴力犯罪学、自杀流行病学五个层面展开，引用国内外流行病学数据、系统综述研究与公开案件资料，呈现医疗执业环境的全貌。
