# 互联网开发

<span class="chapter-tag">第一模块</span>

互联网开发是面向 Web 浏览器与服务器的软件开发方向，是当前计算机就业市场容量最大的领域之一。本模块将从最基础的 HTML、CSS、JavaScript 三大前端核心出发，带你逐步理解网页的结构、样式与交互逻辑，并延伸至后端开发。

## 学习路径建议

1. **001 前端开发** —— 建立对 HTML、CSS、JavaScript 三大核心技术的整体认知
2. **002 - 004 HTML 系列** —— 深入网页结构与可访问性
3. **005 - 007 CSS 系列** —— 掌握样式设计与性能管控
4. **008 - 011 JavaScript 系列** —— 从基础语法到异步编程与 ES6 新特性
5. **后端开发** —— 进入服务器端开发
