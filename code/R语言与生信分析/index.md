# R 语言与生信分析

<span class="chapter-tag">第二模块</span>

R 语言是统计与生物信息学领域最常用的编程语言之一。本模块包含两个互补的子方向：**R 语言教程**（从语法基础到机器学习、深度学习）与**生物信息技术**（从计算机基础到组学分析专题），适合医学/生信方向的同学系统性学习。

## 学习路径建议

### 路径 A：从零开始学 R

1. **001 R 语言基础** —— 安装 R / RStudio，掌握基本语法与数据结构
2. **002 R 语言数据清洗与预处理** —— 数据导入、清洗、变换
3. **003 R 语言与数据可视化** —— ggplot2 等可视化工具
4. **004 R 语言统计分析** —— 假设检验、回归分析等
5. **005 R 语言统计与建模** —— 进阶统计建模
6. **006-007 机器学习与深度学习** —— 进入 AI 方向

### 路径 B：直接学生信

1. **001 计算机基础初步** —— Linux / 命令行 / 文件系统
2. **002 生物信息资源** —— 常用数据库与工具
3. **003 序列分析与比对** —— BLAST / 序列对齐
4. **004-008 组学专题** —— 基因组、转录组、表观、蛋白质、系统生物学
