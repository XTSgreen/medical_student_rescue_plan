# 2.2 生物信息资源与工具

生物信息学研究的核心基础设施由三类资源构成：数据中心、数据库、数据标准格式。本章按这一层次组织，重点介绍各资源的定位、用途和典型访问方式。

## 2.2.1 国际主要数据中心

全球三大核酸数据中心通过 INSDC（国际核苷酸序列数据库协作）协议每日同步数据，向任一中心提交的序列会出现在另两个中心。

### NCBI

美国国家生物技术信息中心，隶属 NIH，是全球使用最频繁的生物信息数据中心。维护 PubMed、GenBank、Protein、SNP、GEO、SRA、ClinVar 等核心数据库，提供 Entrez 检索系统、BLAST 比对工具和 E-utilities 编程接口。

```python
from Bio import Entrez

Entrez.email = "your_email@example.com"

handle = Entrez.esearch(db="pubmed", term="TP53 AND cancer", retmax=10)
record = Entrez.read(handle)
handle.close()

pmid_list = record["IdList"]
print(f"找到 {record['Count']} 篇相关文献")

handle = Entrez.efetch(db="pubmed", id=pmid_list, rettype="abstract")
abstracts = handle.read()
handle.close()
```

### EBI

欧洲生物信息学研究所，位于英国剑桥。维护 Ensembl、UniProt、ENA、ArrayExpress、PDBe 等数据库，提供 InterPro、EMBOSS 等分析服务。

```python
import requests

server = "https://rest.ensembl.org"
endpoint = "/lookup/symbol/homo_sapiens/TP53"
response = requests.get(server + endpoint, headers={"Content-Type": "application/json"})

if response.ok:
    gene_info = response.json()
    print(f"基因ID: {gene_info['id']}")
    print(f"染色体位置: {gene_info['seq_region_name']}:{gene_info['start']}-{gene_info['end']}")
    print(f"基因方向: {gene_info['strand']}")
```

### DDBJ

日本 DNA 数据库，INSDC 创始成员之一，与 GenBank 和 ENA 数据同步，侧重亚洲研究机构的数据收集。

### 其他重要中心

- **CNCB/NGDC**：中国国家生物信息中心，中科院北京基因组研究所维护，提供国家基因组数据云平台
- **GISAID**：流感及新冠病毒基因组共享平台，新冠疫情期间成为全球 SARS-CoV-2 数据主要来源
- **wwPDB**：全球蛋白质数据银行联盟，成员包括 RCSB PDB、PDBe、PDBj，统一维护 PDB 结构数据库

## 2.2.2 核心数据库分类

### 核酸序列数据库

核酸序列数据库存储 DNA/RNA 序列及注释。**RefSeq** 提供人工审校的高质量参考序列，常作为分析的标准对照。

- **GenBank**：NCBI 维护的 INSDC 核心库，收录所有公开核酸序列
- **ENA**：EBI 维护的欧洲核酸档案，强调归档优先与数据可追溯性
- **RefSeq**：NCBI 审校参考序列，ID 规范为 `NM_`（mRNA）、`NR_`（非编码 RNA）、`NP_`（蛋白）
- **SRA**：高通量测序原始读档，存储 Illumina、PacBio、Nanopore 等平台数据

```python
from Bio import SeqIO

for record in SeqIO.parse("sequence.gb", "genbank"):
    print(f"序列ID: {record.id}, 长度: {len(record.seq)} bp")
    for feature in record.features:
        if feature.type == "gene":
            gene_name = feature.qualifiers.get("gene", ["未知"])[0]
            print(f"  基因: {gene_name}, 位置: {feature.location}")
```

SRA 数据通过 SRA Toolkit 下载与转换：

```bash
# 安装: conda install -c bioconda sra-tools

```

### 蛋白质序列数据库

**UniProt** 是蛋白质功能研究的首选数据库，整合了人工审校的 Swiss-Prot 和自动注释的 TrEMBL。

- **UniProtKB/Swiss-Prot**：人工审校高质量注释
- **UniProtKB/TrEMBL**：自动注释
- **Pfam**：蛋白质家族与结构域，使用隐马尔可夫模型描述
- **InterPro**：整合 Pfam、SMART、PROSITE 等多个特征数据库

```python
import requests

uniprot_id = "P04637"  # TP53
url = f"https://rest.uniprot.org/uniprotkb/{uniprot_id}.json"
response = requests.get(url)

if response.ok:
    data = response.json()
    print(f"蛋白质: {data['proteinDescription']['recommendedName']['fullName']['value']}")
    print(f"物种: {data['organism']['scientificName']}")
    for comment in data['comments']:
        if comment['commentType'] == 'FUNCTION':
            print(f"功能: {comment['texts'][0]['value']}")
```

::: tip Pfam 结构域搜索

:::

### 结构数据库

结构数据库存储生物大分子三维结构，是理解分子功能与相互作用的关键。

- **PDB**：X 射线晶体学、核磁共振、冷冻电镜解析的结构数据
- **AlphaFold DB**：DeepMind 提供的预测结构，覆盖超过 2 亿个蛋白质
- **SCOP/CATH**：蛋白质结构分类系统
- **EMDB**：冷冻电镜三维重构数据

```python
from Bio.PDB import PDBParser
import numpy as np

parser = PDBParser()
structure = parser.get_structure("1TUP", "1tup.pdb")

model = structure[0]
chain = model['A']
ca_atom = chain[(' ', 100, ' ')]['CA']
ca_atom2 = chain[(' ', 101, ' ')]['CA']

vector = ca_atom.coord - ca_atom2.coord
distance = np.sqrt(np.sum(vector * vector))
print(f"残基间CA距离: {distance:.2f} Å")
```

### 基因组数据库

基因组数据库提供完整基因组序列和注释。**Ensembl** 与 **UCSC Genome Browser** 因丰富的注释轨道和可视化功能，是基因组研究中最常用的工具。

- **Ensembl**：EBI 与 Sanger Institute 联合维护，覆盖人类、小鼠及非动物物种
- **UCSC Genome Browser**：加州大学圣克鲁斯分校，以可视化轨道著称
- **GENCODE**：人类和小鼠基因组注释的黄金标准
- **1000 Genomes Project**：人类群体遗传变异基准图谱
- **TAIR**：拟南芥基因组数据库
- 模式生物库：**WormBase**、**FlyBase**、**SGD**、**MGI**、**ZFIN**

```python
import requests

server = "https://rest.ensembl.org"
gene_id = "ENSG00000141510"  # TP53

# 获取基因序列
response = requests.get(f"{server}/sequence/id/{gene_id}",
                       headers={"Content-Type": "application/json"})
if response.ok:
    data = response.json()
    print(f"序列长度: {len(data['seq'])} bp")

# 获取转录本信息
response = requests.get(f"{server}/lookup/id/{gene_id}?expand=1",
                       headers={"Content-Type": "application/json"})
if response.ok:
    gene_data = response.json()
    print(f"转录本数量: {len(gene_data['Transcript'])}")
```

### 转录调控数据库

转录调控数据库存储转录因子结合位点、表观遗传修饰和基因调控网络。

- **ENCODE**：人类基因组功能元件图谱，包括转录因子结合位点、增强子、染色质状态
- **Roadmap Epigenomics**：人类表观遗传修饰图谱
- **JASPAR**：转录因子结合谱（PWM）数据库，用于结合位点预测
- **ChIP-Atlas / CistromeDB**：ChIP-seq 和 ATAC-seq 整合数据库
- **RegulonDB**：大肠杆菌基因调控网络

```python
from Bio import motifs
from Bio.Seq import Seq

motif_matrix = {
    'A': [3, 0, 0, 0, 0, 0],
    'C': [0, 5, 0, 0, 0, 0],
    'G': [2, 0, 5, 0, 5, 0],
    'T': [0, 0, 0, 5, 0, 5]
}
motif = motifs.Motif(counts=motif_matrix)
motif.background = {'A': 0.25, 'C': 0.25, 'G': 0.25, 'T': 0.25}

test_seq = Seq("ACGTACGTGTCAGTACGT")
for pos, score in motif.search(test_seq, threshold=5.0):
    print(f"位置: {pos}, 得分: {score:.2f}, 序列: {test_seq[pos:pos+motif.length]}")
```

### 代谢通路数据库

- **Reactome**：人工审校的人类生物通路数据库
- **BioCyc**：包含 MetaCyc（实验验证通路）和 EcoCyc（大肠杆菌）等子库
- **WikiPathways**：社区维护的开放通路库

## 2.2.3 数据检索与提交

### Entrez 系统与 E-utilities

Entrez 是 NCBI 的统一检索平台，支持跨库搜索。E-utilities 是其编程接口，包括 ESearch、EFetch、ESummary、ELink 等工具。R 语言用户可使用 **rentrez** 包实现等价功能。

```python
from Bio import Entrez

Entrez.email = "your_email@example.com"

search_term = "TP53[Gene] AND Homo sapiens[Organism] AND RefSeq[Filter]"
handle = Entrez.esearch(db="nucleotide", term=search_term, retmax=20)
record = Entrez.read(handle)
handle.close()

id_list = record["IdList"]
print(f"找到 {record['Count']} 条记录")

handle = Entrez.efetch(db="nucleotide", id=id_list, rettype="gb", retmode="xml")
records = Entrez.read(handle)
handle.close()

for record in records[:5]:
    print(f"序列ID: {record['GBSeq_primary-accession']}, 长度: {record['GBSeq_length']} bp")
```

```r
# rentrez 等价实现
library(rentrez)

entrez_email("your_email@example.com")
search_res <- entrez_search(db="nucleotide",
                            term="TP53[Gene] AND Homo sapiens[Organism] AND RefSeq[Filter]",
                            retmax=20)

records <- entrez_fetch(db="nucleotide", id=search_res$ids, rettype="gb")
```

::: warning E-utilities 使用规范
- 必须设置有效邮箱（NCBI 要求）
- 大批量请求控制在每秒 3 次以内
- 工作日 9:00-17:00（美东时间）避免提交大批量任务
:::

### BLAST 序列搜索

BLAST 是序列相似性搜索的事实标准，使用启发式算法平衡速度和灵敏度。主要模式包括：

- **BLASTn**：核酸 vs 核酸
- **BLASTp**：蛋白 vs 蛋白
- **BLASTx**：核酸翻译 vs 蛋白
- **tBLASTn**：蛋白 vs 核酸翻译
- **tBLASTx**：核酸翻译 vs 核酸翻译
- **PSI-BLAST**：迭代搜索，发现远缘同源

```bash
# 本地 BLAST 流程
# 安装: conda install -c bioconda blast

makeblastdb -in reference_proteins.fasta -dbtype prot -out my_database
blastp -query query.fasta -db my_database -out results.txt -evalue 0.001 -outfmt 6

# -outfmt 6 输出列：
# qseqid sseqid pident length mismatch gapopen qstart qend sstart send evalue bitscore
```

```python
from Bio.Blast import NCBIWWW, NCBIXML

query_seq = "MEEPQSDPSVEPPLSQETFSDLWKLLPENNVLSPLPSQAMDDLMLSPDDIEQWFTEDPGP"
result_handle = NCBIWWW.qblast("blastp", "nr", query_seq, hitlist_size=10)

for record in NCBIXML.parse(result_handle):
    for alignment in record.alignments[:5]:
        hsp = alignment.hsps[0]
        print(f"{alignment.hit_id}: E值={hsp.expect:.2e}, "
              f"一致性={hsp.identities}/{hsp.align_length}")
```

### 数据提交工具

向数据库提交序列和实验数据需使用专门工具：

- **BankIt**：GenBank 在线提交工具
- **Sequin / tbl2asn**：NCBI 桌面提交工具
- **Webin**：ENA 提交门户
- **SRA Submission**：高通量测序原始数据提交
- **BioProject / BioSample**：组织项目元数据和样本信息

```python
from Bio import SeqIO
from Bio.Seq import Seq
from Bio.SeqRecord import SeqRecord
from Bio.SeqFeature import SeqFeature, FeatureLocation

seq = Seq("ATGGCCGTTACCGAAGGTGAAACCGTTGAAATGACCGGTGAACTGACCGGTGAACTG")
record = SeqRecord(seq, id="MYGENE001", name="MyGene",
                  description="Example gene for submission",
                  annotations={"molecule_type": "DNA",
                               "organism": "Homo sapiens"})

record.features.append(SeqFeature(
    FeatureLocation(0, 57), type="gene",
    qualifiers={"gene": "example_gene", "locus_tag": "EG001"}
))
record.features.append(SeqFeature(
    FeatureLocation(0, 57), type="CDS",
    qualifiers={"gene": "example_gene", "codon_start": 1,
                "transl_table": 1, "product": "example protein",
                "translation": str(seq.translate())}
))

with open("submission.gb", "w") as f:
    SeqIO.write(record, f, "genbank")
```

## 2.2.4 生物本体与术语库

生物本体为数据提供统一语义框架，定义概念间的关系（如 `is_a`、`part_of`），是功能富集分析的基础。

### Gene Ontology (GO)

GO 是使用最广泛的本体，包含三个分支：**分子功能**（Molecular Function）、**生物过程**（Biological Process）、**细胞组分**（Cellular Component）。GO 富集分析用于判断一组差异基因在功能上是否显著富集。

```python
from scipy import stats
import pandas as pd

# 模拟差异基因列表与背景基因集
diff_genes = {'TP53', 'BRCA1', 'MYC', 'EGFR', 'KRAS'}
background = {'TP53', 'BRCA1', 'MYC', 'EGFR', 'KRAS', 'PIK3CA',
              'PTEN', 'AKT1', 'MTOR', 'RB1', 'CCND1'}

# GO:0006915（凋亡过程）注释的基因集
go_genes = {'TP53', 'BRCA1', 'PTEN', 'RB1'}

# 超几何检验
k = len(diff_genes & go_genes)              # 差异基因中命中 GO 的数量
n = len(diff_genes)                         # 差异基因总数
K = len(background & go_genes)              # 背景中命中 GO 的数量
N = len(background)                         # 背景基因总数

pval = stats.hypergeom.sf(k - 1, N, K, n)
print(f"GO:0006915 富集 p 值: {pval:.4e}")
```

## 2.2.5 数据标准与交换格式

统一格式使不同软件和数据库之间可以交换数据。本节按数据类型归纳主要格式。

### FASTA / FASTQ

**FASTA** 存储序列，**FASTQ** 在 FASTA 基础上增加每个碱基的质量值（Phred score），用于存储测序读数。

```
# FASTA
>gene1 Homo sapiens TP53
ATGGAGGAGCCGCAGTCAGATCCTAGCGTCGAGCCCCCTCTGAGTCAGGAAACATTTTCAG

# FASTQ
@SEQ_ID
GATTTGGGGTTCAAAGCAGTATCGATCAAATAGTAAATCCATTTGTTCAACTCACAGTTT
+
!''*((((***+))%%%++)(%%%%).1***-+*''))**55CCF>>>>>>CCCCCCC65
```

```python
from Bio import SeqIO

for record in SeqIO.parse("example.fastq", "fastq"):
    print(f"{record.id}: {record.seq[:30]}..., 质量: {record.letter_annotations['phred_quality'][:10]}")
```

### SAM / BAM / CRAM

存储序列比对结果。SAM 为文本格式，BAM 为二进制压缩格式，CRAM 为更高效的压缩格式。

- **FLAG**：比对标志位
- **CIGAR**：比对操作字符串（M=匹配/错配，I=插入，D=缺失）
- **MAPQ**：比对质量

```python
import pysam

bamfile = pysam.AlignmentFile("aligned.bam", "rb")
for read in bamfile.fetch('chr1', 1000, 2000):
    print(f"{read.query_name}: pos={read.reference_start}, mapq={read.mapping_quality}")
bamfile.close()
```

### VCF / BCF / GVCF

存储遗传变异。VCF 为文本格式，BCF 为二进制格式，GVCF 包含所有位点信息（含非变异位点）。

VCF 关键字段：CHROM、POS、ID、REF、ALT、QUAL、FILTER、INFO、FORMAT、样本列。

```python
from cyvcf2 import VCF

for variant in VCF("variants.vcf"):
    print(f"{variant.CHROM}:{variant.POS} {variant.REF}>{variant.ALT}, "
          f"QUAL={variant.QUAL}")
```

::: tip VCF 注释顺序
位置为 1-based；REF 为参考基因组上的碱基；ALT 为样本观察到的碱基，多等位基因用逗号分隔。
:::

### GFF / GTF / GFF3

存储基因组注释。GFF3 是目前最常用版本，采用 9 列制：seqid、source、type、start、end、score、strand、phase、attributes。

```
##gff-version 3
chr1	NCBI	gene	1000	5000	.	+	.	ID=gene001;Name=TP53
chr1	NCBI	mRNA	1000	5000	.	+	.	ID=transcript001;Parent=gene001
chr1	NCBI	exon	1000	1500	.	+	.	ID=exon001;Parent=transcript001
chr1	NCBI	CDS	1200	1500	.	+	0	ID=cds001;Parent=transcript001
```

```python
import gffutils

db = gffutils.create_db("annotations.gff3", dbfn="annotations.db",
                        force=True, keep_order=True)
for gene in db.features_of_type('gene'):
    print(f"{gene.id}: {gene.chrom}:{gene.start}-{gene.end} ({gene.strand})")
```

::: warning 位置系统差异
- BED 起始位置为 **0-based**，半开区间
- GFF3 / VCF / SAM 位置为 **1-based**，闭合区间
跨格式转换时需特别处理，否则易引入 off-by-one 错误。
:::

### BED / bigBed

存储基因组区间。BED 为文本格式，bigBed 为二进制索引格式，适合大数据集。BED 必填三列为 chrom、chromStart（0-based）、chromEnd（半开区间）。

### 其他格式

- **WIG / bigWig**：连续数值（如测序覆盖度）
- **PDB / mmCIF**：蛋白质三维结构
- **mzML / mzXML**：质谱数据
- **HDF5 / H5AD**：单细胞测序数据，H5AD 是基于 HDF5 的 Scanpy/AnnData 标准格式
- **MAGE-TAB / ISA-Tab**：表达实验元数据

```python
import h5py
import numpy as np

with h5py.File("single_cell_data.h5", "w") as f:
    grp = f.create_group("expression")
    grp.create_dataset("matrix", data=np.random.rand(100, 2000))
    grp.create_dataset("gene_names",
                       data=np.array([f"Gene_{i}" for i in range(2000)], dtype='S'))
    grp.create_dataset("cell_barcodes",
                       data=np.array([f"Cell_{i}" for i in range(100)], dtype='S'))
```

## 2.2.6 Bioconductor 简介

**Bioconductor** 是基于 R 语言的生物信息分析开源项目，提供超过 2000 个相互协作的 R 包，覆盖基因组学、转录组学、表观组学、蛋白质组学等方向。其核心数据结构包括 `SummarizedExperiment`、`GRanges`、`ExpressionSet` 等。

常用包：

- **GenomicRanges**：基因组区间操作（类 BED 工具）
- **DESeq2 / edgeR / limma**：差异表达分析
- **Biostrings**：序列处理
- **VariantAnnotation**：VCF 解析与注释
- **rtracklayer**：导入/导出 GFF、BED、WIG 等格式
- **AnnotationDbi / org.Hs.eg.db**：基因注释查询
- **clusterProfiler**：GO 与 KEGG 富集分析

```r
# 差异表达分析示例（DESeq2）
library(DESeq2)

dds <- DESeqDataSetFromMatrix(countData = counts,
                              colData = coldata,
                              design = ~ condition)
dds <- DESeq(dds)
res <- results(dds)
summary(res)
```


## 2.2.7 资源选择建议

实际研究中按数据类型选择对应资源：

| 数据类型 | 首选数据库 | 编程接口 |
|---------|-----------|---------|
| 核酸序列 | GenBank / RefSeq / ENA | Biopython、rentrez |
| 蛋白质序列 | UniProt | REST API |
| 蛋白结构 | PDB / AlphaFold DB | Biopython.PDB |
| 基因组注释 | Ensembl / GENCODE | Ensembl REST API |
| 基因表达 | GEO / ArrayExpress | GEOparse |
| 蛋白互作 | STRING / BioGRID | STRING API |
| 通路 | KEGG / Reactome | KEGG REST API |
| 变异 | dbSNP / ClinVar / gnomAD | E-utilities |
| 调控 | ENCODE / JASPAR | ENCODE portal |

掌握上述资源后，可结合 **Bioconductor**（R）或 **Biopython / scikit-bio / Bioconductor**（跨语言）构建完整的分析流程。
