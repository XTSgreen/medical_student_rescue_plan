# 2.3 序列分析与比对

序列分析与比对是生物信息学的核心方法。从一条DNA序列的碱基组成，到两条序列的相似性比对，再到多条序列的进化关系推断，这些方法贯穿生物信息学研究的各个环节。本章系统介绍序列特征解析、双序列比对、多序列比对、基序与结构域发现、分子进化分析等内容，并给出R语言（Biostrings、msa、ape）与Python（Biopython）的实现示例。

## 2.3.1 序列特征解析

序列特征解析是对单条序列进行基本性质分析的过程，是后续比对与功能分析的基础。碱基组成、GC含量、开放阅读框、重复序列等特征会直接影响分析策略的选择与结果解读。

### 碱基组成与GC含量

GC含量指序列中G和C碱基所占的百分比。不同物种的基因组GC含量差异显著，人类基因组约为41%，某些细菌可超过70%。同一基因组内不同区域的GC含量也存在差异，基因密集区往往GC含量较高。GC含量影响DNA的熔解温度，是引物设计、物种判断和基因位置预测的重要参考。GC偏斜度定义为（G-C）/（G+C），在预测复制起始点和链不对称性方面有重要应用。

```python
from Bio.SeqUtils import gc_fraction
from Bio.Seq import Seq

seq = Seq("ATGGAGGAGCCGCAGTCAGATCCTAGCGTCGAGCCCCCTCTGAGTCAGGAAACATTTTCAGACCTATGGAAACTACTTCCTGAAAACAACGTTCTGTCCCCCTTGCCGTCCCAAGCAATGGATGATTTGATGCTGTCCCCGGACGATATTGAACAATGGTTCACTGAAGACCCAGGTCCAGATGA")

gc_content = gc_fraction(seq) * 100
g_count = seq.count('G')
c_count = seq.count('C')
a_count = seq.count('A')
t_count = seq.count('T')
gc_skew = (g_count - c_count) / (g_count + c_count)
at_skew = (a_count - t_count) / (a_count + t_count)

print(f"GC含量: {gc_content:.2f}%")
print(f"GC偏斜度: {gc_skew:.4f}")
print(f"AT偏斜度: {at_skew:.4f}")
```

R语言中可以使用Biostrings包完成同样的分析。Biostrings是Bioconductor生态中处理生物序列的核心包，支持DNAString、RNAString、AAString等序列类。

```r
library(Biostrings)

seq <- DNAString("ATGGAGGAGCCGCAGTCAGATCCTAGCGTCGAGCCCCCTCTGAGTCAGGAAACATTTTCAGACCTATGGAAACTACTTCCTGAAAACAACGTTCTGTCCCCCTTGCCGTCCCAAGCAATGGATGATTTGATGCTGTCCCCGGACGATATTGAACAATGGTTCACTGAAGACCCAGGTCCAGATGA")

base_freq <- alphabetFrequency(seq, baseOnly = TRUE)
gc_content <- (base_freq["G"] + base_freq["C"]) / sum(base_freq) * 100
gc_skew <- (base_freq["G"] - base_freq["C"]) / (base_freq["G"] + base_freq["C"])

cat(sprintf("GC含量: %.2f%%\n", gc_content))
cat(sprintf("GC偏斜度: %.4f\n", gc_skew))
```

### 开放阅读框预测

开放阅读框（ORF）是从起始密码子ATG到终止密码子（TAA、TAG、TGA）之间的连续编码区域。ORF预测是基因预测的基础，需要同时考虑六种阅读框（正链三种、负链三种）。原核生物的ORF通常直接对应蛋白质编码基因，真核生物则需要考虑剪接位点。

```python
from Bio.Seq import Seq

dna_seq = Seq("ATGGAGGAGCCGCAGTCAGATCCTAGCGTCGAGCCCCCTCTGAGTCAGGAAACATTTTCAGACCTATGGAAACTACTTCCTGAAAACAACGTTCTGTCCCCCTTGCCGTCCCAAGCAATGGATGATTTGATGCTGTCCCCGGACGATATTGAACAATGGTTCACTGAAGACCCAGGTCCAGATGATAGCTGA")

stop_codons = ['TAA', 'TAG', 'TGA']

for strand, seq in [('+', dna_seq), ('-', dna_seq.reverse_complement())]:
    for frame in range(3):
        orf_start = None
        for pos in range(frame, len(seq) - 2, 3):
            codon = str(seq[pos:pos+3])
            if codon == 'ATG' and orf_start is None:
                orf_start = pos
            elif codon in stop_codons and orf_start is not None:
                orf_len = pos + 3 - orf_start
                if orf_len >= 150:
                    protein = seq[orf_start:pos+3].translate()
                    print(f"链{strand} 阅读框{frame}: ORF位置 {orf_start}-{pos+3}, 长度{orf_len}bp, 蛋白质长度{len(protein)-1}aa")
                orf_start = None
```

### 序列转换与模糊碱基

序列转换包括互补、反向和反向互补三种操作。设计PCR引物时需要获取模板链的反向互补链序列。IUPAC模糊码用于表示碱基位置的不确定性，N表示任意碱基，R表示嘌呤（A或G），Y表示嘧啶（C或T），在处理低质量位点、设计简并引物和表示多态性位点时常用。

```r
library(Biostrings)

seq <- DNAString("ATGGAGGAGCCGCAGTCAGATCCTAGCG")

complement_seq <- complement(seq)
reverse_seq <- reverse(seq)
rev_comp <- reverseComplement(seq)

cat("原始序列:  ", as.character(seq), "\n")
cat("互补序列:  ", as.character(complement_seq), "\n")
cat("反向互补:  ", as.character(rev_comp), "\n")

# 翻译为蛋白质
protein <- translate(seq)
cat("翻译蛋白:  ", as.character(protein), "\n")
```

### 蛋白质理化性质

等电点（pI）是蛋白质净电荷为零时的pH值，分子量是所有氨基酸残基的质量之和。这两个参数在蛋白质纯化（等电聚焦、离子交换层析）和质谱鉴定中必不可少。疏水性图谱基于Kyte-Doolittle标度，沿序列滑动计算平均疏水性，连续疏水区域通常对应跨膜螺旋或核心疏水区。

```python
from Bio.SeqUtils.ProtParam import ProteinAnalysis

protein_seq = "MEEPQSDPSVEPPLSQETFSDLWKLLPENNVLSPLPSQAMDDLMLSPDDIEQWFTEDPGP"
analyzed = ProteinAnalysis(protein_seq)

mw = analyzed.molecular_weight()
pi = analyzed.isoelectric_point()
aa_percent = analyzed.get_amino_acids_percent()
hydrophobic_ratio = aa_percent['A'] + aa_percent['V'] + aa_percent['L'] + aa_percent['I'] + aa_percent['F'] + aa_percent['W']

print(f"长度: {len(protein_seq)}aa, 分子量: {mw/1000:.2f}kDa, 等电点: {pi:.2f}")
print(f"疏水残基比例: {hydrophobic_ratio:.2%}")
```

::: tip 信号肽与跨膜预测
SignalP预测信号肽，TMHMM和Phobius预测跨膜结构域。Phobius能同时区分信号肽和跨膜螺旋，避免误判。DeepLoc基于深度学习预测亚细胞定位，准确率较高。
:::

## 2.3.2 双序列比对

双序列比对通过将两条序列对齐排列，找出相似性与差异性，用于判断同源性、推断功能和估计进化距离。获得新序列后，最直接的功能推断方法就是与数据库中已知序列比对。

### 动态规划算法

双序列比对的算法基础是动态规划，通过构建得分矩阵寻找最优比对路径。

**Needleman-Wunsch算法**是全局比对，对两条序列的整个长度进行比对，适用于长度相近且整体相似的序列。回溯从矩阵右下角到左上角。

**Smith-Waterman算法**是局部比对，只比对最相似的片段，适用于长度差异大或只有局部区域相似的序列。得分矩阵中不允许负值，回溯从最大值开始到零值止。

```python
from Bio import pairwise2
from Bio.pairwise2 import format_alignment

seq1 = "ATGGAGGAGCCGCAGT"
seq2 = "ATGGAGCCGCAGTCAG"

global_aligns = pairwise2.align.globalms(seq1, seq2, 2, -1, -0.5, -0.1)
print("全局比对 (Needleman-Wunsch):")
for a in global_aligns[:2]:
    print(format_alignment(*a))

local_aligns = pairwise2.align.localms(seq1, seq2, 2, -1, -0.5, -0.1)
print("局部比对 (Smith-Waterman):")
for a in local_aligns[:2]:
    print(format_alignment(*a))
```

点矩阵法（Dot plot）将两条序列作为矩阵的行和列，相同碱基的格点标记，相似区域形成对角线，插入缺失导致中断。该方法直观展示相似性模式，适合发现重复区域和重排事件。

### 打分矩阵

打分矩阵评估碱基或氨基酸替换的得分，基于生物学观察：某些替换在进化中更常出现，应给予更高得分。

**PAM系列**基于观察到的氨基酸替换频率构建。PAM1表示每100个残基平均发生1次可接受突变，PAM250对应更远的进化距离。比对近缘序列选小PAM值，远缘序列选大PAM值。

**BLOSUM系列**基于蛋白质家族保守模块的替换频率。BLOSUM62最常用，基于同一性不超过62%的模块构建；BLOSUM90适合高度相似序列，BLOSUM45适合远缘序列。BLOSUM直接基于观察数据，不依赖外推，多数实际应用中表现更好。

DNA替代矩阵区分**转换**（嘌呤间A-G或嘧啶间C-T）和**颠换**（嘌呤与嘧啶间），转换在进化中更常出现，罚分较轻。

### 空位罚分

**仿射空位罚分**是最常用模型，将空位罚分分为开罚分（gap open）和延伸罚分（gap extend），开罚分远大于延伸罚分，反映连续插入缺失比分散插入缺失更可能发生。较小空位罚分产生更多空位，较大空位罚分倾向连续匹配区域。

### BLAST家族

动态规划复杂度为O(mn)，对长序列和大规模数据库搜索太慢。**BLAST**通过牺牲一定灵敏度大幅提高速度，是目前数据库搜索的主流方法。

| 工具 | 查询序列 | 数据库 | 用途 |
|------|----------|--------|------|
| blastn | 核酸 | 核酸 | 核酸序列搜索 |
| blastp | 蛋白质 | 蛋白质 | 蛋白质序列搜索 |
| blastx | 核酸翻译 | 蛋白质 | 新转录本功能推断 |
| tblastn | 蛋白质 | 核酸翻译 | 基因组中找蛋白同源 |
| tblastx | 核酸翻译 | 核酸翻译 | 远缘核酸同源检测 |

BLAST的核心思想是**词长（k-mer）种子扩展**：先在查询序列中找长度为w的词，在数据库中搜索精确匹配作为种子，再向两侧扩展。较短词长提高灵敏度但降低速度。

**E值**表示随机情况下期望得到的得分不低于当前得分的命中数，E值越小越显著。**比特分**是标准化得分，不受打分矩阵和空位罚分影响，便于不同比对间比较。E值小于0.05或0.01通常被认为具有统计显著性。

```bash
# 构建BLAST数据库
makeblastdb -in custom_sequences.fasta -dbtype nucl -out custom_db

# blastn搜索
blastn -query query.fasta -db custom_db -evalue 1e-5 -outfmt 6 -num_threads 4 -out blast_results.tsv

# blastp搜索
blastp -query protein_query.fasta -db nr -evalue 1e-10 -matrix BLOSUM62 -outfmt "6 qseqid sseqid pident length evalue bitscore" -out blastp_results.tsv

# 短序列比对（引物搜索）
blastn -query primers.fasta -db custom_db -task blastn-short -evalue 1000 -word_size 7 -out short_blast.tsv
```

::: warning 低复杂度区域过滤
BLAST默认使用DUST（核酸）和SEG（蛋白质）过滤低复杂度区域。低复杂度区域易产生虚假高分匹配，搜索前必须屏蔽。重复序列也需用RepeatMasker屏蔽，否则可能导致假阳性。
:::

E值的计算基于Karlin-Altschul统计理论，随机序列比对得分服从极值分布：

```python
import numpy as np

m, n = 1000, 10000000  # 查询长度, 数据库长度
K, lam = 0.13, 0.318   # Karlin-Altschul参数
raw_score = 50

E_value = K * m * n * np.exp(-lam * raw_score)
bit_score = (lam * raw_score - np.log(K)) / np.log(2)
P_value = 1 - np.exp(-E_value)

print(f"E值: {E_value:.2e}, 比特分: {bit_score:.2f}, P值: {P_value:.2e}")
```

## 2.3.3 多序列比对

多序列比对（MSA）将三条或更多序列同时比对，揭示序列间的保守性与变异性模式，是构建系统发育树、发现功能位点和蛋白质结构预测的基础。

### 算法策略

多序列比对的计算复杂度随序列数量指数增长，精确动态规划只适用于少量短序列，实际应用采用近似策略。

**渐进比对**（Progressive alignment）是经典策略，Clustal系列采用此方法。先计算所有序列两两距离，构建引导树，再按拓扑顺序逐步加入序列。优点是速度快，缺点是早期比对错误无法纠正。

**迭代比对**通过多轮迭代优化结果。MUSCLE采用两阶段迭代，先快速构建初始比对，再通过树重分割和重新比对优化。MAFFT提供多种策略：fft-ns-i用快速傅里叶变换加速，l-ins-i考虑局部一致性，e-ins-i允许长插入缺失。

**一致性比对**整合多个双序列比对结果。T-Coffee先生成所有序列对的双序列比对和结构比对，计算一致性权重，再基于一致性构建多序列比对。MSAProbs结合HMM和渐进比对，利用后验概率指导决策。

**基于HMM的方法**将多序列比对建模为概率模型。HMMER构建配置文件HMM表示序列家族特征，用于数据库同源搜索。

```bash
# Clustal Omega
clustalo -i input.fasta -o aligned.fasta --outfmt fasta --force

# MAFFT快速策略
mafft --auto input.fasta > aligned.fasta

# MAFFT高精度策略
mafft --linsi input.fasta > aligned_linsi.fasta

# MUSCLE
muscle -in input.fasta -out aligned_muscle.fasta

# trimAl清洗比对
trimal -in aligned.fasta -out trimmed.fasta -automated1
```

### R语言实现多序列比对

R语言中msa包封装了Clustal Omega、ClustalW和MUSCLE，可以直接在R环境中调用。比对结果可转换为ape包的bin对象，用于后续系统发育分析。

```r
library(msa)
library(ape)

# 读取序列
sequences <- readDNAStringSet("input_sequences.fasta")

# 使用Clustal Omega进行多序列比对
alignment <- msa(sequences, method = "ClustalOmega")

# 转换为ape包的bin格式用于建树
aln_bin <- as.DNAbin(alignment)

# 计算距离矩阵
dist_matrix <- dist.dna(aln_bin, model = "K80")

# 构建NJ树
nj_tree <- nj(dist_matrix)

# 绘制树
plot(nj_tree, main = "Neighbor-Joining Tree")
add.scale.bar()
```

::: tip 工具选择
MAFFT的fft-ns-i适合大量序列快速比对，l-ins-i适合需要高准确率的比对。PRANK考虑插入删除的进化模型，特别适合进化分析。比对清洗推荐trimAl的automated1策略。
:::

### 比对后处理

比对清洗去除不可靠区域，保留高质量列。Gblocks用严格统计标准筛选保守列，trimAl提供多种自动策略，BMGE基于熵值和相似性选择列。构建系统发育树时，清洗后的比对能减少噪声影响。

常用比对格式：FASTA（最简单通用）、Clustal（带序列编号）、Phylip（系统发育分析标准格式）、Nexus（包含树和比对信息）、Stockholm（Pfam数据库格式）。

**序列徽标**（Sequence Logo）用字母高度表示每个位置的残基频率和信息量，是基序可视化的标准方式。WebLogo是在线工具，ggseqlogo是R语言包。

```python
from Bio import AlignIO
from Bio.Align import AlignInfo

alignment = AlignIO.read("aligned.fasta", "fasta")
summary = AlignInfo.SummaryInfo(alignment)
consensus = summary.dumb_consensus(threshold=0.5)

print(f"序列数量: {len(alignment)}, 比对长度: {alignment.get_alignment_length()}")
print(f"一致性序列: {consensus}")
```

## 2.3.4 序列基序与结构域

序列基序是DNA或蛋白质中反复出现的短序列模式，与特定生物学功能相关。DNA基序通常是转录因子结合位点，蛋白质基序可能是功能位点或结构标记。

### 基序表示模型

**共有序列**列出每个位置最常出现的碱基，如TATA框表示为TATAWAWR（W=A或T，R=A或G）。直观但丢失频率细节。

**位置频率矩阵**（PFM）记录每个位置各碱基出现次数。**位置权重矩阵**（PWM）将频率转换为对数似然比权重。**位置特异性得分矩阵**（PSSM）经过背景频率校正和log转换。判断序列是否包含某转录因子结合位点时，用PWM/PSSM计算匹配得分。

```python
import numpy as np

pfm = np.array([
    [10, 0, 0, 0], [0, 0, 10, 0], [0, 0, 10, 0], [10, 0, 0, 0],
    [0, 5, 5, 0], [0, 0, 0, 10], [0, 0, 0, 10], [5, 0, 5, 0]
])

background = np.array([0.25, 0.25, 0.25, 0.25])
pseudocount = 0.5
total = pfm.sum(axis=1, keepdims=True)
ppm = (pfm + pseudocount) / (total + 4 * pseudocount)
pwm = np.log2(ppm / background)

bases = ['A', 'C', 'G', 'T']
test_seq = "TATATATA"
score = sum(pwm[i, bases.index(base)] for i, base in enumerate(test_seq))
print(f"序列 {test_seq} 的PWM得分: {score:.2f}")
```

### 基序发现算法

**枚举法**穷举所有可能短序列模式，统计富集显著性。DREME专用于发现短而精确的DNA基序。FIMO用已知PWM扫描序列匹配位点。结果确定性强，但长基序计算量大。

**概率方法**通过迭代优化发现基序。MEME使用期望最大化（EM）算法，从随机初始基序出发反复迭代，适合发现普遍存在的基序。Gibbs采样通过随机选择基序位置迭代更新，适合发现只存在于部分序列中的基序。

**比较基因组学方法**利用跨物种保守性发现功能基序。PhyloCon比较多个物种同源序列，PhastCons基于系统发育HMM检测保守非编码元件。

基于ChIP-seq数据的基序发现是当前最常用的转录因子结合位点发现方法。HOMER的findMotifs.pl和MEME-ChIP流程整合了从头发现和已知基序匹配。DeepBind和DanQ等深度学习方法在大规模数据上预测精度显著提升。

### 数据库与工具

**MEME Suite**是最完整的基序分析工具包，包含MEME（从头发现）、DREME（短基序）、FIMO（扫描）、MAST（搜索）、AME（富集分析）、Tomtom（基序比较）。

转录因子结合谱数据库：**JASPAR**（免费开放真核TF）、**TRANSFAC**（商业）、**HOCOMOCO**（人类和小鼠高质量）、**CIS-BP**（原核和真核）。Tomtom可将发现的基序与这些数据库比较，找到最相似的已知基序。

蛋白质结构域数据库：**Pfam**（最广泛使用的蛋白家族数据库）、**InterPro**（整合多个数据库）、**SMART**（信号通路相关结构域）、**CDD**（NCBI保守结构域）。InterProScan是整合注释工具，HMMER基于配置文件HMM搜索Pfam等数据库。

```bash
# HMMER搜索Pfam数据库
hmmscan --pfamtblout pfam_results.txt Pfam-A.hmm protein.fasta

# MEME从头基序发现
meme input.fasta -o meme_output -nmotifs 5 -minw 6 -maxw 20

# FIMO用已知基序扫描序列
fimo motif.meme sequences.fasta > fimo_results.tsv

# Tomtom比较基序
tomtom query.meme jaspar_database.meme -o tomtom_output
```

## 2.3.5 分子进化分析

分子进化分析利用分子序列数据研究生物进化关系和过程。通过比较同源序列，可以推断系统发育关系、估计进化速率、检测自然选择、重建祖先序列。

### 进化模型

进化模型描述分子序列在进化过程中发生替换的数学规律，是系统发育树构建和进化假设检验的基础。

**核苷酸替代模型**从简单到复杂：JC69假设所有碱基替换速率相等；K80区分转换和颠换；F81允许不同碱基频率；HKY85结合转换/颠换差异和碱基频率差异；GTR是最一般的时间可逆模型。实际分析常需添加伽马分布（+Γ）建模位点间速率异质性，以及不变位点比例（+I）。ModelTest或jModelTest用于选择最优模型。

**氨基酸替代模型**：Poisson最简单，Dayhoff基于早期数据，JTT基于更大数据集，WAG和LG分别针对球蛋白和广泛蛋白质。mtREV专用于线粒体蛋白。LG通常是较好的默认选择。

**密码子替代模型**区分同义和非同义替换。**dN/dS比率**（ω）是核心参数：ω<1表示纯化选择，ω=1中性进化，ω>1正选择。Goldman-Yang和Muse-Gaut是两种主要框架。

### 系统发育树构建

系统发育树构建方法分为距离法、最大简约法、最大似然法和贝叶斯法。

**距离法**先计算两两进化距离，再基于距离矩阵建树。**邻接法**（NJ）逐步合并最近分类单元，速度快，适合大数据集。UPGMA假设分子钟恒定，产生超度量树，进化速率差异大时可能错误。

**最大简约法**（MP）寻找最少进化步骤的拓扑，不需显式模型，但长枝吸引可能导致错误。

**最大似然法**（ML）在给定模型和拓扑下计算似然值，选择最大似然树。树搜索策略包括NNI、SPR、TBR。分支支持度用自举（bootstrap，通常1000次）评估。ML平衡准确率和效率，目前最广泛使用。

**贝叶斯法**通过MCMC采样估计树的后验概率分布。MrBayes常用，BEAST构建时间标度树并估计分化时间。优点是直接获得后验概率作为支持度，缺点是MCMC运行长且需判断收敛。

```r
library(ape)

# 读取比对序列
aln <- read.dna("aligned.fasta", format = "fasta")

# 计算距离矩阵（K80模型）
dist_matrix <- dist.dna(aln, model = "K80")

# NJ建树
nj_tree <- nj(dist_matrix)

# 自举检验（100次重复）
boot_trees <- boot.phylo(nj_tree, aln, function(x) nj(dist.dna(x, model = "K80")), B = 100)

# 绘制带自举值的树
plot(nj_tree, main = "Phylogenetic Tree (NJ)")
nodelabels(boot_trees, frame = "none", bg = "white")
add.scale.bar()

# 最大似然建树（使用phangorn包）
library(phangorn)
phangorn_aln <- phyDat(aln, type = "DNA")
ml_tree <- pml(nj_tree, data = phangorn_aln)
ml_tree_opt <- optim.pml(ml_tree, model = "GTR", rearrangement = "stochastic")
logLik(ml_tree_opt)
```

```bash
# IQ-TREE：自动模型选择+建树+自举
iqtree2 -s aligned.fasta -m MFP -bb 1000 -alrt 1000 -nt AUTO

# RAxML：最大似然法建树
raxmlHPC -s aligned.fasta -n output -m GTRGAMMA -p 12345 -# 20

# FastTree：快速近似ML建树
FastTree -gtr -nt aligned.fasta > tree.nwk
```

合并树（consensus tree）整合多棵树信息：严格合并树只包含所有输入树中都出现的分支，多数合并树包含超过50%输入树中出现的分支。树可视化工具：FigTree（轻量级）、ggtree（R包，功能强大）、iTOL（在线，支持丰富注释）、Dendroscope（大树可视化）。

### 正选择检测

正选择检测是进化分析中最受关注的应用。dN/dS>1表明非同义突变被自然选择保留。

**分支模型**允许不同分支有不同ω值，检测特定谱系正选择。**位点模型**允许不同密码子位点有不同ω值，M7（beta分布）vs M8（beta+ω>1）的似然比检验是标准方法。**分支-位点模型**同时考虑分支和位点差异，BEB方法识别受正选择的具体位点。

```bash
# PAML CODEML：位点模型检测正选择
# codeml.ctl配置：
#   seqfile = aligned_codons.phy
#   treefile = tree.nwk
#   NSsites = 7 8
codeml codeml.ctl

# HyPhy：MEME检测偶发性正选择
hyphy meme --alignment aligned_codons.fasta --tree tree.nwk

# HyPhy：BUSTED检测基因水平正选择
hyphy busted --alignment aligned_codons.fasta --tree tree.nwk

# HyPhy：FEL检测位点水平选择
hyphy fel --alignment aligned_codons.fasta --tree tree.nwk
```

::: note 选择压力方法
RELAX检测选择压力放松或加强。MEME检测偶发性正选择。FEL用固定效应估计每位点dN/dS。SLAC基于祖先序列重建。BUSTED检测基因水平偶发正选择。
:::

### 进化工具

**MEGA**是流行图形化软件，集成比对、模型选择、建树和编辑，适合初学者。**IQ-TREE**高效ML建树，内置ModelFinder自动选模，支持超快速自举。**RAxML**是大规模ML建树标准工具。**FastTree**用近似ML，速度比RAxML快数倍，适合超大规模数据集。**PAML**专注密码子水平分析，CODEML是检测正选择的标准工具。**HyPhy**提供灵活选择压力检测。

### 祖先序列重建与基因家族进化

**祖先序列重建**（ASR）根据现存物种序列和系统发育树推断祖先节点序列。边际重建为每个位点独立推断，联合重建考虑位点相关性。用于研究蛋白质进化历史、重建古代基因功能、设计特定性质蛋白质。

**基因重复与丢失**是基因家族进化的重要事件。Notung协调基因树与物种树的不一致，识别重复和丢失。**直系同源**（ortholog）由物种分化产生，通常保留相似功能；**旁系同源**（paralog）由基因重复产生，功能可能分化。OrthoFinder同时推断直系同源群和物种树，是当前最常用工具。

## 2.3.6 序列比较的特殊应用

### 全基因组比对与共线性分析

全基因组比对比较两个或多个完整基因组，用于发现结构变异、保守区域和重排事件。MUMmer适合近缘物种全基因组比对，LASTZ用于远缘物种，minimap2支持长读长和全基因组比对。

共线性分析检测基因组间保守的基因排列顺序。MCScanX是最常用工具，可检测共线性区域并分析基因重复事件。

```bash
# MUMmer全基因组比对
nucmer --maxmatch -p genome_comparison reference.fasta query.fasta
delta-filter -m genome_comparison.delta > filtered.delta
show-coords -rcl filtered.delta > coords.txt

# minimap2全基因组比对
minimap2 -x asm5 reference.fasta query.fasta > alignment.paf

# MCScanX共线性分析
MCScanX gene_collinearity
```

### 系统发育足迹分析

系统发育足迹分析（phylogenetic footprinting）通过比较多个物种的非编码序列发现保守调控元件。功能重要的调控元件受选择压力约束，在近缘物种间表现出高于背景的保守性。phastCons基于HMM识别保守区域，phyloP对每位点进行保守性检验。增强子和保守非编码元件（CNE）的识别是重要应用。

### 短读长比对

短读长比对到参考基因组是重测序分析的核心步骤。**BWA**最广泛使用，**Bowtie2**采用FM-index快速比对，**HISAT2**是RNA-seq专用剪接感知比对工具，能正确比对跨越外显子-内含子边界的读段。这些工具基于Burrows-Wheeler变换索引，与序列比对理论基础密切相关。

```bash
# BWA比对流程
bwa index reference.fasta
bwa mem -t 8 reference.fasta reads_R1.fastq reads_R2.fastq > aligned.sam

# Bowtie2比对
bowtie2-build reference.fasta ref_index
bowtie2 -x ref_index -1 reads_R1.fastq -2 reads_R2.fastq -S aligned.sam

# HISAT2剪接感知比对
hisat2-build reference.fasta ref_index
hisat2 -x ref_index -1 reads_R1.fastq -2 reads_R2.fastq -S rna_aligned.sam
```

::: tip 长读长比对
第三代测序（PacBio、Oxford Nanopore）错误率5-15%，读长达数十kb，传统短读长工具不适用。minimap2采用最小化子（minimizer）索引结合动态规划，是长读长比对首选工具。
:::

## 2.3.7 比对性能与统计

### 比对得分标准化

原始比对得分依赖打分矩阵和空位罚分，不同参数设置下的得分不能直接比较。**比特分**通过标准化消除打分参数影响，公式为S' = (λS - lnK) / ln2，其中λ和K是Karlin-Altschul统计量。比较不同BLAST搜索结果时应使用比特分。

### 统计显著性

BLAST统计显著性基于极值分布理论。Karlin-Altschul理论证明随机序列比对得分服从Gumbel分布，E值公式为E = Kmn·e^(-λS)，m和n是查询序列和数据库长度，S是比对得分。P值与E值关系为P = 1 - e^(-E)，E值很小时P值约等于E值。

**多重检验校正**：对1000条序列分别BLAST搜索，即使E值阈值0.05，也可能得到50个假阳性。Bonferroni校正最保守，将阈值除以检验次数；FDR校正控制假发现率，更宽松，大规模分析中常用。

### 敏感性与特异性

**敏感性**指真实同源序列被正确检出的比例，**特异性**指检出序列中真正同源的比例。两者存在权衡：降低E值阈值提高特异性但降低敏感性。探索性研究可放宽阈值，确认性研究应使用严格阈值。

### 比对评估基准

评估比对算法性能的基准数据集：BAliBASE（蛋白质多序列比对标准）、HomFam（基于Homstrad）、SABmark（超家族和扭曲家族两级）、PREFAB（结合结构和序列）。比对质量评分：Sum-of-pairs（所有序列对得分之和）、Column Score（正确列比例）、TC Score（完全正确列比例）。
