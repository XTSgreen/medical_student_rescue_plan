# 2.1 计算机与编程基础

生物信息学分析建立在 Linux 命令行、Shell 脚本、Python 编程、环境管理、版本控制和容器化这六项基础技能之上。本章按此顺序组织，每节先给出概念，再给出可直接运行的代码示例。

## 2.1.1 Linux 操作系统

### 文件系统结构

Linux 文件系统以根目录 `/` 为起点，所有文件和设备都挂载在这棵树上。生物信息学工作中需要识别以下关键目录：

| 目录 | 用途 | 日常使用场景 |
|------|------|--------------|
| `/home` | 用户主目录，`~` 的简写 | 存放项目、脚本、数据 |
| `/usr/local` | 本地编译安装的软件 | 源码安装 samtools 等 |
| `/var/log` | 系统与服务日志 | 排查任务失败原因 |
| `/tmp` | 临时文件，重启清空 | 程序中间产物 |
| `/etc` | 系统配置文件 | 修改环境变量、服务配置 |
| `/proc` | 内核状态接口 | 查看内存、CPU 信息 |

```bash
# 查看当前所在目录
pwd

# 切换到主目录
cd ~

# 查看目录内容（长格式、人类可读大小）
ls -lh
```

::: tip 主目录简写
`~` 等价于 `$HOME`，在路径中可以直接使用，例如 `~/data/sample.fastq`。
:::

### 用户与权限

每个文件有三组权限，分别对应**所有者**、**所属组**、**其他用户**，每组包含**读 r (4)**、**写 w (2)**、**执行 x (1)** 三种权限。`ls -l` 输出第一列的十字符中，第一位是文件类型，后九位按顺序对应三组权限。

```bash
# 创建用户并设置密码
sudo useradd -m -s /bin/bash bioinfo
sudo passwd bioinfo

# 查看文件权限
ls -l sample.fastq
# -rw-r--r-- 1 user group 1024 Jan 1 10:00 sample.fastq

# 数字方式设置权限：所有者 rwx=7, 组 r-x=5, 其他 r-x=5
chmod 755 script.sh

# 字母方式：为所有者添加执行权限
chmod u+x script.sh
```

| 权限 | 数字 | 字符表示 | 文件含义 | 目录含义 |
|------|------|----------|----------|----------|
| 读 r | 4 | r | 查看内容 | 列出文件名 |
| 写 w | 2 | w | 修改内容 | 创建/删除文件 |
| 执行 x | 1 | x | 运行脚本 | 进入目录 |

修改所有者使用 `chown`，递归修改目录使用 `-R` 选项：

```bash
sudo chown bioinfo:bioinfo data.txt
sudo chown -R bioinfo:bioinfo /home/bioinfo/project
```

### 进程管理

每个运行的程序是一个进程，拥有唯一的进程 ID (PID)。`ps` 查看进程快照，`top` 或 `htop` 提供实时视图。长时间任务必须正确管理，避免 SSH 断开时被终止。

```bash
# 查看所有进程
ps aux

# 实时监控
top
htop

# 后台运行并忽略挂起信号
nohup python analysis.py > output.log 2>&1 &

# 终止进程
kill 12345        # 正常终止
kill -9 12345     # 强制终止
```

::: warning 强制终止的风险
`kill -9` 立即结束进程，可能导致临时文件未清理或数据损坏。先尝试 `kill`，无响应时再使用 `-9`。
:::

### 磁盘与文件管理

生物信息学数据文件常达数十 GB。开始分析前必须检查磁盘空间，避免任务中途因空间不足失败。

```bash
# 查看文件系统空间
df -h

# 查看目录占用（汇总）
du -sh .

# 找出最大的 10 个文件
du -ah | sort -rh | head -n 10
```

文件操作命令：

```bash
# 复制文件和目录
cp source.txt dest.txt
cp -r source_dir/ dest_dir/

# 移动或重命名
mv old.txt new.txt

# 删除（不可恢复，谨慎使用 -rf）
rm file.txt
rm -r directory/

# 创建符号链接，避免数据复制
ln -s /path/to/data data_link
```

::: tip 符号链接的用途
将分散在不同目录的样本数据链接到统一工作目录，方便批量处理，且不占用额外空间。
:::

### 文本编辑器

vim 与 nano 是命令行两大编辑器。nano 适合快速修改配置文件，vim 适合长时间编写代码。

| 操作 | nano | vim |
|------|------|-----|
| 打开文件 | `nano file` | `vim file` |
| 编辑模式 | 直接输入 | 按 `i` 进入插入模式 |
| 保存 | `Ctrl+O` | `Esc` 后输入 `:w` |
| 退出 | `Ctrl+X` | `Esc` 后输入 `:q` |
| 保存退出 | `Ctrl+O` 后 `Ctrl+X` | `Esc` 后输入 `:wq` |

### 环境变量

环境变量是程序运行时的配置信息。`PATH` 决定命令查找路径，`LD_LIBRARY_PATH` 决定动态库查找路径，`PYTHONPATH` 决定 Python 模块查找路径。

```bash
# 查看变量值
echo $PATH

# 临时设置
export PATH=/home/user/bin:$PATH

# 永久生效：写入 bashrc
echo 'export PATH=/home/user/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

### 压缩与归档

`tar` 是最常用的归档工具，配合 `gzip` 或 `bzip2` 实现压缩。

```bash
# 创建 gzip 压缩归档
tar czvf archive.tar.gz directory/

# 解压到当前目录
tar xzvf archive.tar.gz

# 解压到指定目录
tar xzvf archive.tar.gz -C /target/

# gzip 单文件
gzip file.txt        # 生成 file.txt.gz，原文件删除
gunzip file.txt.gz
```

| 格式 | 压缩命令 | 解压命令 | 特点 |
|------|----------|----------|------|
| .tar.gz | `tar czvf` | `tar xzvf` | 速度与压缩率平衡，最常用 |
| .tar.bz2 | `tar cjvf` | `tar xjvf` | 压缩率更高，速度较慢 |
| .zip | `zip -r` | `unzip` | 跨平台兼容 |

### 远程访问与文件传输

SSH 提供安全的远程登录和文件传输。密钥认证比密码更安全，且免输入。

```bash
# 远程登录
ssh username@hostname

# 生成密钥对
ssh-keygen -t rsa -b 4096

# 将公钥复制到远程主机
ssh-copy-id username@hostname

# 复制文件到远程
scp localfile.txt username@hostname:/remote/path/

# 使用 rsync 同步目录（仅传变化部分）
rsync -avz localdir/ username@hostname:/remote/path/
```

::: tip rsync 与 scp 的选择
单次传输少量文件用 `scp`，同步大量文件或大文件用 `rsync`。`rsync` 支持断点续传和差异同步。
:::

### 管道与重定向

重定向改变命令的输入输出流向，管道将一个命令的输出连接到另一个命令的输入。

```bash
# 标准输出重定向（覆盖）
ls > filelist.txt

# 追加
echo "log entry" >> logfile.txt

# 同时重定向标准输出和标准错误
command > output.log 2>&1
command &> output.log

# 丢弃输出
command > /dev/null 2>&1

# 管道：统计包含 pattern 的行数
cat file.txt | grep "pattern" | wc -l
```

### 查找与过滤

`find` 按条件查找文件，`grep` 按模式搜索文本内容。

```bash
# 按文件名查找
find . -name "*.fastq"

# 按大小查找（大于 100 MB）
find . -size +100M

# 按修改时间查找（7 天内）
find . -mtime -7

# 对找到的文件执行命令
find . -name "*.txt" -exec wc -l {} \;

# grep 搜索文本
grep "gene" file.txt          # 基本搜索
grep -i "gene" file.txt       # 忽略大小写
grep -v "gene" file.txt       # 显示不匹配的行
grep -c "gene" file.txt       # 只显示匹配行数
grep -rn "error" /var/log/    # 递归显示行号
```

## 2.1.2 Shell 脚本编程

### 通配符与变量

Shell 通配符用于匹配文件名，变量用于存储数据。变量赋值时等号两边不能有空格。

```bash
# 通配符
ls *.fastq              # 所有 fastq 文件
ls sample?.fastq        # sample1.fastq, sampleA.fastq
ls sample[123].fastq    # sample1, sample2, sample3
mkdir project_{A,B,C}   # 创建 project_A, project_B, project_C

# 变量
data_dir=/data/project
sample_name="sample_001"
echo "${sample_name}_R1.fastq"   # 大括号避免歧义

# 命令替换
current_date=$(date +%Y%m%d)
file_count=$(ls | wc -l)
```

### 数组与特殊变量

bash 支持一维数组。特殊变量由 shell 自动设置，提供脚本运行环境信息。

```bash
# 数组
samples=(sample1 sample2 sample3)
echo ${samples[0]}          # 第一个元素
echo ${samples[@]}          # 所有元素
echo ${#samples[@]}         # 数组长度
samples+=(sample4)          # 追加元素

# 特殊变量
echo "Script: $0"           # 脚本名
echo "Args: $#"             # 参数个数
echo "All args: $@"         # 所有参数
echo "Exit status: $?"      # 上一命令退出状态
echo "PID: $$"              # 当前进程 ID
```

### 条件判断

`if` 语句根据命令退出状态决定执行分支。`test` 命令或方括号 `[ ]` 用于条件测试，方括号两侧必须有空格。

```bash
# 文件测试
if [ -f "data.txt" ]; then
    echo "File exists"
elif [ -d "data" ]; then
    echo "Directory exists"
else
    echo "Not found"
fi

# 数值比较：-eq -ne -lt -le -gt -ge
if [ $count -gt 100 ]; then
    echo "Large dataset"
fi

# 字符串比较
if [ "$str1" = "$str2" ]; then
    echo "Equal"
fi
```

`case` 语句适合多分支离散值判断：

```bash
case $file_type in
    *.fastq)  echo "FASTQ file" ;;
    *.fasta)  echo "FASTA file" ;;
    *.bam)    echo "BAM file" ;;
    *)        echo "Unknown" ;;
esac
```

### 循环

`for` 遍历列表，`while` 在条件为真时重复执行。批量处理文件是循环最常见的用途。

```bash
# 遍历文件
for file in *.fastq; do
    echo "Processing $file"
    wc -l "$file"
done

# C 风格循环
for ((i=1; i<=10; i++)); do
    echo "Number: $i"
done

# 逐行读取文件
while read line; do
    echo "$line"
done < data.txt

# 等待文件出现
while [ ! -f "output.txt" ]; do
    sleep 5
done
```

### 函数

函数将重复使用的命令封装为可调用单元，使用 `local` 定义局部变量避免污染全局作用域。

```bash
process_file() {
    local file=$1
    local output_dir=$2
    if [ -f "$file" ]; then
        wc -l "$file"
        return 0
    else
        echo "Error: $file not found"
        return 1
    fi
}

process_file "data.fastq" "results/"

# 通过命令替换捕获函数输出
get_file_count() {
    ls -1 "$1" 2>/dev/null | wc -l
}
count=$(get_file_count "data/")
```

### 调试技巧

`set` 命令开启调试选项，在脚本开发阶段非常有用。

| 选项 | 作用 |
|------|------|
| `set -x` | 打印执行的每条命令 |
| `set -e` | 命令失败时立即退出 |
| `set -u` | 使用未定义变量时报错 |
| `set -o pipefail` | 管道中任一命令失败则整体失败 |

```bash
#!/bin/bash
set -euxo pipefail

input_fastq="${1:?Error: input FASTQ required}"
output_dir="${2:-results}"

mkdir -p "$output_dir"
fastqc "$input_fastq" -o "$output_dir"
```

::: tip 调试单个命令
运行时使用 `bash -x script.sh` 开启跟踪，`bash -n script.sh` 仅检查语法不执行。
:::

### 常用文本处理工具

`awk`、`sed`、`cut`、`sort`、`uniq` 是 Shell 文本处理的核心工具，组合使用可以完成复杂的数据处理。

```bash
# awk 按列处理
awk '{print $1}' data.txt                       # 打印第一列
awk -F, '{print $1, $3}' data.csv               # 指定逗号分隔
awk '$3 > 100 {print $0}' data.txt              # 条件过滤
awk '{sum+=$1} END {print sum/NR}' numbers.txt  # 计算平均值

# FASTQ 文件平均读长
awk 'NR%4==2 {sum+=length($0); count++} END {print sum/count}' sample.fastq

# sed 文本替换
sed 's/old/new/g' file.txt          # 全局替换
sed -i 's/old/new/g' file.txt       # 原地修改
sed '/pattern/d' file.txt           # 删除匹配行
sed -n '10,20p' file.txt            # 打印 10-20 行

# cut 提取列
cut -f1,3 data.txt                  # 制表符分隔，提取 1、3 列
cut -d, -f1 data.csv                # 逗号分隔

# sort 与 uniq 配合
sort data.txt | uniq -c | sort -nr  # 统计并按频率排序

# 统计 FASTQ reads 数量
wc -l sample.fastq | awk '{print $1/4}'
```

## 2.1.3 环境与包管理

### Conda 与 Mamba

### 频道配置

频道是 Conda 包的来源仓库。生物信息学推荐配置顺序为 conda-forge、bioconda、defaults，优先级从高到低。


每个 Conda 环境相互隔离，包含独立的 Python 版本和软件包。为不同分析任务创建独立环境，避免依赖冲突。

## 2.1.4 Python 编程基础

### 数据类型与结构

Python 使用缩进表示代码块，建议 4 个空格。变量动态类型，无需声明。常用数据结构包括列表、元组、字典、集合。

```python
# 基本类型
gene_name = "TP53"
expression = 45.6
is_significant = True

# 列表：有序可变
genes = ["BRCA1", "TP53", "EGFR"]
genes.append("MYC")
print(genes[0], genes[-1], genes[1:3])

# 元组：有序不可变，可作为字典键
coordinates = (100, 200, 300)

# 字典：键值对，常用于存储映射关系
gene_info = {
    "name": "TP53",
    "chromosome": "chr17",
    "start": 7668421,
    "end": 7687490
}
print(gene_info.get("strand", "+"))

# 集合：无序唯一，用于去重和成员测试
unique_genes = set(["TP53", "BRCA1", "TP53", "EGFR"])
```

### 控制流程

`if-elif-else` 进行条件分支，`for` 遍历可迭代对象，`while` 在条件为真时循环。推导式用简洁语法创建新数据结构。

```python
# 条件分支
expression = 15.5
if expression > 20:
    status = "high"
elif expression > 10:
    status = "medium"
else:
    status = "low"

# for 循环
for gene in ["TP53", "BRCA1", "EGFR"]:
    print(f"Processing {gene}")

# 列表推导式
values = [10.5, 12.3, 8.7, 15.2]
high = [x for x in values if x > 10]

# 字典推导式
lengths = {"TP53": 393, "BRCA1": 1863, "EGFR": 1210}
long = {k: v for k, v in lengths.items() if v > 500}
```

### 函数

`def` 定义函数，参数可以有默认值。`*args` 接收任意位置参数，`**kwargs` 接收任意关键字参数。`lambda` 定义匿名函数，常用于高阶函数参数。

```python
def calculate_gc_content(sequence):
    gc = sequence.count('G') + sequence.count('C')
    return gc / len(sequence) * 100

def analyze_sequence(sequence, min_length=10):
    if len(sequence) < min_length:
        return None
    return {"length": len(sequence), "gc": calculate_gc_content(sequence)}

# 可变参数
def calculate_mean(*values):
    return sum(values) / len(values)

# 匿名函数：按 G 含量排序
sequences = ["ATGC", "GCTA", "TTAA"]
sorted_seqs = sorted(sequences, key=lambda x: x.count('G'))

# 生物信息学函数：反向互补
def reverse_complement(seq):
    comp = {'A': 'T', 'T': 'A', 'G': 'C', 'C': 'G'}
    return ''.join(comp[b] for b in reversed(seq))
```

### 文件操作

使用 `with` 语句自动管理文件资源，即使发生异常也能正确关闭。大文件应逐行读取，避免一次性加载到内存。

```python
# 读取 FASTA 文件
def read_fasta(file_path):
    sequences = {}
    current_id = None
    current_seq = []
    with open(file_path, 'r') as f:
        for line in f:
            line = line.strip()
            if line.startswith('>'):
                if current_id:
                    sequences[current_id] = ''.join(current_seq)
                current_id = line[1:].split()[0]
                current_seq = []
            else:
                current_seq.append(line)
        if current_id:
            sequences[current_id] = ''.join(current_seq)
    return sequences

# 写入文件
def write_fasta(sequences, output_file, line_width=60):
    with open(output_file, 'w') as f:
        for seq_id, sequence in sequences.items():
            f.write(f">{seq_id}\n")
            for i in range(0, len(sequence), line_width):
                f.write(sequence[i:i+line_width] + "\n")
```

### 异常处理

`try-except` 捕获异常，`finally` 始终执行资源清理。捕获具体异常类型，避免空 `except` 隐藏错误。

```python
try:
    with open("nonexistent.txt", 'r') as f:
        content = f.read()
except FileNotFoundError:
    print("File not found")
except PermissionError:
    print("Permission denied")
except Exception as e:
    print(f"Error: {e}")
finally:
    print("Cleanup here")

# 主动抛出异常
def validate_dna(sequence):
    if not all(base in 'ATGC' for base in sequence.upper()):
        raise ValueError("Invalid sequence: non-ATGC character")
    return True
```

### 模块与生物信息学库

Python 通过 `import` 导入模块。生物信息学常用 Biopython 处理序列数据，pandas 处理表格数据，NumPy 进行数值计算，Matplotlib 绘图。


### 正则表达式

`re` 模块提供正则表达式操作。建议使用原始字符串 `r'...'` 避免反斜杠转义问题。`search` 搜索第一个匹配，`findall` 返回所有匹配，`sub` 执行替换。

```python
import re

# 提取 GFF 属性字段中的基因 ID
gff_line = "chr17\tHAVANA\tgene\t7668421\t7687490\t.\t+\t.\tID=gene:TP53;Name=TP53"
match = re.search(r'ID=gene:(\w+);Name=(\w+)', gff_line)
if match:
    print(f"Gene ID: {match.group(1)}")
    print(f"Name: {match.group(2)}")

# 命名捕获组
match = re.search(r'(?P<chr>\w+):(?P<start>\d+)-(?P<end>\d+)', "chr17:7668421-7687490")
print(match.group('chr'), match.group('start'), match.group('end'))

# 验证 DNA 序列
def validate_dna(seq):
    return bool(re.match(r'^[ATGC]+$', seq))

# 查找限制性酶切位点
for m in re.finditer(r'GAATTC', "ATGCGAATTCGATCGAATTCCGATCG"):
    print(f"EcoRI site at {m.start()}")
```

## 2.1.5 Git 版本控制

### 基本概念

Git 是分布式版本控制系统，每个开发者持有完整仓库副本。三个核心区域构成工作流：**工作区**（实际文件）、**暂存区**（待提交快照）、**仓库**（提交历史）。

| 概念 | 说明 |
|------|------|
| 仓库 (repository) | 包含项目所有文件和历史记录 |
| 提交 (commit) | 文件快照，含 SHA-1 哈希、作者、消息 |
| 分支 (branch) | 指向某提交的可移动指针 |
| 暂存区 (staging) | `git add` 后、`git commit` 前的待提交内容 |

### 基本工作流

修改文件 → `git add` 加入暂存区 → `git commit` 提交到仓库。每次提交应只包含逻辑相关的修改，提交消息简洁描述改动内容。

```bash
# 初始化仓库
mkdir bioinfo_project && cd bioinfo_project
git init

# 配置用户信息
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# 添加文件并提交
git add analysis.py
git add README.md
git commit -m "Add analysis script and README"

# 查看状态与历史
git status
git log --oneline
git log --graph --oneline --all

# 查看差异
git diff                  # 工作区与暂存区
git diff --staged         # 暂存区与最新提交
```

### 分支管理

分支允许并行开发不同功能。`git checkout -b` 创建并切换分支，`git merge` 合并分支。冲突时手动编辑冲突标记后提交。

```bash
# 创建并切换分支
git checkout -b feature-add-qc

# 查看所有分支
git branch -a

# 切换回主分支并合并
git checkout master
git merge feature-add-qc

# 删除已合并的分支
git branch -d feature-add-qc
```

### 远程仓库

远程仓库用于多人协作和备份。`git push` 推送本地提交，`git pull` 拉取远程更新并合并，`git fetch` 仅获取不合并。

```bash
# 克隆远程仓库
git clone https://github.com/user/project.git

# 添加远程仓库
git remote add origin https://github.com/user/project.git

# 首次推送并设置上游
git push -u origin master

# 拉取更新
git pull origin master

# 仅获取不合并
git fetch origin
```

### 撤销操作

撤销操作可能丢失修改，需谨慎。`git reflog` 记录所有引用变更，可用于恢复误删提交。

```bash
# 丢弃工作区修改
git checkout -- analysis.py

# 取消暂存
git reset HEAD analysis.py

# 修改最后一次提交
git commit --amend -m "New message"

# 回退到指定提交（丢弃后续修改）
git reset --hard a1b2c3d

# 查看操作历史
git reflog
```

::: warning reset --hard 的风险
`git reset --hard` 会丢弃所有未提交的修改，执行前确认工作区没有需要保留的内容。
:::

### .gitignore 配置

生物信息学项目应将大文件、临时文件、结果文件排除在版本控制之外。

```bash
cat > .gitignore << 'EOF'
# 数据文件
*.fastq
*.fasta
*.bam
*.vcf

# 结果文件
results/*.txt
results/*.pdf

# 临时文件
*.log
*.tmp
__pycache__/

# 系统文件
.DS_Store
EOF
```

::: tip 大文件管理
测序数据等大文件不应纳入 Git。使用 Git LFS 或专门的数据存储系统管理，仅在仓库中保留示例数据用于测试。
:::

## 2.1.6 容器化技术

### Docker 基础

容器将应用程序及其所有依赖打包成镜像，镜像运行实例为容器。容器化保证分析环境在不同系统上完全一致，是可重复分析的关键技术。

| 概念 | 说明 |
|------|------|
| 镜像 (image) | 只读模板，包含运行环境 |
| 容器 (container) | 镜像的运行实例 |
| Dockerfile | 构建镜像的指令文件 |
| 数据卷 (volume) | 持久化数据，独立于容器生命周期 |

```bash
# 拉取镜像
docker pull biocontainers/fastqc:v0.11.9

# 构建镜像
docker build -t bioinfo-analysis:1.0 .

# 运行容器（挂载数据目录）
docker run -v /path/to/data:/data bioinfo-analysis:1.0

# 后台运行
docker run -d --name analysis bioinfo-analysis:1.0

# 查看运行中的容器
docker ps

# 进入运行中的容器
docker exec -it analysis bash

# 查看日志、停止、删除
docker logs analysis
docker stop analysis
docker rm analysis
```

### Dockerfile 编写

Dockerfile 从基础镜像开始，逐步添加软件和配置。每条指令创建一个层，合理排序可利用缓存加速构建。

```dockerfile
FROM python:3.9-slim

LABEL maintainer="your.email@example.com"
WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    wget bzip2 libncurses5-dev zlib1g-dev \
    && rm -rf /var/lib/apt/lists/*

# 安装 Miniconda
RUN wget -q https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh \
    && bash Miniconda3-latest-Linux-x86_64.sh -b -p /opt/conda \
    && rm Miniconda3-latest-Linux-x86_64.sh
ENV PATH="/opt/conda/bin:${PATH}"

# 配置频道并安装生物信息学工具
RUN conda config --add channels bioconda \
    && conda config --add channels conda-forge \
    && conda install -y fastqc bwa samtools bcftools \
    && conda clean -afy

# 复制脚本并设置入口
COPY scripts/ /app/scripts/
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

ENTRYPOINT ["python", "/app/scripts/pipeline.py"]
```

::: tip 镜像优化
合并 `RUN` 指令减少层数，使用 `conda clean -afy` 清理缓存，选择 `slim` 基础镜像，可显著减小镜像体积。
:::

### Docker Compose

Docker Compose 用 YAML 文件定义多容器应用，一键启动包含数据库、Web、分析服务的完整平台。

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:13
    environment:
      POSTGRES_DB: bioinfo_db
      POSTGRES_USER: bioinfo
      POSTGRES_PASSWORD: password
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"

  jupyter:
    image: jupyter/datascience-notebook
    ports:
      - "8888:8888"
    volumes:
      - ./notebooks:/home/jovyan/work
      - ./data:/home/jovyan/data

  analysis:
    build: ./analysis
    volumes:
      - ./data:/data
      - ./results:/results
    depends_on:
      - postgres

volumes:
  postgres_data:
```

```bash
# 启动所有服务（后台）
docker-compose up -d

# 查看状态
docker-compose ps

# 停止并删除容器
docker-compose down
```

### Singularity

Singularity 适合 HPC 集群环境，普通用户即可运行容器，无需 root 权限。镜像为单个 SIF 文件，便于传输。

```bash
# 从 Docker Hub 拉取并转换为 SIF
singularity pull fastqc.sif docker://biocontainers/fastqc:v0.11.9

# 执行容器中的命令
singularity exec fastqc.sif fastqc sample.fastq

# 交互式 shell
singularity shell fastqc.sif

# 绑定挂载数据目录
singularity exec -B /path/to/data:/data fastqc.sif fastqc /data/sample.fastq
```

::: note HPC 环境选择
共享集群中优先使用 Singularity 而非 Docker。Singularity 与 Slurm、Nextflow、Snakemake 集成良好，且无需管理员权限。
:::

### 容器化生物信息学流程

将分析流程容器化可保证可重复性。Biocontainers 项目为 Bioconda 中的软件提供对应容器镜像，覆盖数千个生物信息学工具。结合 Nextflow 或 Snakemake 等工作流系统，可以协调多个容器的执行、管理数据流和依赖关系。

数据应通过数据卷或绑定挂载存储在容器外部，避免容器删除后数据丢失。集群环境中通常使用共享文件系统，通过绑定挂载访问数据。
